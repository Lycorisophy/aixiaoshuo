# 《蚀名簿》第二版·核心设定框架

> 版本：v2.0
> 更新日期：2026-04-02
> 核心诡计：身份替换 + 家族犯罪
> 参考：京极夏彦《狂骨之梦》《魍魉之匣》

---

## 一、核心设定确认

### 五大核心决定

| 问题 | 选择 | 说明 |
|------|------|------|
| **时间跨度** | 一百年（3-4 代人） | 从民国时期开始，约 1920s-2020s |
| **井底设定** | 藏身份文件和遗物 | 不藏尸体，避免法医学漏洞 |
| **言临动机** | 主动想打破家族传统 | 内心挣扎，"加害者也是被害者" |
| **结局** | 开放式 | 不明确说是否公开真相 |
| **妖怪元素** | 作为"社会心理"保留 | 妖怪是人心制造的烟雾弹 |

---

## 二、世界观设定

### 双层结构

```
┌─────────────────────────────────────────────────┐
│                    表层（妖怪故事）              │
│  名册 = 记录"名字"的玄幻档案                     │
│  失名者 = 被妖怪吞噬的人                         │
│  井底 = 通向"名册意识"的神秘空间                 │
│  容器 = 吸收灵魂的玄幻存在                       │
└─────────────────────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────┐
│                    里层（犯罪真相）              │
│  名册 = 犯罪记录（被害者身份信息）               │
│  失名者 = 被同一人/家族陆续杀害的人              │
│  井底 = 藏匿身份文件和遗物的密室                 │
│  容器 = 真凶本人或帮凶（一直在场）               │
└─────────────────────────────────────────────────┘
```

### 妖怪元素的处理原则

| 场景 | 妖怪元素 | 真实解释 |
|------|----------|----------|
| 民间传说 | "井底有妖怪吃名字" | 家族散布的谣言，掩盖犯罪 |
| 失名现象 | "名字被吞噬" | 身份被替换，社会记录被篡改 |
| 井底异象 | "听到名字呼唤" | 心理暗示 + 回声效应 |
| 纸翁的"法术" | 民间秘术 | 家族控制的信息网络 |

**核心原则：** 妖怪是"社会心理层面的真实"，人们相信妖怪，所以忽略人为犯罪。

### 重要说明

3. **沈近只是受害者**：沈家不是犯罪家族，只是被选中的目标

## 四、叙事结构

### 五幕结构（约 40 节）

```
第一幕：侵（第 01-08 节）
├─ 时间：沈近失踪后第 1-7 天
├─ 视角：A 视角 
├─ 内容：名册出土→沈近失踪→遇见纸翁→听说井底传说
├─ 线索：失踪者都是外来者、都有户籍涂改痕迹
└─ 结尾：陈言决定下井

第二幕：啮（第 09-16 节）
├─ 时间：沈近失踪后第 7-14 天
├─ 视角：B 视角 
├─ 内容：下井调查→发现名册秘密→言临提供"线索"
├─ 线索：名册上每对名字、言临的回避行为
└─ 结尾：发现沈近可能被"替换"

第三幕：穴（第 17-24 节）
├─ 时间：沈近失踪后第 14-21 天
├─ 视角：A 视角 
├─ 内容：调查失踪者→发现外貌相似→言临身份可疑
├─ 线索：旧照片中的"双胞胎"、户籍档案涂改
└─ 结尾：言临被发现是家族成员

第四幕：耗（第 25-32 节）
├─ 时间：沈近失踪后第 21-28 天
├─ 视角： B 视角
├─ 内容：揭露家族犯罪→言临的动机→井底真相
├─ 线索：井底藏的身份文件、家族秘传记录
└─ 结尾：找到沈近（可能还活着）

第五幕：朽（第 33-40 节）
├─ 时间：沈近失踪后第 28-35 天
├─ 视角：A 视角 
├─ 内容：救出沈近→追究幕后→余韵
├─ 线索：完整证据链收束
└─ 结尾：开放式（不明确说是否公开真相）
```

### 双视角设计

| 视角 | 角色 | 作用 | 写作要点 |
|------|------|------|----------|
| **A 视角** | 陈言 | 读者代入点，调查者 | 真实记录，但信息有限 |
| **B 视角** | 言临 | 误导读者，内心挣扎 | 表面帮助，实际监视；内心独白有双重含义 |

## 五、核心证据链

### 读者可验证的线索

```
1. 失踪者外貌相似 
   → 2. 名册上一对名字（真/假）
   → 3. 言临的回避行为（多次出现）
   → 4. 户籍档案涂改痕迹
   → 5. 井底藏的身份文件
   → 6. 秦氏家族秘传记录
```

### 核心线索设计

| 线索 | 前期暗示 | 后期验证 |
|------|----------|----------|
| **失踪者的外貌相似** | 多处暗示"总觉得他像谁" | 证实是替身关系 |
| **名册上的对应记录** | 每条记录都是一对名字 | 证实身份替换 |
| **言临的某个习惯** | 多次出现小动作（如摸手套） | 最终识别出真凶 |
| **井底的实际性质** | 传说通往妖怪巢穴 | 实际上是藏证据的地下室 |
| **失踪者的人际关系** | 都有与同一人的交集 | 证实言临与每个受害者都有关联 |

### 辅助线索

| 线索 | 作用 |
|------|------|
| 旧照片中的"双胞胎" | 暗示身份替换 |
| 户籍档案的涂改痕迹 | 暗示身份篡改 |
| 失踪者最后出现的地点 | 指向言临的活动区域 |
| 名册的纸张材质/字迹 | 指向民国时期的家族记录 |

## 六、犯罪手法设定

### 身份替换手法（百年传统）

| 步骤 | 手法 | 说明 |
|------|------|------|
| 第一步 | 寻找与自己外貌相似的目标 | 专门找外来者、孤儿、边缘人群 |
| 第二步 | 杀害目标，获取其身份文件 | 户籍、证件、照片等 |
| 第三步 | 用目标的身份生活 | 同时销毁自己的痕迹 |
| 第四步 | 在名册上记录这次"替换" | 作为家族秘传 |
| 第五步 | 等待时机，继续下一轮替换 | 约 25-30 年一次 |

### 为什么能维持百年？

| 原因 | 说明 |
|------|------|
| **每一代只执行一次** | 降低暴露风险 |
| **目标都是边缘人群** | 失踪后不易引起关注 |
| **家族控制信息网络** | 纸翁等知情者帮助掩盖 |
| **收买官员/警察** | 篡改档案、压案不查 |
| **妖怪传说作为烟雾弹** | 人们归因于超自然，忽略人为犯罪 |

## 七、言临的动机设计

### 核心动机：主动想打破家族传统

| 层面 | 内容 |
|------|------|
| **表面行为** | 帮助陈言调查，提供线索 |
| **实际目的** | 监视调查进展，确保家族秘密不暴露 |
| **内心挣扎** | 想打破传统，但害怕家族报复 |
| **最终选择** | 在关键时刻帮助陈言，但代价不明 |

### B 视角写作要点

```
B 视角中：
- B 表现得很关心 A 的调查进展
- B 提供的"线索"实际上是误导性信息
- B 的内心独白要设计成表面关心、实则警惕的双重含义
- 读者在 B 视角中会认为 B 是好人，直到最终反转

示例内心独白：
"我得帮他找到真相。"（表面）
"但我不能让他找到得太快。"（实际）
"也许...这次真的可以结束。"（内心挣扎）
```

## 八、开放式结局设计

### 结局要点

| 元素 | 设计 |
|------|------|
| **沈近的命运** | 找到，但状态不明（可能失忆/受伤） |
| **秦氏家族的结局** | 部分被揭露，但幕后仍在逃 |
| **言临的选择** | 帮助陈言后消失，生死不明 |
| **真相是否公开** | 不明确说，留给读者想象 |

### 最后一幕建议

```
陈言站在档案馆门口，手里拿着完整的证据链。

手机响了，是记者："沈先生，您准备好公开了吗？"

陈言看向远处，言临消失的方向。

"我……"

画面定格，不给出明确答案。
```

## 九、与第一版的核心差异

| 方面 | 第一版 | 第二版 |
|------|--------|--------|
| **核心诡计** | 玄幻设定（名册意识、容器） | 身份替换（真实犯罪） |
| **时间跨度** | 三百年 | 一百年 |
| **推理要素** | 靠"老人"告诉你 | 靠证据链自行推理 |
| **妖怪来源** | 真的有妖怪 | 妖怪是人心问题的烟雾弹 |
| **降妖除魔** | 进入井底打怪 | 揭露犯罪、救出受害者 |
| **B 视角** | 玄幻设定下的反派 | 推理小说中的真凶/帮凶 |
| **言临动机** | 模糊（守护容器） | 清晰（想打破家族传统） |
| **结局** | 沈近消失，言临变成零一 | 开放式，真相是否公开不明 |
