## 二、核心设定：名册的真相

### 表层（妖怪故事）

| 元素 | 表层设定 |
|------|----------|
| **名册** | 记录"名字"的玄幻档案，被神秘力量操控 |
| **失名者** | 被妖怪吞噬的人，名字从世界上消失 |
| **井底** | 通向"名册意识"的神秘空间 |
| **"容器"** | 吸收灵魂的玄幻存在 |

### 里层（推理真相）

| 元素 | 里层设定 |
|------|----------|
| **名册** | 真实的犯罪记录——记录**被害者的身份信息** |
| **失名者** | 被**同一人/家族陆续杀害**的人 |
| **井底** | **藏尸/藏证据的密室/地下室** |
| **"容器"** | **真凶本人或帮凶**，一直在场 |

## 三、主诡计：三百年的身份替换

### 核心手法

凶手专门寻找**与自己外貌相似**的人，杀人后**互换身份**。

| 步骤 | 手法 |
|------|------|
| 第一步 | 寻找与自己外貌相似的目标 |
| 第二步 | 杀害目标，获取其身份文件（户籍、证件） |
| 第三步 | 用目标的身份生活，同时销毁自己的痕迹 |
| 第四步 | 在名册上记录这次"替换"（作为家族秘传） |
| 第五步 | 等待时机，继续下一轮替换 |

### 目的

- 凶手借用被害者的身份生活
- 抹去自己的存在痕迹
- 家族血脉通过"替换他人"得以延续
- 财富和地位通过"继承他人身份"不断积累

### "失名"现象的解释

被害者原来的名字/身份从社会上消失。人们记得的只是凶手的替身。当真相揭开，人们才意识到：**失踪者不是"消失"了，而是被另一个人"取代"了**。

## 四、诡计结构

### 参考京极"中盘揭秘"型结构

| 阶段 | 内容 | 推理要素 |
|------|------|----------|
| **第一部（侵）** | 名册出土，陆续有人失踪，妖怪传说兴起 | 铺设线索：失踪者的共同点 |
| **第二部（啮）** | 主角调查，发现名册的秘密 | 建立推理框架：名册=受害者名单 |
| **第三部（穴）** | 发现受害者都曾被"替换"，凶手一直在身边 | 身份诡计揭示：谁是凶手？ |
| **第四部（耗）** | 揭露凶手身份和动机 | 动机揭示：三百年的"身份替换"传统 |
| **第五部（朽）** | 收网，救出可能的幸存者，追究幕后 | 完整真相+余韵 |

## 五、可验证的证据链

### 线索设计原则

每个线索都应该让读者能够**自行推理验证**，而不是靠角色口述揭示真相。

### 核心线索

| 线索 | 前期暗示 | 后期验证 |
|------|----------|----------|
| **失踪者的外貌相似** | 多处暗示"总觉得他像谁" | 证实是替身关系 |
| **名册上的对应记录** | 每条记录都是一对名字（真/假） | 证实身份替换 |
| **凶手的某个习惯** | 多次出现凶手的小动作 | 最终识别出真凶 |
| **井底的实际性质** | 传说通往妖怪巢穴 | 实际上是藏匿证据的地下室 |
| **失踪者的人际关系** | 都有与同一人的交集 | 证实凶手与每个受害者都有关联 |

### 辅助线索

| 线索 | 作用 |
|------|------|
| 旧照片中的"双胞胎" | 暗示身份替换 |
| 户籍档案的涂改痕迹 | 暗示身份篡改 |
| 失踪者最后出现的地点 | 指向凶手的活动区域 |
| 名册的纸张材质/字迹 | 指向特定历史时期的家族记录 |

## 六、B视角的重新设计

### 当前问题

言临/零一的动机过于玄幻（"守护容器"），缺乏推理小说的犯罪动机。

### 改进后

| 设计 | 说明 |
|------|------|
| **B的真实身份** | 凶手本人，或凶手的协助者（家族成员） |
| **B视角的作用** | **误导读者**——让读者以为B是在"调查"，实际上是在"掩盖真相" |
| **B的动机** | 家族使命——延续"替换"传统，或被迫参与家族犯罪 |
| **B的反转** | 第五章揭露B的真面目时，读者才意识到**一直在被骗** |

### B视角的写作技巧

- B视角中，B表现得很关心A的调查进展
- B提供的"线索"实际上是**误导性信息**
- B的内心独白要设计成表面关心、实则警惕的双重含义
- 读者在B视角中会认为B是好人，直到最终反转

## 七、诡计的局限性（凶手必须解释清楚）

### 必须回答的问题

| 问题 | 回答 |
|------|------|
| 凶手如何找到相似的替身？ | 通过家族积累的"资源"（地下渠道、人口贩卖网络） |
| 凶手的身份如何维持？ | 利用家族势力收买官员/警察，篡改档案 |
| 三百年的秘密为何没暴露？ | 每一代都只执行一次替换，且目标都是边缘人群（孤儿、外来者） |
| 井底藏的是什么？ | 被替换者的遗物、身份文件，以及"失败品"（替换失败后被杀害的替身） |

### 不能有的"作弊"

- ❌ 凶手有超自然能力
- ❌ 真相是靠"读心术"或"神仙指点"得知
- ✅ 所有真相都必须有**可追溯的证据链**
