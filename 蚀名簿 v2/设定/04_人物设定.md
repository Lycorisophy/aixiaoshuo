# 《蚀名簿》第二版·人物设定

> 版本：v2.1
> 更新日期：2026-04-02
> 核心：身份替换 + 家族犯罪
> 叙事：双视角（A 视角陈言 + B 视角言临）
> 角色：9 人（7 男 2 女）

## 一、双主角设定

### A 视角：陈言（沈远）

| 属性 | 内容 |
|------|------|
| **真名** | 沈远 |
| **化名** | 陈言 |
| **年龄** | 28 岁 |
| **职业** | 民俗文献整理者（市图书馆/档案馆） |
| **视角定位** | **A 视角**：记录者（华生医生） |
| **性格** | 沉默寡言，善于从文献中发现线索，执着 |
| **外貌特征** | 深色外套，衣领竖起，随身携带旧钢笔和笔记本 |

**背景故事：**
在某图书馆/档案馆工作，专门整理出土文献和民间文书。有一个哥哥叫沈近，在故事开始前已"失踪"。这是他介入此事的直接原因。

**能力：**
- 文献解读：能追溯文献链条，发现伪造与叠写
- 口述史整理：善于还原历史事件的真相
- 细节观察：能从细微处发现线索

**弱点：**
- 对"解释"的依赖（通过解释来抵御创伤）
- 过于执着，有时不顾危险
- 对言临有天然的信任（后期被背叛）

**成长弧线：**
- 开篇：为救哥哥而调查
- 中段：发现真相，被言临"背叛"
- 结尾：选择自己决定真相是否公开

**化名来源：**
"陈"取"陈述"之意，"言"即言语。意为"记录真相的人"。

---

### B 视角：言临（秦观）

| 属性 | 内容 |
|------|------|
| **真名** | 秦观 |
| **化名** | 言临 |
| **年龄** | 29 岁 |
| **职业** | 自称"记录者"（无固定职业） |
| **视角定位** | **B 视角**：反派之一（加害者也是被害者） |
| **性格** | 表面温和，内心挣扎，敏锐，善于伪装 |
| **外貌特征** | 总戴着一副旧手套，随身携带空白笔记本，说话时喜欢重复别人的话 |

**背景故事：**
秦氏家族第 4 代传人。从小被灌输"家族使命"——延续身份替换传统。但他内心抗拒，想打破这个诅咒。与陈言"偶遇"，实则是有意接近，想借陈言之手揭露真相，但又害怕家族报复。

**能力：**
- 敏锐的归纳能力
- 语言与符号直觉
- 能捕捉规则漏洞
- 擅长伪装和误导

**弱点：**
- 内心挣扎，优柔寡断
- 对家族有恐惧心理
- 对陈言有愧疚感

**成长弧线：**
- 开篇：监视陈言，提供误导信息
- 中段：内心挣扎加剧，开始真正帮助陈言
- 结尾：在关键时刻选择帮助陈言，然后消失

**化名来源：**
"言"取自言语，意为"记录者"；"临"意为"在场"。暗示他"在场见证"但不直接参与。

**B 视角写作要点：**

```
B 视角中：
1. 言临表现得很关心陈言的调查进展
2. 提供的"线索"实际上是误导性信息
3. 内心独白要设计成表面关心、实则警惕的双重含义
4. 读者在 B 视角中会认为他是好人，直到最终反转

示例内心独白：
"我得帮他找到真相。"（表面）
"但我不能让他找到得太快。"（实际）
"也许...这次真的可以结束。"（内心挣扎）
```

## 三、本传核心角色

### 本传女性：林晚照

| 属性 | 内容 |
|------|------|
| **姓名** | 林晚照 |
| **年龄** | 27 岁 |
| **职业** | 调查记者（市晚报社会新闻部） |
| **本传定位** | **失踪者家属**，为姐姐复仇 |
| **性格** | 执着、敏锐、不轻易相信人 |
| **外貌特征** | 短发，常穿深色风衣，随身携带录音笔和相机 |

**背景故事：**
姐姐林晨曦在三年前失踪，警方定性为"自愿离家"，但林晚照不相信。她成为调查记者，就是为了找出真相。她一直在暗中调查秦氏家族，但苦于没有证据。

**能力：**
- 调查采访：能接触到警方和档案馆接触不到的人
- 信息整合：能把碎片信息拼凑成完整故事
- 媒体资源：能发动舆论压力

**与主线的关系：**
- 第 12 节左右首次出现，采访"失踪案"
- 第 18 节与陈言合作，交换信息
- 第 26 节提供关键线索（姐姐的遗物）
- 第 35 节面临选择：发表报道 or 保护证人

**核心秘密：**
她手里有姐姐失踪前的最后一封信，信中提到"秦氏"和"名册"，但她一直不知道是什么意思。

**成长弧线：**
- 开篇：为姐姐复仇
- 中段：发现真相比想象更复杂
- 结尾：选择用报道揭露真相，但保护言临的身份

**与陈言的对照：**
| 维度 | 陈言 | 林晚照 |
|------|------|--------|
| **目标** | 救哥哥 | 为姐姐复仇 |
| **方法** | 文献调查 | 媒体曝光 |
| **结局选择** | 犹豫 | 坚定公开 |
| **情感驱动** | 亲情 | 亲情 + 正义感 |

**作用：**
- 提供"媒体视角"，补充陈言的"文献视角"
- 增加情感线（但不是恋爱，是姐妹情）
- 在结局选择上与陈言形成对照（她选择公开，陈言犹豫）

## 四、幕后反派：秦氏家族

### 家族设定

| 属性 | 内容 |
|------|------|
| **家族名** | 秦氏 |
| **起源** | 民国时期（约 1920s） |
| **传统** | 身份替换（约 25-30 年一次） |
| **目的** | 借用他人身份，积累财富和地位 |
| **手法** | 寻找外貌相似者，杀害后互换身份 |
| **传承** | 家族秘传，只有核心成员知道 |

### 家族成员

| 角色 | 身份 | 状态 |
|------|------|------|
| **秦观（言临）** | 第 4 代传人 | 想打破传统 |
| **秦父** | 第 3 代传人 | 幕后主使，在逃 |
| **秦叔** | 第 3 代传人（秦父之弟） | 协助者，在逃 |
| **秦祖** | 第 1 代传人 | 已故，创立传统 |

### 家族运作模式

```
第 1 代（秦祖）：创立传统，开始身份替换
       ↓
第 2 代（秦父辈）：扩大规模，建立信息网络
       ↓
第 3 代（秦父）：维持传统，控制纸翁等知情者
       ↓
第 4 代（秦观）：内心挣扎，想打破传统
```

## 八、叙事策略说明

### 双视角设计目的

1. **信息遮蔽**：B 视角掩盖真相，让读者无法预判下一步
2. **情感误导**：读者对 B 视角产生共情，误以为他是盟友
3. **反转冲击**：揭露 B 的真实身份时，情感冲击更强
4. **主题深化**：通过 B 视角展现"加害者也是被害者"的复杂人性

### 女性角色的叙事作用

| 角色 | 叙事作用 |
|------|----------|
| **林晚照** | 提供"媒体视角"，在结局选择上与陈言形成对照 |
| **谢知微** | 提供"情报视角"，串联多部小说的关键信息源 |

### 读者预期管理

| 阶段 | 读者对言临的认知 | 实际身份 |
|------|------------------|----------|
| 前期（第 01-10 节） | 陈言的朋友/帮手 | 秦氏家族后代，监视者 |
| 中期（第 11-25 节） | 内心挣扎的盟友 | 想打破传统但害怕报复 |
| 后期（第 26-35 节） | 真相揭露，被背叛 | 在关键时刻选择帮助陈言 |
| 结局（第 36-40 节） | 消失，生死不明 | 开放式 |

### B 视角章节分布

建议 B 视角章节：第 05、11、17、23、29 节（共 5 节，约 12.5%）

| 章节 | 视角 | 内容 | 误导点 |
|------|------|------|--------|
| 第 05 节 | B | 言临"偶遇"陈言 | 让读者以为是巧合 |
| 第 11 节 | B | 言临提供"线索" | 实际是误导信息 |
| 第 17 节 | B | 言临内心挣扎 | 让读者同情他 |
| 第 23 节 | B | 言临坦白身份 | 模糊他的真实立场 |
| 第 29 节 | B | 言临选择帮助 | 最终揭示他帮助陈言 |

## 九、人物命名规则

- **真名**：角色真实身份（沈远、秦观、顾清舟等）
- **化名**：取自职业、行为特征等（陈言、言临、云清子等）
- **化名与真名完全不同字**：避免读者提前猜出身份

### 命名含义

| 名字 | 含义 |
|------|------|
| 沈远 | "远"暗示他与真相的距离 |
| 陈言 | "陈述言语"，记录者 |
