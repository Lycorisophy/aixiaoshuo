## 一、双视角设计

### 视角分配：按章切换（ABABA 模式）

| 章节 | 视角 | 角色 | 说明 |
|------|------|------|------|
| **第一章：侵** | A | 陈言 | 开篇，建立主角视角，调查哥哥失踪 |
| **第二章：啮** | B | 言临 | 揭示言临的秘密和内心挣扎 |
| **第三章：穴** | A | 陈言 | 回到调查主线，发现真相线索 |
| **第四章：耗** | B | 言临 | 言临的动机揭露，最终选择 |
| **第五章：朽** | A | 陈言 | 调查收尾，面临选择，开放式结局 |

**设计目的：**
- A 视角（陈言）：读者代入点，调查者，"明线"
- B 视角（言临）：误导读者，内心挣扎，"暗线"
- 每章内部视角统一，章与章之间切换
- 读者在两个视角之间切换，逐渐发现言临的真实身份

**优势：**
- 每章内部叙事连贯，不频繁切换
- 读者在第一章代入陈言，第二章通过言临视角看到"另一面"
- 第三章回到陈言，读者已经知道言临有秘密，产生悬疑感
- 第四章言临视角揭露动机，读者产生共情
- 第五章回到陈言，面临最终选择

## 二、A 视角：陈言（沈远）

| 属性 | 内容 |
|------|------|
| **真名** | 沈远 |
| **笔名** | 陈言 |
| **年龄** | 28 岁 |
| **职业** | 志怪小说作家（兼职文献整理） |
| **经济状况** | 稿费勉强够房租，收入不稳定 |
| **视角定位** | **A 视角**：记录者（华生医生） |
| **性格** | 执着、敏感、善于观察，但有时过于依赖"解释" |
| **外貌特征** | 深色外套，衣领竖起，随身携带旧钢笔和笔记本 |

**背景故事：**
在某几本杂志上连载志怪短篇，稿费不高，最近灵感枯竭。为了找素材和赚零钱，偶尔去图书馆帮忙整理出土文献。有一个哥哥叫沈近，在故事开始前已"失踪"。这是他介入此事的直接原因。

**说话风格：**
- **句式**：中等长度，偶尔有长句（写作习惯）
- **语气**：内敛，带点文人气，喜欢用比喻
- **习惯用语**："说实话"、"怎么说呢"、"这个念头让我……"
- **内心独白**：频繁，经常自我质疑
- **对话特点**：问问题多，喜欢追问细节

**做事风格：**
- 遇到不懂的词会查到底（文献工作者的习惯）
- 写作时会反复修改，追求准确
- 对哥哥的事异常执着，有时不顾危险
- 习惯记录一切（随身带笔记本）
- 遇到压力时会躲到图书馆（舒适区）

**能力：**
- 文献解读：能追溯文献链条，发现伪造与叠写
- 口述史整理：善于还原历史事件的真相
- 细节观察：能从细微处发现线索
- 写作能力：能把碎片信息组织成连贯故事

**弱点：**
- 对"解释"的依赖（通过解释来抵御创伤）
- 过于执着，有时不顾危险
- 对言临有天然的信任（后期被背叛）
- 经济压力大，容易焦虑

**成长弧线：**
- 开篇：为救哥哥而调查，顺便找素材
- 中段：发现真相，被言临"背叛"
- 结尾：选择自己决定真相是否公开

**笔名来源：**
"陈"取"陈述"之意，"言"即言语。意为"记录真相的人"。

**写作提示（避免 OOC）：**
```
✓ 多用"我"的主观感受和心理活动
✓ 遇到不懂的词会查到底
✓ 说话带点文人气，喜欢用比喻
✓ 经常自我质疑，内心独白多
✓ 对哥哥的事异常执着

✗ 不要过于冷静理性（他不是侦探）
✗ 不要说话太简短（他有写作习惯）
✗ 不要轻易相信别人（除了言临）
```

## 三、B 视角：言临（秦观）

| 属性 | 内容 |
|------|------|
| **真名** | 秦观 |
| **化名** | 言临 |
| **年龄** | 29 岁 |
| **职业** | 自称"记录者"（无固定职业） |
| **视角定位** | **B 视角**：反派之一（加害者也是被害者） |
| **性格** | 表面温和，内心挣扎，敏锐，善于伪装 |
| **外貌特征** | 总戴着一副旧手套，随身携带空白笔记本，说话时喜欢重复别人的话 |

**背景故事：**
秦氏家族第 4 代传人。从小被灌输"家族使命"——延续身份替换传统。但他内心抗拒，想打破这个诅咒。与陈言"偶遇"，实则是有意接近，想借陈言之手揭露真相，但又害怕家族报复。

**说话风格：**
- **句式**：短句为主，简洁
- **语气**：表面温和，实际警惕
- **习惯用语**："路过"、"我比你熟"、"放心"
- **特殊习惯**：用写字代替说话（带空白笔记本）
- **对话特点**：问什么答什么，从不主动透露信息
- **内心独白**：双重含义（表面关心 vs 实际警惕）

**做事风格：**
- 行动前先观察，不轻易表态
- 知道很多秘密，但只说该说的
- 做事有条理，计划周密
- 习惯用写字代替说话（原因未知，伏笔）
- 对陈言有愧疚感，但保持距离

**能力：**
- 敏锐的归纳能力
- 语言与符号直觉
- 能捕捉规则漏洞
- 擅长伪装和误导

**弱点：**
- 内心挣扎，优柔寡断
- 对家族有恐惧心理
- 对陈言有愧疚感

**成长弧线：**
- 开篇：监视陈言，提供误导信息
- 中段：内心挣扎加剧，开始真正帮助陈言
- 结尾：在关键时刻选择帮助陈言，然后消失

**化名来源：**
"言"取自言语，意为"记录者"；"临"意为"在场"。暗示他"在场见证"但不直接参与。

**B 视角写作要点：**
```
B 视角中：
1. 言临表现得很关心陈言的调查进展
2. 提供的"线索"实际上是误导性信息
3. 内心独白要设计成表面关心、实则警惕的双重含义
4. 读者在 B 视角中会认为他是好人，直到最终反转

示例内心独白：
"我得帮他找到真相。"（表面）
"但我不能让他找到得太快。"（实际）
"也许...这次真的可以结束。"（内心挣扎）
```

**写作提示（避免 OOC）：**
```
✓ 说话简短，从不多说
✓ 用写字代替说话（带空白笔记本）
✓ 表面温和，实际警惕
✓ 内心独白有双重含义
✓ 对陈言有愧疚感但不表露

✗ 不要过于热情或话多
✗ 不要主动透露信息
✗ 不要情绪化
```

## 十、叙事策略说明

### 双视角切换设计（ABABA 模式）

| 方面 | 设计 |
