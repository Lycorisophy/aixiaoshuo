# 《蚀名簿》第二版·理论框架

> 版本：v2.0
> 日期：2026-04-02
> 核心：身份替换 + 家族犯罪
> 类型：推理悬疑（非玄幻）

---

## 一、核心框架：名册的隐喻

### 名册的三重含义

```
名册 = 犯罪记录 + 家族秘传 + 破案关键
          ↓              ↓            ↓
     记录被害者      秦氏家族      揭露真相
     身份信息        百年传统      的证据
```

### "失名"的四个层次

| 层次 | 内容 | 实际含义 |
|------|------|----------|
| 第一层 | 名字消失 | 身份被替换，社会记录被篡改 |
| 第二层 | 关系断裂 | 被害者的社会关系被"替身"继承 |
| 第三层 | 记忆模糊 | 人们对被害者的记忆逐渐消失 |
| 第四层 | 真相掩盖 | 犯罪被包装成"妖怪传说" |

**核心隐喻：** "失名"不是玄幻现象，而是**人为犯罪的结果**。

## 二、犯罪手法：身份替换

### 核心诡计

**身份替换手法：**

```
1. 寻找目标 → 2. 杀害目标 → 3. 获取身份文件 
    → 4. 互换身份 → 5. 记录名册 → 6. 销毁痕迹
```

### 秦氏家族的运作模式

| 步骤 | 手法 | 说明 |
|------|------|------|
| 第一步 | 寻找外貌相似者 | 专门找外来者、孤儿、边缘人群 |
| 第二步 | 杀害目标 | 获取其身份文件（户籍、证件） |
| 第三步 | 互换身份 | 用目标的身份生活，销毁自己的痕迹 |
| 第四步 | 记录名册 | 在名册上记录这次"替换"（作为家族秘传） |
| 第五步 | 散布谣言 | "井底有妖怪吃名字"，掩盖犯罪 |
| 第六步 | 等待时机 | 约 25-30 年后，继续下一轮替换 |

### 为什么能维持百年？

| 原因 | 说明 |
|------|------|
| **每一代只执行一次** | 降低暴露风险 |
| **目标都是边缘人群** | 失踪后不易引起关注 |
| **家族控制信息网络** | 纸翁等知情者帮助掩盖 |
| **收买官员/警察** | 篡改档案、压案不查 |
| **妖怪传说作为烟雾弹** | 人们归因于超自然，忽略人为犯罪 |

## 三、叙事结构：双视角设计

### A 视角（陈言）vs B 视角（言临）

| 视角 | 角色 | 作用 | 写作要点 |
|------|------|------|----------|
| **A 视角** | 陈言 | 读者代入点，调查者 | 真实记录，但信息有限 |
| **B 视角** | 言临 | 误导读者，内心挣扎 | 表面帮助，实际监视；内心独白有双重含义 |

### B 视角的"不可靠叙事"

**设计原则：**

```
B 视角中：
1. 言临表现得很关心陈言的调查进展
2. 提供的"线索"实际上是误导性信息
3. 内心独白要设计成表面关心、实则警惕的双重含义
4. 读者在 B 视角中会认为他是好人，直到最终反转

示例内心独白：
"我得帮他找到真相。"（表面）
"但我不能让他找到得太快。"（实际）
"也许...这次真的可以结束。"（内心挣扎）
```

### 视角分布

| 幕名 | A 视角 | B 视角 | 说明 |
|------|--------|--------|------|
| 第一幕（侵） | 90% | 10% | B 视角仅第 05 节 |
| 第二幕（啮） | 70% | 30% | B 视角第 11 节 |
| 第三幕（穴） | 50% | 50% | B 视角第 17、23 节 |
| 第四幕（耗） | 60% | 40% | B 视角第 29 节 |
| 第五幕（朽） | 80% | 20% | B 视角第 36 节 |

## 四、主题设计

### 核心主题

| 主题 | 内容 | 小说中的体现 |
|------|------|--------------|
| **身份与自我** | 什么是真实的"我"？ | 身份被替换后，"我"还是"我"吗？ |
| **家族罪孽与个人选择** | 后代是否应为祖辈罪行负责？ | 言临想打破家族传统 |
| **真相与正义** | 公开真相就是正义吗？ | 陈言面临选择：公开 or 保护 |
| **谣言与人心** | 谣言如何掩盖真相？ | "妖怪传说"掩盖人为犯罪 |

### "妖怪传说"的社会心理学解释

| 层面 | 内容 |
|------|------|
| **传播动机** | 秦氏家族故意散布谣言，掩盖犯罪 |
| **传播条件** | 人们倾向于相信超自然解释，忽略人为犯罪 |
| **传播效果** | 失踪案被归因于"妖怪"，无人深入调查 |
| **破除方式** | 用证据链揭露真相，让人们意识到是人为犯罪 |

**核心观点：** 妖怪不是真实存在的，而是**人心制造的烟雾弹**。

## 五、证据链设计

### 读者可验证的线索

```
1. 失踪者外貌相似 
   → 2. 名册上一对名字（真/假）
   → 3. 言临的回避行为（多次出现）
   → 4. 户籍档案涂改痕迹
   → 5. 井底藏的身份文件
   → 6. 秦氏家族秘传记录
```

### 线索分布

| 线索 | 第一幕 | 第二幕 | 第三幕 | 第四幕 | 第五幕 |
|------|--------|--------|--------|--------|--------|
| 失踪者外貌相似 | 暗示 | 暗示 | 证实 | 详细 | 收束 |
| 名册上一对名字 | - | 发现 | 分析 | 详细 | 收束 |
| 言临的回避行为 | - | 出现 | 频繁 | 解释 | 收束 |
| 户籍涂改痕迹 | 暗示 | 发现 | 分析 | 详细 | 收束 |
| 井底身份文件 | - | 发现 | - | 详细 | 收束 |
| 秦氏家族记录 | - | - | 暗示 | 发现 | 收束 |

**设计原则：** 每个线索都应该让读者能够**自行推理验证**，而不是靠角色口述揭示真相。

## 六、人物动机设计

### 核心人物动机

| 人物 | 表面动机 | 真实动机 | 成长弧线 |
|------|----------|----------|----------|
| **陈言** | 救哥哥 | 揭露真相 | 从"救哥哥"到"选择是否公开真相" |
| **言临** | 帮助陈言 | 想打破家族传统 | 从"监视者"到"帮助者" |
| **顾清舟** | 调查真相 | 为家族复仇 | 从"旁观者"到"协助者" |
| **林晚照** | 为姐姐复仇 | 揭露犯罪 | 从"复仇"到"正义" |
| **谢知微** | 卖情报 | 等"对的人" | 从"中立"到"站队" |
| **秦父/秦叔** | 维持传统 | 积累财富地位 | 反派，在逃 |

### 言临的复杂动机

**言临是"加害者也是被害者"：**

| 层面 | 内容 |
|------|------|
| **加害者** | 他是秦氏家族后代，参与监视陈言 |
| **被害者** | 他从小被灌输"家族使命"，内心抗拒 |
| **挣扎** | 想打破传统，但害怕家族报复 |
| **选择** | 最终选择帮助陈言，然后消失 |

## 七、开放式结局设计

### 结局要点

| 元素 | 设计 |
|------|------|
| **沈近的命运** | 找到，但状态不明（可能失忆/受伤） |
| **秦氏家族的结局** | 部分被揭露，但秦父/秦叔在逃 |
| **言临的选择** | 帮助陈言后消失，生死不明 |
| **真相是否公开** | 不明确说，留给读者想象 |

### 最后一幕设计

```
陈言站在档案馆门口，手里拿着完整的证据链。

手机响了，是记者："沈先生，您准备好公开了吗？"

陈言看向远处，言临消失的方向。

"我……"

画面定格，不给出明确答案。
```

**设计意图：**
- 不明确说是否公开真相
- 让读者自己判断什么是"正确"的选择
- 余韵悠长，引发思考

## 九、创作原则

### 1. 可验证性原则

所有真相都必须有**可追溯的证据链**，不能靠"神仙指点"或"读心术"。

### 2. 合理性原则

犯罪手法必须符合逻辑，不能有"作弊"：
- ❌ 凶手有超自然能力
- ❌ 真相是靠"托梦"得知
- ✅ 所有真相都必须有证据支持

### 3. 公平性原则

读者应该有机会**自行推理**出真相：
- 所有线索都要提前铺设
- 不能隐藏关键信息
- 不能让读者觉得"被骗"

### 4. 人性复杂原则

人物不能是非黑即白：
- 言临是"加害者也是被害者"
- 纸翁是"被迫参与者"
- 陈言面临"公开 or 保护"的道德困境
