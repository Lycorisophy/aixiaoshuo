# 《蚀名簿》路人读者反馈（按你给的清单）

> 代入：我就是那种“随手翻几页”的人，扫着看、没耐心、段落一长就想跳。

## 1. 第一印象（最重要）

### 开篇第一段吸引我了吗？
- **严格说，第一眼看到的是开头那首四句诗（雨落檐前铅色沉…）**：我会把它当“装饰/题头”，**不会被它吸引**，甚至有一点“啊又来一段文艺开场”的疲劳感。
- **真正抓住我的是后面第一段叙述（“那场雨从三月末一直下到四月初…”）**。它很快把氛围压住了，而且比较生活化，不是硬拽设定。
- **决定性钩子在第 27–31 行附近**：
  - “我哥失踪七天”这句很直接。
  - 接着字条 + “蚀名”这个陌生词 + 三天后收到写着“沈近”的老纸片，**悬念堆得很有效**。

### 读第一页时，我想继续吗？
- **会继续。**因为第一页就把“哥哥失踪 + 神秘词条蚀名 + 老纸新字 + 疑似本人笔迹”连环抛出来。
- 但我也会产生一个很路人的念头：**“快点进主线吧，别一直下雨写味道写青石板。”**如果后面还连续这么铺陈，我会开始滑手机。

## 2. 阅读阻力

### 哪些地方让我想跳过？
1. **“氛围描写偏密”**：雨、青石板、旧纸霉味、灯泡银光……你写得不差，但我这种扫读型会觉得**信息重复**，会跳读。
2. **“句式重复（尤其后半段）”**：
   - 我抽样看到中后期大量“雨还在下”“这几个字在……回荡，像是某种审判/诅咒”“陈言感觉某种东西在胸腔里炸开…”
   - 还有很多“某个……他可能不想面对的……东西/事实/真相”这种省略号节奏。
   - 这种写法一两次有效，**多了会让我麻木**，变成“嗯嗯知道你在营造宿命感”，然后我就开始快进。
3. **人名/身份切换带来的小晕**（但不是致命）：
   - 前面主要是：陈言、沈近、顾清舟、纸翁、守碑人。
   - 后面又出现：林晚照、周守成、言临、秦观、沈远……
   - 对认真读者这可能是乐趣，但我这种普通读者会出现“等等这个是谁来着”的瞬间。

### 如果只能删掉一段，我删哪段？
- **我会删掉每节开头那首四句诗**（或者至少前几节删/缩）。
  - 理由很简单：我扫读时它不提供剧情信息，反而打断节奏。
- 如果你坚持要留“章回体气质”，那我会选择另一个：**中后期连续出现的“雨还在下 + 审判/诅咒 + 胸腔炸开 + 某种……省略号”那类段落，至少合并/减半**。

## 3. 兴趣点

### 我从哪里开始“有点兴趣了”？
- **第一个兴趣点**：字条里突然出现“蚀名”，然后主角查三天查不到（第 47–56 行附近）。这是“普通人能代入的困惑”。
- **第二个兴趣点（更强）**：包裹里那张老纸片，上面写着“沈近”，而且像沈近笔迹（第 57–76 行附近）。我会在这儿想：
  - “这是不是有人在搞他？”
  - “这是超自然还是人为犯罪？”
- **第三个兴趣点**：纸翁那句“你哥哥不是第一个”（第 209 行附近）。这是很经典但有效的升级。

### 哪句话/哪个情节让我觉得“有点意思”？
- “**纸是老的，字是新的**。”（你在第 02 节把它讲清楚了）
- “**名字是根，名字是魂。没有名字的人，就像树没了根**。”（纸翁那段）
- 以及“**名字被抹掉就真的消失**”这个设定——它很“都市传说 + 档案恐怖”，挺抓人。

### 我会怎么一句话安利给朋友？
- **“一个写小说的人找失踪哥哥，发现有人在古老名册里‘抹掉名字’，被抹掉的人会从现实里消失。”**

## 4. 理解门槛

### 我看懂发生了什么吗？
- **开头到第一章前几节：看懂了，而且很好懂。**
  - 目标明确：找哥哥。
  - 悬念明确：蚀名/蚀名簿。
  - 阵营也基本清楚：顾清舟像“懂行的同伴但不完全可信”，纸翁像“知道很多但有所隐瞒的老人”。
- **中后期（我抽样到第二章开头、第三章、第五章片段）：会开始有点晕**，主要原因不是世界观，而是写法：
  - 省略号断句 + 反复强调同一种情绪，会让我难以抓“这一段到底推进了什么信息”。

### “蚀名”等概念解释清楚吗？
- **“蚀名/蚀名簿”的核心含义在前两节其实解释得够用了**：名字被侵蚀/抹除 → 人在现实里被抹掉（失踪、身份被替换、记忆被动手脚）。
- 但如果站在“普通读者耐心有限”的角度，我会希望更早出现一句更直白的版本，比如：
  - “有人在一份旧名册上动手脚，名字没了，人就会从所有记录里消失。”
  这样我能更稳地跟着走。

### 信息量是刚好/太多/太少？
- **前期：刚好偏爽。**悬念密度够。
- **中后期：信息不一定多，但‘情绪与氛围’太多**，导致我体感上像在“听回声”，而不是看推进。

## 5. 最终的审判

### 书店随手翻到，我会买吗？
- **不确定（偏会）**。
  - 如果我只翻到第一章前两节：**我很可能会买/至少加入待读**。
  - 如果我刚好翻到你中后期那种“雨还在下 + 审判/诅咒 + 某种……省略号”密集段落：我会犹豫，觉得“有点拖/有点用力”。

### 如果不会买，是哪个点让我放下？
- **重复句式带来的疲劳**（不是节奏慢，而是“慢在重复强调同一种感觉”）。
- 以及“每节诗 + 分隔线”这种结构，如果我在碎片时间读，会觉得**被频繁打断**。

### 如果会买，我最想知道接下来发生什么？
- **到底是谁在“蚀名”，以及它是超自然机制还是一套非常具体的人为操作（档案/户籍/身份替换）。**
- **顾清舟到底站哪边**：他是“守规则的人”、还是“参与者”、还是“受害者”？
- **哥哥沈近到底变成了什么意义上的‘不是他了’**：是记忆被拔走、身份被换壳、还是被写进了簿子里。

- **“前几节真的挺好看，悬念抓得住人；但越往后越容易写成‘回声式的情绪咏叹’，普通人会疲劳。”**
