## 一、写作流程规范

### 每节写作前必须完成

**【三必读】**

1. **通读故事大纲**（设定/01_故事大纲.md）
   - 确认本节在五幕结构中的位置
   - 确认本节的核心事件
   - 确认本节需要铺设的线索
   - **确认本章的视角（A 陈言 / B 言临）**

2. **通读上一节全文**（chapters/第 XX 节 XXX.md）
   - 确保情节连贯
   - 确保人物性格一致（不 OOC）
   - 确保线索衔接正确
   - **确保视角一致（同一章内不切换视角）**

3. **通读上一章摘要**（摘要/第 X 章摘要.md，如果是新章第一节）
   - 了解上一章的情节进展
   - 了解已铺设的线索
   - 了解人物关系变化
   - **了解上一章的视角，准备切换**

**【写作前检查清单】**

对照人物设定（设定/04_人物设定.md）检查：

**A 视角（陈言）：**
- [ ] 是否用了"我"的主观感受？
- [ ] 是否有内心独白和自我质疑？
- [ ] 说话是否带点文人气，喜欢用比喻？
- [ ] 遇到不懂的词是否会查到底？
- [ ] 是否对哥哥的事异常执着？

**B 视角（言临）：**
- [ ] 说话是否简短，从不多说？
- [ ] 是否用写字代替说话？
- [ ] 表面温和，实际警惕？
- [ ] 内心独白有双重含义？
- [ ] 对陈言有愧疚感但不表露？

**其他角色：**
- [ ] 顾清舟：说话是否简短精准？是否平静但有距离感？
- [ ] 谢知微：说话是否冷静专业？是否转笔？
- [ ] 林晚照：说话是否直接犀利？是否按录音笔？
- [ ] 纸翁：说话是否欲言又止？是否叹气？
- [ ] 悟缘：说话是否只说关键词？是否停顿很久？

## 三、正文写作规范

### 格式规范

| 项目 | 规范 |
|------|------|
| **章节标题** | 第 X 节 [标题]，标题 2-4 字 |
| **定场诗** | 每章开篇和结尾各一首，7 言 8 句 |
| **字数** | 每节 5000-6000 字 |
| **叙事视角** | 双视角切换（A 陈言 / B 言临，按章切换） |
| **对话格式** | "对话内容" + 说话人 + 动作/神态 |
| **场景切换** | 用 `---` 分隔 |
| **本节结束** | `*（本节完）*` |

### 文风规范

| 视角 | 要求 |
|------|------|
| **A 视角（陈言）** | 第一人称"我"，带点文人气，喜欢用比喻，内心独白多 |
| **B 视角（言临）** | 第一人称"我"，表面温和，实际警惕，内心独白有双重含义 |

### 线索铺设

| 方面 | 要求 |
|------|------|
| **A 视角** | 自然铺设线索，陈言作为调查者发现线索 |
| **B 视角** | 言临作为知情者，内心挣扎，提供误导信息 |
| **悬念设置** | 每节结尾留悬念，每章结尾留大悬念 |
