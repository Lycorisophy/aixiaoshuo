# 《蚀名簿》第二版·核心设定框架

> 版本：v2.0
> 更新日期：2026-04-02
> 核心诡计：身份替换 + 家族犯罪
> 参考：京极夏彦《狂骨之梦》《魍魉之匣》

---

## 一、核心设定确认

### 五大核心决定

| 问题 | 选择 | 说明 |
|------|------|------|
| **时间跨度** | 一百年（3-4 代人） | 从民国时期开始，约 1920s-2020s |
| **井底设定** | 藏身份文件和遗物 | 不藏尸体，避免法医学漏洞 |
| **言临动机** | 主动想打破家族传统 | 内心挣扎，"加害者也是被害者" |
| **结局** | 开放式 | 不明确说是否公开真相 |
| **妖怪元素** | 作为"社会心理"保留 | 妖怪是人心制造的烟雾弹 |

## 二、世界观设定

### 双层结构

```
┌─────────────────────────────────────────────────┐
│                    表层（妖怪故事）              │
│  名册 = 记录"名字"的玄幻档案                     │
│  失名者 = 被妖怪吞噬的人                         │
│  井底 = 通向"名册意识"的神秘空间                 │
│  容器 = 吸收灵魂的玄幻存在                       │
└─────────────────────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────┐
│                    里层（犯罪真相）              │
│  名册 = 犯罪记录（被害者身份信息）               │
│  失名者 = 被同一人/家族陆续杀害的人              │
│  井底 = 藏匿身份文件和遗物的密室                 │
│  容器 = 真凶本人或帮凶（一直在场）               │
└─────────────────────────────────────────────────┘
```

### 妖怪元素的处理原则

| 场景 | 妖怪元素 | 真实解释 |
|------|----------|----------|
| 民间传说 | "井底有妖怪吃名字" | 家族散布的谣言，掩盖犯罪 |
| 失名现象 | "名字被吞噬" | 身份被替换，社会记录被篡改 |
| 井底异象 | "听到名字呼唤" | 心理暗示 + 回声效应 |
| 纸翁的"法术" | 民间秘术 | 家族控制的信息网络 |

**核心原则：** 妖怪是"社会心理层面的真实"，人们相信妖怪，所以忽略人为犯罪。

## 四、叙事结构

### 五幕结构（约 40 节）

```
第一幕：侵（第 01-08 节）
├─ 时间：沈近失踪后第 1-7 天
├─ 视角：A 视角 
├─ 内容：名册出土→沈近失踪→遇见纸翁→听说井底传说
├─ 线索：失踪者都是外来者、都有户籍涂改痕迹
└─ 结尾：陈言决定下井

第二幕：啮（第 09-16 节）
├─ 时间：沈近失踪后第 7-14 天
├─ 视角：B 视角 
├─ 内容：下井调查→发现名册秘密→言临提供"线索"
├─ 线索：名册上每对名字、言临的回避行为
└─ 结尾：发现沈近可能被"替换"

第三幕：穴（第 17-24 节）
├─ 时间：沈近失踪后第 14-21 天
├─ 视角：A 视角 
├─ 内容：调查失踪者→发现外貌相似→言临身份可疑
├─ 线索：旧照片中的"双胞胎"、户籍档案涂改
└─ 结尾：言临被发现是家族成员

第四幕：耗（第 25-32 节）
├─ 时间：沈近失踪后第 21-28 天
├─ 视角： B 视角
├─ 内容：揭露家族犯罪→言临的动机→井底真相
├─ 线索：井底藏的身份文件、家族秘传记录
└─ 结尾：找到沈近（可能还活着）

第五幕：朽（第 33-40 节）
├─ 时间：沈近失踪后第 28-35 天
├─ 视角：A 视角 
├─ 内容：救出沈近→追究幕后→余韵
├─ 线索：完整证据链收束
└─ 结尾：开放式（不明确说是否公开真相）
```

### 双视角设计

| 视角 | 角色 | 作用 | 写作要点 |
|------|------|------|----------|
| **A 视角** | 陈言 | 读者代入点，调查者 | 真实记录，但信息有限 |
| **B 视角** | 言临 | 误导读者，内心挣扎 | 表面帮助，实际监视；内心独白有双重含义 |

## 五、核心证据链

### 读者可验证的线索

```
1. 失踪者外貌相似 
   → 2. 名册上一对名字（真/假）
   → 3. 言临的回避行为（多次出现）
   → 4. 户籍档案涂改痕迹
   → 5. 井底藏的身份文件
   → 6. 秦氏家族秘传记录
```

### 核心线索设计

| 线索 | 前期暗示 | 后期验证 |
|------|----------|----------|
| **失踪者的外貌相似** | 多处暗示"总觉得他像谁" | 证实是替身关系 |
| **名册上的对应记录** | 每条记录都是一对名字 | 证实身份替换 |
| **言临的某个习惯** | 多次出现小动作（如摸手套） | 最终识别出真凶 |
| **井底的实际性质** | 传说通往妖怪巢穴 | 实际上是藏证据的地下室 |
| **失踪者的人际关系** | 都有与同一人的交集 | 证实言临与每个受害者都有关联 |

### 辅助线索

| 线索 | 作用 |
|------|------|
| 旧照片中的"双胞胎" | 暗示身份替换 |
| 户籍档案的涂改痕迹 | 暗示身份篡改 |
| 失踪者最后出现的地点 | 指向言临的活动区域 |
| 名册的纸张材质/字迹 | 指向民国时期的家族记录 |

## 六、犯罪手法设定

### 身份替换手法（百年传统）

| 步骤 | 手法 | 说明 |
|------|------|------|
| 第一步 | 寻找与自己外貌相似的目标 | 专门找外来者、孤儿、边缘人群 |
| 第二步 | 杀害目标，获取其身份文件 | 户籍、证件、照片等 |
| 第三步 | 用目标的身份生活 | 同时销毁自己的痕迹 |
| 第四步 | 在名册上记录这次"替换" | 作为家族秘传 |
| 第五步 | 等待时机，继续下一轮替换 | 约 25-30 年一次 |

### 为什么能维持百年？

| 原因 | 说明 |
|------|------|
| **每一代只执行一次** | 降低暴露风险 |
| **目标都是边缘人群** | 失踪后不易引起关注 |
| **家族控制信息网络** | 纸翁等知情者帮助掩盖 |
| **收买官员/警察** | 篡改档案、压案不查 |
| **妖怪传说作为烟雾弹** | 人们归因于超自然，忽略人为犯罪 |

## 七、言临的动机设计

### 核心动机：主动想打破家族传统

| 层面 | 内容 |
|------|------|
| **表面行为** | 帮助陈言调查，提供线索 |
| **实际目的** | 监视调查进展，确保家族秘密不暴露 |
| **内心挣扎** | 想打破传统，但害怕家族报复 |
| **最终选择** | 在关键时刻帮助陈言，但代价不明 |

### B 视角写作要点

```
B 视角中：
- B 表现得很关心 A 的调查进展
- B 提供的"线索"实际上是误导性信息
- B 的内心独白要设计成表面关心、实则警惕的双重含义
- 读者在 B 视角中会认为 B 是好人，直到最终反转

示例内心独白：
"我得帮他找到真相。"（表面）
"但我不能让他找到得太快。"（实际）
"也许...这次真的可以结束。"（内心挣扎）
```

## 八、开放式结局设计

### 结局要点

| 元素 | 设计 |
|------|------|
| **沈近的命运** | 找到，但状态不明（可能失忆/受伤） |
| **秦氏家族的结局** | 部分被揭露，但幕后仍在逃 |
| **言临的选择** | 帮助陈言后消失，生死不明 |
| **真相是否公开** | 不明确说，留给读者想象 |

### 最后一幕建议

```
陈言站在档案馆门口，手里拿着完整的证据链。

手机响了，是记者："沈先生，您准备好公开了吗？"

陈言看向远处，言临消失的方向。

"我……"

画面定格，不给出明确答案。
```

# 《蚀名簿》第二版·故事大纲

> 版本：v2.3
> 更新日期：2026-04-02
> 核心诡计：身份替换 + 家族犯罪
> 叙事：双视角切换（A 陈言 / B 言临，按章切换 ABABA）
> 结构：五幕（侵、啮、穴、耗、朽）

---

## 一、核心命题

这座老城正在发生一种"身份层面的灾害"：**人的名字、身份、社会关系**被系统性剥夺和替换。

所谓"失名"，并非传统意义的妖怪作祟，而是**秦氏家族百年犯罪传统**的产物：

- 每一代秦氏传人都会寻找与自己外貌相似的人
- 杀害目标，获取其身份文件
- 用目标的身份生活，同时销毁自己的痕迹
- 在名册上记录这次"替换"（作为家族秘传）

"失名者"不是消失了，而是**被另一个人取代了**。

---

## 二、世界观与规则

### 双层结构

| 层面 | 设定 | 真相 |
|------|------|------|
| **表层（妖怪故事）** | 名册记录"名字"，被神秘力量操控 | 名册是犯罪记录（被害者身份信息） |
| **里层（犯罪真相）** | 失名者被妖怪吞噬 | 失名者被秦氏家族陆续杀害 |
| **井底传说** | 通向"名册意识"的神秘空间 | 藏匿身份文件和遗物的密室 |
| **容器传说** | 吸收灵魂的玄幻存在 | 真凶本人或帮凶（一直在场） |

### 妖怪元素的处理

**核心原则：** 妖怪是"社会心理层面的真实"，人们相信妖怪，所以忽略人为犯罪。

| 场景 | 妖怪元素 | 真实解释 |
|------|----------|----------|
| 民间传说 | "井底有妖怪吃名字" | 秦氏家族散布的谣言，掩盖犯罪 |
| 失名现象 | "名字被吞噬" | 身份被替换，社会记录被篡改 |
| 井底异象 | "听到名字呼唤" | 心理暗示 + 回声效应 |
| 纸翁的"法术" | 民间秘术 | 家族控制的信息网络 |

## 三、主要角色与弧线

### 陈言（沈远）—— 第一人称"我"

| 属性 | 内容 |
|------|------|
| **身份** | 志怪小说作家（兼职文献整理），沈近之弟 |
| **目标** | 找到失踪的哥哥沈近，顺便找写作素材 |
| **弱点** | 对"解释"的依赖，过于执着，经济压力大 |
| **弧线** | 从"为救哥哥而调查"到"发现真相"到"选择是否公开" |

**说话风格：** 内敛，带点文人气，喜欢用比喻，经常自我质疑
**做事风格：** 遇到不懂的词会查到底，习惯记录一切，对哥哥的事异常执着

---

### 顾清舟（云清子）—— 男主角

| 属性 | 内容 |
|------|------|
| **身份** | 衔霜楼主人，独立调查者 |
| **目标** | 揭露秦氏家族的犯罪真相 |
| **弱点** | 知道太多，但不愿直接介入 |
| **弧线** | 从"旁观者"到"协助者" |

**说话风格：** 简短精准，用写字代替说话，平静但有距离感
**做事风格：** 行动前先观察，知道很多但不说破，对陈言有保护欲

**与陈言的关系：**
- 两年前因陈言的志怪小说惹上麻烦时认识
- 顾清舟帮陈言摆平了麻烦
- 陈言信任他，但他总保持距离

---

### 言临（秦观）—— 关键角色

| 属性 | 内容 |
|------|------|
| **身份** | 秦氏家族第 4 代传人，想打破传统 |
| **目标** | 借陈言之手揭露真相，但又害怕家族报复 |
| **弱点** | 内心挣扎，优柔寡断 |
| **弧线** | 从"监视陈言"到"真正帮助陈言"，最后消失 |

**说话风格：** 表面温和，内心挣扎，敏锐，善于伪装
**做事风格：** 擅长伪装和误导，内心愧疚，最终选择帮助陈言

**秘密：**
- 他是秦氏家族后代，但想打破传统
- 他监视陈言，但又想借陈言之手揭露真相

- 公开真相：正义得到伸张，但顾清舟可能被牵连

**林晚照的选择对照：**
- 她选择公开（记者的职业道德）
- 陈言犹豫（个人情感与正义的冲突）

# 《蚀名簿》第二版·人物设定

> 版本：v2.3
> 更新日期：2026-04-02
> 核心：身份替换 + 家族犯罪
> 叙事：双视角切换（A 陈言 / B 言临，ABABA 模式）
> 角色：9 人（7 男 2 女）

---

## 一、双视角设计

### 视角分配：按章切换（ABABA 模式）

| 章节 | 视角 | 角色 | 说明 |
|------|------|------|------|
| **第一章：侵** | A | 陈言 | 开篇，建立主角视角，调查哥哥失踪 |
| **第二章：啮** | B | 言临 | 揭示言临的秘密和内心挣扎 |
| **第三章：穴** | A | 陈言 | 回到调查主线，发现真相线索 |
| **第四章：耗** | B | 言临 | 言临的动机揭露，最终选择 |
| **第五章：朽** | A | 陈言 | 调查收尾，面临选择，开放式结局 |

**设计目的：**
- A 视角（陈言）：读者代入点，调查者，"明线"
- B 视角（言临）：误导读者，内心挣扎，"暗线"
- 每章内部视角统一，章与章之间切换
- 读者在两个视角之间切换，逐渐发现言临的真实身份

**优势：**
- 每章内部叙事连贯，不频繁切换
- 读者在第一章代入陈言，第二章通过言临视角看到"另一面"
- 第三章回到陈言，读者已经知道言临有秘密，产生悬疑感
- 第四章言临视角揭露动机，读者产生共情
- 第五章回到陈言，面临最终选择

## 二、A 视角：陈言（沈远）

| 属性 | 内容 |
|------|------|
| **真名** | 沈远 |
| **笔名** | 陈言 |
| **年龄** | 28 岁 |
| **职业** | 志怪小说作家（兼职文献整理） |
| **经济状况** | 稿费勉强够房租，收入不稳定 |
| **视角定位** | **A 视角**：记录者（华生医生） |
| **性格** | 执着、敏感、善于观察，但有时过于依赖"解释" |
| **外貌特征** | 深色外套，衣领竖起，随身携带旧钢笔和笔记本 |

**背景故事：**
在某几本杂志上连载志怪短篇，稿费不高，最近灵感枯竭。为了找素材和赚零钱，偶尔去图书馆帮忙整理出土文献。有一个哥哥叫沈近，在故事开始前已"失踪"。这是他介入此事的直接原因。

**说话风格：**
- **句式**：中等长度，偶尔有长句（写作习惯）
- **语气**：内敛，带点文人气，喜欢用比喻
- **习惯用语**："说实话"、"怎么说呢"、"这个念头让我……"
- **内心独白**：频繁，经常自我质疑
- **对话特点**：问问题多，喜欢追问细节

**做事风格：**
- 遇到不懂的词会查到底（文献工作者的习惯）
- 写作时会反复修改，追求准确
- 对哥哥的事异常执着，有时不顾危险
- 习惯记录一切（随身带笔记本）
- 遇到压力时会躲到图书馆（舒适区）

**能力：**
- 文献解读：能追溯文献链条，发现伪造与叠写
- 口述史整理：善于还原历史事件的真相
- 细节观察：能从细微处发现线索
- 写作能力：能把碎片信息组织成连贯故事

**弱点：**
- 对"解释"的依赖（通过解释来抵御创伤）
- 过于执着，有时不顾危险
- 对言临有天然的信任（后期被背叛）
- 经济压力大，容易焦虑

**成长弧线：**
- 开篇：为救哥哥而调查，顺便找素材
- 中段：发现真相，被言临"背叛"
- 结尾：选择自己决定真相是否公开

**笔名来源：**
"陈"取"陈述"之意，"言"即言语。意为"记录真相的人"。

**写作提示（避免 OOC）：**
```
✓ 多用"我"的主观感受和心理活动
✓ 遇到不懂的词会查到底
✓ 说话带点文人气，喜欢用比喻
✓ 经常自我质疑，内心独白多
✓ 对哥哥的事异常执着

✗ 不要过于冷静理性（他不是侦探）
✗ 不要说话太简短（他有写作习惯）
✗ 不要轻易相信别人（除了言临）
```

## 三、B 视角：言临（秦观）

| 属性 | 内容 |
|------|------|
| **真名** | 秦观 |
| **化名** | 言临 |

| **视角定位** | **B 视角**：反派之一（加害者也是被害者） |
| **性格** | 表面温和，内心挣扎，敏锐，善于伪装 |

**背景故事：**
秦氏家族第 4 代传人。从小被灌输"家族使命"——延续身份替换传统。但他内心抗拒，想打破这个诅咒。与陈言"偶遇"，实则是有意接近，想借陈言之手揭露真相，但又害怕家族报复。

**说话风格：**
- **句式**：短句为主，简洁
- **语气**：表面温和，实际警惕
- **习惯用语**："路过"、"我比你熟"、"放心"
- **特殊习惯**：用写字代替说话（带空白笔记本）
- **对话特点**：问什么答什么，从不主动透露信息
- **内心独白**：双重含义（表面关心 vs 实际警惕）

**做事风格：**
- 行动前先观察，不轻易表态
- 知道很多秘密，但只说该说的
- 做事有条理，计划周密
- 习惯用写字代替说话（原因未知，伏笔）
- 对陈言有愧疚感，但保持距离

**能力：**
- 敏锐的归纳能力
- 语言与符号直觉
- 能捕捉规则漏洞
- 擅长伪装和误导

**弱点：**
- 内心挣扎，优柔寡断
- 对家族有恐惧心理
- 对陈言有愧疚感

**成长弧线：**
- 开篇：监视陈言，提供误导信息
- 中段：内心挣扎加剧，开始真正帮助陈言
- 结尾：在关键时刻选择帮助陈言，然后消失

**化名来源：**
"言"取自言语，意为"记录者"；"临"意为"在场"。暗示他"在场见证"但不直接参与。

**B 视角写作要点：**
```
B 视角中：
1. 言临表现得很关心陈言的调查进展
2. 提供的"线索"实际上是误导性信息
3. 内心独白要设计成表面关心、实则警惕的双重含义
4. 读者在 B 视角中会认为他是好人，直到最终反转

示例内心独白：
"我得帮他找到真相。"（表面）
"但我不能让他找到得太快。"（实际）
"也许...这次真的可以结束。"（内心挣扎）
```

**写作提示（避免 OOC）：**
```
✓ 说话简短，从不多说
✓ 用写字代替说话（带空白笔记本）
✓ 表面温和，实际警惕
✓ 内心独白有双重含义
✓ 对陈言有愧疚感但不表露

✗ 不要过于热情或话多
✗ 不要主动透露信息
✗ 不要情绪化
```

## 十、叙事策略说明

### 双视角切换设计（ABABA 模式）

| 方面 | 设计 |
|------|------|
| **视角分配** | A（陈言）→ B（言临）→ A → B → A → ... |
| **A 视角作用** | 读者代入点，调查者，"明线" |
| **B 视角作用** | 误导读者，内心挣扎，"暗线" |
| **信息遮蔽** | B 视角掩盖真相，让读者无法预判下一步 |
| **情感误导** | 读者对 B 视角产生共情，误以为他是盟友 |
| **反转冲击** | 揭露 B 的真实身份时，情感冲击更强 |

### 女性角色的叙事作用

| 角色 | 叙事作用 |
|------|----------|
| **林晚照** | 提供"媒体视角"，在结局选择上与陈言形成对照 |
| **谢知微** | 提供"情报视角"，串联多部小说的关键信息源 |

### 读者预期管理

| 阶段 | 读者对言临的认知 | 实际身份 |
|------|------------------|----------|
| 前期（第 01-10 节） | 陈言的朋友/帮手 | 秦氏家族后代，监视者 |
| 中期（第 11-25 节） | 内心挣扎的盟友 | 想打破传统但害怕报复 |
| 后期（第 26-35 节） | 真相揭露，被背叛 | 在关键时刻选择帮助陈言 |
| 结局（第 36-40 节） | 消失，生死不明 | 开放式 |

## 写作规范补充

### 定场诗使用规则

1. **位置**：每部开头第一页放开篇定场诗，结尾最后一页放结尾定场诗
2. **格式**：标题四字居中，诗文八句各占一行
3. **字号**：正文标题的 1.2-1.5 倍，略大于正文
4. **排版**：前后各空一行，与正文分隔

### 时代背景

- **故事时间**：现代（约 2020s），回溯至民国时期（约 1920s）
- **故事地点**：江南某老城
- **禁忌事项**：
  - 不谈论政治和国策
  - 不谈论重大历史事件
- **处理方式**：故事聚焦于家族犯罪、身份替换，保持推理悬疑氛围

### 去玄幻化原则

1. **删除妖怪名称**：纸羽、灯下人、契虫等全部删除或改为比喻
2. **删除宗教术语**：涅槃、轮回等改为世俗化表达
3. **强调人为犯罪**：所有"失名"现象都是人为犯罪，不是超自然
4. **保留悬疑氛围**：去掉玄幻但不去掉悬疑感

# 《蚀名簿》第二版·理论框架

> 版本：v2.0
> 日期：2026-04-02
> 核心：身份替换 + 家族犯罪
> 类型：推理悬疑（非玄幻）

---

## 一、核心框架：名册的隐喻

### 名册的三重含义

```
名册 = 犯罪记录 + 家族秘传 + 破案关键
          ↓              ↓            ↓
     记录被害者      秦氏家族      揭露真相
     身份信息        百年传统      的证据
```

### "失名"的四个层次

| 层次 | 内容 | 实际含义 |
|------|------|----------|
| 第一层 | 名字消失 | 身份被替换，社会记录被篡改 |
| 第二层 | 关系断裂 | 被害者的社会关系被"替身"继承 |
| 第三层 | 记忆模糊 | 人们对被害者的记忆逐渐消失 |
| 第四层 | 真相掩盖 | 犯罪被包装成"妖怪传说" |

**核心隐喻：** "失名"不是玄幻现象，而是**人为犯罪的结果**。

---

## 二、犯罪手法：身份替换

### 核心诡计

**身份替换手法：**

```
1. 寻找目标 → 2. 杀害目标 → 3. 获取身份文件 
    → 4. 互换身份 → 5. 记录名册 → 6. 销毁痕迹
```

### 秦氏家族的运作模式

| 步骤 | 手法 | 说明 |
|------|------|------|
| 第一步 | 寻找外貌相似者 | 专门找外来者、孤儿、边缘人群 |
| 第二步 | 杀害目标 | 获取其身份文件（户籍、证件） |
| 第三步 | 互换身份 | 用目标的身份生活，销毁自己的痕迹 |
| 第四步 | 记录名册 | 在名册上记录这次"替换"（作为家族秘传） |
| 第五步 | 散布谣言 | "井底有妖怪吃名字"，掩盖犯罪 |
| 第六步 | 等待时机 | 约 25-30 年后，继续下一轮替换 |

### 为什么能维持百年？

| 原因 | 说明 |
|------|------|
| **每一代只执行一次** | 降低暴露风险 |
| **目标都是边缘人群** | 失踪后不易引起关注 |
| **家族控制信息网络** | 纸翁等知情者帮助掩盖 |
| **收买官员/警察** | 篡改档案、压案不查 |
| **妖怪传说作为烟雾弹** | 人们归因于超自然，忽略人为犯罪 |

## 三、叙事结构：双视角设计

### A 视角（陈言）vs B 视角（言临）

| 视角 | 角色 | 作用 | 写作要点 |
|------|------|------|----------|
| **A 视角** | 陈言 | 读者代入点，调查者 | 真实记录，但信息有限 |
| **B 视角** | 言临 | 误导读者，内心挣扎 | 表面帮助，实际监视；内心独白有双重含义 |

### B 视角的"不可靠叙事"

**设计原则：**

```
B 视角中：
1. 言临表现得很关心陈言的调查进展
2. 提供的"线索"实际上是误导性信息
3. 内心独白要设计成表面关心、实则警惕的双重含义
4. 读者在 B 视角中会认为他是好人，直到最终反转

示例内心独白：
"我得帮他找到真相。"（表面）
"但我不能让他找到得太快。"（实际）
"也许...这次真的可以结束。"（内心挣扎）
```

- ❌ 凶手有超自然能力
- ❌ 真相是靠"托梦"得知
- ✅ 所有真相都必须有证据支持

### 3. 公平性原则

- 所有线索都要提前铺设
- 不能隐藏关键信息

人物不能是非黑即白：
- 言临是"加害者也是被害者"
- 纸翁是"被迫参与者"

## 三、主诡计：三百年的身份替换

### 核心手法

凶手专门寻找**与自己外貌相似**的人，杀人后**互换身份**。

| 步骤 | 手法 |
|------|------|
| 第一步 | 寻找与自己外貌相似的目标 |
| 第二步 | 杀害目标，获取其身份文件（户籍、证件） |
| 第三步 | 用目标的身份生活，同时销毁自己的痕迹 |
| 第四步 | 在名册上记录这次"替换"（作为家族秘传） |
| 第五步 | 等待时机，继续下一轮替换 |

### 目的

- 凶手借用被害者的身份生活
- 抹去自己的存在痕迹
- 家族血脉通过"替换他人"得以延续
- 财富和地位通过"继承他人身份"不断积累

### "失名"现象的解释

被害者原来的名字/身份从社会上消失。人们记得的只是凶手的替身。当真相揭开，人们才意识到：**失踪者不是"消失"了，而是被另一个人"取代"了**。

| **第二部（啮）** | 主角调查，发现名册的秘密 | 建立推理框架：名册=受害者名单 |
| **第三部（穴）** | 发现受害者都曾被"替换"，凶手一直在身边 | 身份诡计揭示：谁是凶手？ |
| **第四部（耗）** | 揭露凶手身份和动机 | 动机揭示：三百年的"身份替换"传统 |
| **第五部（朽）** | 收网，救出可能的幸存者，追究幕后 | 完整真相+余韵 |

## 五、可验证的证据链

### 线索设计原则

每个线索都应该让读者能够**自行推理验证**，而不是靠角色口述揭示真相。

### 核心线索

| **名册上的对应记录** | 每条记录都是一对名字（真/假） | 证实身份替换 |
| **凶手的某个习惯** | 多次出现凶手的小动作 | 最终识别出真凶 |
| **井底的实际性质** | 传说通往妖怪巢穴 | 实际上是藏匿证据的地下室 |
| **失踪者的人际关系** | 都有与同一人的交集 | 证实凶手与每个受害者都有关联 |

## 一、证据链设计原则

### 1. 公平性原则

所有关键线索必须**提前铺设**，让读者有机会自行推理出真相：
- ❌ 不能隐藏关键信息
- ❌ 不能让"神仙指点"揭示真相
- ✅ 所有线索都要在正文中出现
- ✅ 读者应该能在真相揭露前猜到

### 2. 可验证性原则

每个线索都必须有**物理证据**支撑：
- ❌ 不能靠"托梦"或"直觉"
- ✅ 必须有文件、照片、物证等
- ✅ 证据之间要能相互印证

### 3. 逻辑性原则

证据链必须符合逻辑，不能有跳跃：
- ❌ 不能"因为 A 所以 Z"（跳过 BCD）
- ✅ 必须是"A→B→C→D→...→Z"的完整链条

### 4. 多重印证原则

关键事实必须有**多个证据**印证：
- 单一证据不可靠
- 至少 2-3 个证据指向同一结论

## 六、线索铺设技巧

### 1. "三次提及"原则

关键线索至少要提及**三次**，读者才能记住：

| 线索 | 第一次 | 第二次 | 第三次 |
|------|--------|--------|--------|
| **言临的手套** | 第 05 节（B 视角，言临戴手套） | 第 21 节（陈言注意到手套） | 第 29 节（言临脱下手套） |
| **户籍涂改** | 第 07 节（陈言发现涂改） | 第 19 节（发现百年涂改） | 第 33 节（作为证据提交） |
| **名册上一对名字** | 第 04 节（陈言看到沈近名字旁有另一个名字） | 第 10 节（发现规律） | 第 22 节（证实是身份替换） |

### 2. "先暗示后证实"原则

先暗示，让读者产生猜测，然后再证实：

| 线索 | 暗示章节 | 证实章节 |
|------|----------|----------|
| **言临是秦氏家族** | 第 05、11 节（B 视角中言临的异常） | 第 23 节（言临坦白） |
| **井底藏证据** | 第 03 节（井口封印） | 第 09 节（发现身份文件） |
| **秦氏家族百年犯罪** | 第 06 节（纸翁提到"秦氏"） | 第 25 节（完整犯罪史） |

### 3. "多重印证"原则

关键事实必须有多个证据印证：

| 事实 | 证据 1 | 证据 2 | 证据 3 |
|------|--------|--------|--------|
| **身份替换存在** | 名册上一对名字 | 户籍涂改痕迹 | 井底身份文件 |
| **言临是秦氏家族** | 名册上秦观名字 | 手套上的标记 | 言临自己的坦白 |
| **百年犯罪传统** | 户籍涂改跨越百年 | 谢知微的账本 | 秦氏家族秘传记录 |

## 十、读者推理引导

### 读者应该在什么时候猜到真相？

| 真相 | 读者应该猜到的章节 | 线索依据 |
|------|-------------------|----------|
| **名册是犯罪记录** | 第 10 节 | 名册上一对名字 |
| **言临有问题** | 第 11-15 节 | 言临的回避行为、B 视角内心独白 |
| **身份替换手法** | 第 18-20 节 | 旧照片、户籍涂改 |
| **言临是秦氏家族** | 第 21-22 节 | 言临被当面对质 |
| **秦氏家族百年犯罪** | 第 25 节 | 完整犯罪史揭露 |

### 如何避免读者"被骗感"？

1. **所有线索都要提前铺设**：不能突然出现关键证据
2. **B 视角要诚实**：言临的内心独白可以隐瞒，但不能说谎
3. **真相要有逻辑**：不能靠"巧合"或"神仙指点"
4. **给读者思考时间**：关键线索出现后，要有缓冲章节
