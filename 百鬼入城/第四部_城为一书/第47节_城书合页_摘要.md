# 第47节 城书合页·摘要

## 核心事件

- 沈述在网上发起"给城市起名字"活动
- 几万人参与——给出了几万名字
- 最常见的名字："家"（5000次）、"归"（3000次）、"城"（2000次）
- 城市不知道怎么选——它从来没有"选择"过
- 方菲的提议：不需要选一个名字——可以用所有的名字
- 沈述的领悟：把所有人的名字合在一起——变成"完整的名字"
- 城市变成了一本书——"城书合页"

## 城市的名字

### 候选名字

| 名字 | 出现次数 |
|------|----------|
| 家 | 5000 |
| 归 | 3000 |
| 城 | 2000 |
| 老城 | 1000 |
| 新城 | 800 |

### 最终答案

- 不是选一个——是用所有
- 所有人给的所有名字 = 城市的完整名字
- 这本书 = 所有人一起写的书

## "城书合页"的含义

- 城市 = 一本书
- 每页 = 一个人的名字
- 每个人 = 一行字
- 这本书没有结尾——永远有人写新的故事

## 结局的意义

- "不结束"——只是"停下来"
- 沈述写完他这一章
- 下一章是读者的
- 这本书不属于任何一个人——属于所有人
