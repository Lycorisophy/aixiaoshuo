## 二、文档作用说明

| 文档 | 作用 |
|------|------|
| `00_项目说明.md` | 项目索引，说明文档结构和写作规范 |

### 每部文件夹内的文档

| 文档 | 作用 |
|------|------|
| `摘要.md` | 该部的整体摘要（800-1500字），概述本部的核心事件、转折、主题 |
| `第XX节_标题.md` | 正文内容，每节4000-8000字 |
| `第XX节_摘要.md` | 该节的内容摘要（300-500字），便于快速回顾和编辑审阅 |

## 三、写作规范

### 节摘要格式

每节完成后，需撰写摘要，格式如下：

```markdown
## 第X节「标题」摘要

**核心事件**：本节发生的最主要事件（1-2句）

**关键发现**：主角在这一节中发现了什么

**悬念埋设**：本节留下的悬念或伏笔

**角色状态**：主角/配角的情感和处境变化
```

### 部摘要格式

每部完成后，需撰写摘要，格式如下：

```markdown
## 第一部「部名」摘要

**本部核心事件**：（3-5句概述）

**主要转折**：
1. 转折点1
2. 转折点2

**百鬼显形**：本部出现的百鬼及作用

**主题深化**：本部涉及的主题思考

**为下一部铺垫**：
```
