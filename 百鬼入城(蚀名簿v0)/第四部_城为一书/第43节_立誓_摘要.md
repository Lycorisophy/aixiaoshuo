# 第43节 立誓·摘要

## 核心事件

- 沈述决定立一个誓——需要一个"北极星"作为支点
- 小时候的誓："永远不忘记母亲"——但他忘了
- 方菲的提醒：记忆不是你想留住就能留住的
- 核心领悟：誓不是关于"结果"的，是关于"过程"的
- 沈述立下"北极星誓"：我会永远尝试
- 方菲立下自己的誓：我会永远看着你

## 誓的重新定义

### 誓 vs 承诺

| | 誓 | 承诺 |
|--|-----|------|
| 语气 | "一定" | "尽量" |
| 性质 | 更重 | 较轻 |
| 做不到 | 等于骗自己 | 可能有遗憾 |

### 誓的本质

- 誓不是一个"状态"
- 誓是一个"动作"
- 是一个——一直在做的动作
- "我会永远尝试" = 一个一直在做的"做"

### 立誓的意义

- 誓 = 北极星
- 北极星不是某个东西
- 北极星是一个人
- 是一个你会一直看着的人
- 是一个会一直看着你的人

## 方菲的誓

- "我会永远看着你"
- 看着沈述尝试
- 看着沈述写
- 看着沈述不放弃
- "这是我自己的誓。和你无关。你不用遵守。"

## 哲学内涵

- **"做不到"vs"骗自己"**：
  - 骗自己 = 明明能做到，但不去做
  - 做不到 = 真的做不到
  - 区别：骗自己会后悔，做不到只是接受

- **简单的誓**：
  - 复杂的誓会忘记
  - 简单的誓会记得
  - "我会永远尝试"——简单，容易记住

## 人物状态

- 沈述：立下了北极星誓
- 方菲：立下了自己的誓——"我会永远看着你"
