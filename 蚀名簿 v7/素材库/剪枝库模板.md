# 剪枝库（模板）

> 使用方法：每条剪枝复制下面「条目模板」一节，填完后按日期或主题堆在本文件下方，或拆成多文件 `剪枝库_主题.md`。

## 条目模板

- **标题**：（四字或短语）
- **原出处**：（文件路径 + 原节号/段落大致位置）
- **内容摘要**：（三句话内，以后不必再打开母本也能想起写了什么）
- **废弃原因**：（设定冲突 / 节奏拖累 / 视角变更 / 因果不成立 / 其他）
- **是否可能番外或第二部回收**：（是 / 否 / 待定）
- **若回收，需要的补丁**：（人设或世界观的最低改动）

---

## 示例条目

- **标题**：旧版「顾陪同下井」整段
- **原出处**：《蚀名簿》正文_第08节_决意下井_v1.md 末段
- **内容摘要**：顾清舟绳位、陈言独降；手指停等伏笔。
- **废弃原因**：与现行设定「顾不下井、陈言+言临下井」冲突。
- **是否可能番外或第二部回收**：待定（可作 IF 线彩蛋）
- **若回收，需要的补丁**：标明平行宇宙或旧稿附录
