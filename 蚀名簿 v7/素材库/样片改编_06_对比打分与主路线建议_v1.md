# 《蚀名簿》样片对比打分与主路线建议（v1）

> 说明：本轮为 **v1 样片制作包评估**（脚本与生产可行性层），用于决定下一阶段主路线。

## 1) 同尺评分（10分制）

| 维度 | 动态漫画 | AI视频 | 说明 |
|---|---:|---:|---|
| 叙事可懂 | 9.0 | 8.2 | 动态漫画字幕与旁白更可控，信息更稳。 |
| 角色稳定 | 9.2 | 7.4 | AI视频有跳脸风险，尤其镜头 9-12。 |
| 时代可信 | 9.1 | 7.8 | 动态漫画更易压住“1986质感”；AI需反复回拉。 |
| 文本忠实 | 9.3 | 8.0 | 动态漫画可逐句贴文本；AI镜头容易偏题。 |
| 制作效率 | 8.1 | 7.6 | 首轮样片阶段，动态漫画返工成本更低。 |
| 总分 | **44.7 / 50** | **39.0 / 50** | 动态漫画领先。 |

## 2) 结论

- **建议主路线：A主/B辅**
  - **A（动态漫画）为主线连载形态**
  - **B（AI视频）为宣传切条与情绪强化补充**

## 3) 决策理由（精简）

1. 你这部文本依赖“词句钉子 + 情绪停顿”，动态漫画更能保真。  
2. 第一阶段最怕角色漂移和时代表征失真，动态漫画更稳。  
3. AI视频的镜头感确实更强，但首轮更适合作“爆点片段”而非主叙事承载。

## 4) 下一阶段建议（可直接执行）

- **动态漫画主线**：
  - 固定项目模板：`风格圣经 -> 分镜表 -> 动效参数 -> 字幕旁白`。
  - 以 90 秒为单位滚动迭代，先跑 3 支再提速。
- **AI视频辅线**：
  - 先只做 20-40 秒“高情绪镜头组”；
  - 建角色锚图库后再尝试完整 90 秒。
