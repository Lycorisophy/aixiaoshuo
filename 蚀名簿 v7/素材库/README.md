# 素材库

彻底重构时，**旧正文不丢、不覆盖母本**：把仍可用的段落拆成**颗粒**，用**对照表**挂到新大纲上；剪掉的枝节进**剪枝库**，以后番外或第二部可翻。

## 原则

1. **母本保留原位**：`正文_第××节_*.md`、`连载润色版/` 等不要当「草稿纸」改到面目全非；大改前可复制整包到 **`归档_只读/`**（已建目录，见 [`归档_只读/README.md`](归档_只读/README.md)；大文件可 gitignore）。
2. **新稿另起目录**：例如 `连载_v2/`，与旧稿并行，直到新结构定稿。
3. **只往本库放摘录与元数据**：环境、对话块、意象、器物描写等，剪贴到 `颗粒摘录/`，文件名建议：`YYYYMMDD_原节号_简述.md`（例：`20260405_08_井下绳与头灯.md`）。

## 本库内容

| 路径 | 用途 |
|------|------|
| `颗粒摘录/` | 按场景拆出的 md 摘录；**[`颗粒摘录/INDEX.md`](颗粒摘录/INDEX.md)** 为索引 |
| `新旧对照模板.md` | 空白模板 |
| [`新旧对照_进行中.md`](新旧对照_进行中.md) | **当前迁移表**（已挂 **04–40** v1；08–12 功能句较细，其余待大纲填实） |
| [`_tools/build_grain_digest.py`](_tools/build_grain_digest.py) | 从母本批量生成 `20260411_*_摘编.md`（默认跳过 08–12，避免覆盖手工细拆） |
| `剪枝库模板.md` | 空白模板 |
| [`剪枝库_进行中.md`](剪枝库_进行中.md) | **已登记剪枝**（顾绳独下、旧09主骨架等） |

## 最小工作流

1. 在新大纲上标好「新节功能」。
2. 扫旧稿：能嵌的段落 → 写入 `颗粒摘录/` 并在对照表里填**目标新节**。
3. 与因果链冲突的整段 → 剪枝库记一笔，不强行嵌。
4. 写新节时优先「从颗粒拼」，其次才从零写。

**建立状态（v1 母本）**：**第 04–40 节**均已入 [`颗粒摘录/INDEX.md`](颗粒摘录/INDEX.md)（**08–12** 为手工多文件细拆，**04–07、13–40** 为每节一摘编）。本目录下**无**第 01–03 节 `正文_*_v1.md`；另有 `*_样稿.md` 未纳入脚本，需时请手补。
