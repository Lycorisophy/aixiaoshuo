## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 34 节：舆论如潮（A 视角：陈言）

潮从墙缝先起来，起来不问谁允许。
标题如刀刀不血，血在名字背面滴。
E01E02才落地，地未干时人已挤。
挤成声浪声成网，网里谁先被简写。

------

我以为编号能让雨小一点。

我错了。

雨没小。

小的是**我**——小到一张蜡纸油印传单就能把我从人群里拎出来，拎得像示众。

传单贴在菜场口的水泥柱上。

浆糊味混着鱼腥，腥得像某种讽刺：人每天靠吃死物活，却还要在活物中间贴“真相”。

标题不大。

大的是那种**简写**：

**城西名册案？**

问号像钩。

钩不求答案。

钩只求**你停一步**。

停一步，你就会听见旁边有人念：

“听说姓秦的……”

“听说档案……”

“听说有个写小说的……”

写小说的。
```

## 颗粒 2（节选 L111–L152）·中段推进

```

顾清舟把茶壶挪开一寸。

挪得像把战场清出空白。

桌上摊着当天能收集到的纸片：传单、剪报、单位门口贴的**情况说明**（说明很短，短得像被人用刀削过）、还有不知谁塞进门缝的**匿名信**。

匿名信的字歪歪扭扭。

歪歪扭扭像故意不让笔迹认人。

信里只写：

**别信名字。**

**名字会换。**

我盯着那行。

盯得像盯镜子。

顾清舟道：

“你在想什么？”

“想**公共命名**。”我说。

话一出口我就后悔。

后悔不是因为错。

是因为太像论文。

论文在这时候像刀鞘。

刀鞘一套，刀就不见血。

顾清舟没有接“公共命名”。

他只问：

“你想当指针吗？”
```

## 颗粒 3（节选 L215–L256）·收束或转折

```

林晚照上门。

上门时鞋跟沾泥。

泥脚不进门。

她站在门槛外，像把自己先切成两半：

一半在流程里。

一半在人情里。

“报社主编叫我停。”她说。

停字很轻。

轻得像刀背。

“停什么？”我问。

“停‘深挖’。”她说。

深挖两个字带着编辑部特有的口气：

**像挖土，又像挖坟**。

我点头。

点得像认罪。

“那你怎么还来？”我问。

她看我。

看了两秒。

“我来问你一句。”她说。

“你怕不怕——”

她停住。
```
