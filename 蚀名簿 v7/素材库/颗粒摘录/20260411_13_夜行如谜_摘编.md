## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 13 节：夜行如谜（B视角：言临）

夜不是一下子黑下来的。

夜是先湿，再黑。

湿从鞋底爬上来，黑从屋檐压下来。

我和陈言走在回城北的路上。

没有约定“回哪”。

只是两个人的脚步默认了同一个方向。

像两条被雨拧在一起的线。

陈言走得很急。

急不是勇敢。

急是想把纸翁那半句话从耳朵里甩出去。

我走得慢。

慢不是拖。

慢是在数。

数身后有没有第三组脚步。


老城夜里最吵的是安静。

安静里任何声音都像被放大。

水滴。

铁皮。

远处电瓶车过水洼的一溅。

还有——
```

## 颗粒 2（节选 L262–L303）·中段推进

```

我把他们带进一条更旧的巷子。

巷子尽头是死墙。

墙上贴着半张剥落的告示。

告示上的字被雨泡糊了。

糊得像故意不让谁看清。

陈言一愣。

“死路？”

我不答。

我走到墙边一扇不起眼的铁门前。

门上没有牌。

只有一把锈锁。

锁很旧。

旧得像摆设。

我从怀里摸出一张卡。

卡面磨白。

白得像被人反复刷过。

我把卡贴在门侧一个几乎看不见的感应区。

嘀。

很轻。

轻得像错觉。

门缝开了一条线。
```

## 颗粒 3（节选 L550–L591）·收束或转折

```

陈言跟进来。

他声音发哑：

“你刚才在外面，是不是收了什么条子？”

我抬头。

“没有。”我说。

这是谎话。

谎话在这一刻是**护栏**。

护栏挡的不是他。

挡的是我自己。

陈言盯着我手套。

“你抖了。”他说。

我低头。

看自己的手。

确实在抖。

抖得像怕冷。

冷是借口。

我怕的是别的。

怕的是我发现自己竟然在算：

**22:40**之前，我还能不能把陈言从第七页边拉开。

顾清舟的声音从楼上传来。

很平。
```
