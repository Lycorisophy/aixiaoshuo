## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 15 节：雨夜迷途（B视角：言临）

雨又下起来时，衔霜楼的灯像被谁调暗了一格。

不是灯坏了。

是雨把光吃掉了。

陈言坐在外间。

面前摊着从档案馆带回来的复印件。

他没翻第七页。

他答应过不翻。

可不翻不等于不想。

想会在他眼睛里烧。

烧得我坐不住。


“两列。”他忽然开口。

声音哑得像砂纸。

“你早就知道有‘两列’。”

不是问句。

问句还有退路。

这是逼。

逼会让人露出掌纹。

我把笔记本放在膝上。

没翻开。

翻开就像应战。
```

## 颗粒 2（节选 L268–L309）·中段推进

```

陈言沉默了很久。

沉默里，他像把井底的紫、纸边的孔、两列的空，一件件往这个「走位/承名」的框里塞。

塞得进，他就松一点。

松一点，他的肩线就塌一点。

塌得像终于肯承认：

**这世上如果真有鬼，鬼也至少有个故事形状。**

故事形状能让人睡。

睡一会儿是一会儿。

我看着他那一瞬的松。

松得我胃里发苦。

苦是因为我知道我在喂糖。

糖化开之前很甜。

甜完会更渴。

陈言忽然开口，声音低哑：

“要是……真是民俗里说的那样呢？”

他不是在问我。

他在求一个能用的解释。

求到了，他就能对自己说：**我哥还在某个‘位’上，只是被挪了。**

挪了总比没了好。

好得是假。

可他需要这个假。
```
