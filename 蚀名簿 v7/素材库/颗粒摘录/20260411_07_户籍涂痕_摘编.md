## 颗粒 1（节选 L1–L32）·开场气氛与钩子

```
# 第 07 节：户籍涂痕（A视角：陈言）

我第二次走进“记录”的地方时，心里已经没有第一次那种天真的羞怯。

第一次我去市政服务中心，像去求一个答案。

我以为只要我把名字说清楚，把关系说清楚，把“我哥失踪了”说清楚，窗口就会像一面镜子，把我需要的东西反射回来。

可镜子不反射。

镜子只反光。

反光刺得人睁不开眼。

我从纸马铺出来，雨更冷了。

小票贴在胸口，热敏纸的边角磨着皮肤，像一片薄薄的刀。它不疼，但它一直在提醒我：你现在拿着的不是“线索”，是“路径”。

**1986/04/03 03:12  柜台 04**。

以及那行手写：*用它要交接签字。*

我不知道这张票据原本属于谁。

我也不问。

问了，纸翁会闭嘴；闭嘴不是拒绝，是自保。

我只知道：它能让我把一句话从“我说”变成“纸上写”。

而在这个城市里，“纸上写”比“我说”更像存在。

```

## 颗粒 2（节选 L34–L75）·中段推进

```

我没有再去十二号窗口。

我去的是侧厅的“档案查询与复印服务”。

那里不需要你跟窗口对话太久。你只要把材料递进去，按着流程缴费，等他们把复印件从另一扇小窗里递出来。它更像一台机器：你把硬币投进去，它吐出一张纸。

机器不会同情你。

但机器也很难撒谎——至少，它撒谎会留下工艺痕。

我取了号。

纸条上印着新的字：B052。

时间戳：18:26。

我把号码纸折好，放进钱包夹层。

我突然明白自己这两天学到的第一件事：任何“当下”都要先变成“可复核”。

我等了二十分钟。

灯管的白光在头顶嗡嗡响，像一条不肯停下的线。等候区的人比窗口少，空气里有复印机热起来的塑料味，混着纸粉的干涩。纸粉落在舌尖，会让你下意识想喝水。

轮到我时，柜台后面坐着一个男工作人员，年纪不大，眼神却很疲。他像习惯了别人把一生的麻烦塞进一张申请单里。

“办什么？”他问。

“查询一个人。”我说，“需要户籍档案相关的……复印件。”

他没有抬头。

“证件。”

我递了身份证。

他把证件对着灯看了看，低头抄号，敲键盘。

“查询对象身份证号。”

我深吸一口气。
```

## 颗粒 3（节选 L172–L213）·收束或转折

```

我换到另一张桌子前。

那是“档案复印申请”窗口。

我填了一张表。

表上需要写：查询对象姓名、与本人关系、用途。

我写：沈近。

关系：兄弟。

用途：寻人。

我把笔放下的时候，笔尖在纸上停了一下。

那一瞬间，我忽然有点恍惚——像在写一份不存在的人的申请。

工作人员把表收走，让我等。

我坐回椅子。

灯管在头顶嗡嗡响。

我盯着自己的手。

指甲缝里还有一点点纸粉，那是我在纸马铺摸过旧报纸留下的。纸粉很细，像灰。

我突然想起沈近小时候说过的话：把纸驯服。

可现在，是纸在驯服我。

二十分钟后，工作人员把一叠复印件递出来。

“只能给这些。”他说。

我接过来。

纸是热的。

复印机的热把纸烘得发干，边缘微微卷起。复印件的四角都有一圈浅灰边，那是老式滚筒压出来的痕。
```
