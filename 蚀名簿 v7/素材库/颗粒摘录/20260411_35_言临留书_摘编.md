## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 35 节：言临留书（A 视角：陈言）

书来无火却有灰，灰是留白不肯堆。
账页三折如三折，折处何人曾低眉。
E十E十一十二，数字如钉钉在谁。
谁边若问真与伪，伪真同日不同杯。

------

信是早上塞进来的。

塞进门缝。

缝很窄。

窄得像这城市只允许坏消息以侧身姿势进屋。

我捡起信。

信封没有寄件。

没有寄件不等于匿名。

匿名在这时候太干净。

干净像假。

假的东西往往**特别工整**。


我拿到顾清舟面前。

不拆。

先放。

放得像把雷放在桌上，等另一个人决定要不要剪线。

顾清舟看了一眼。

一眼就够。

```

## 颗粒 2（节选 L113–L154）·中段推进

```

我把账页对着光。

光从窗纸渗进来。

渗得像没洗干净的棉纱。

纸纹、折痕、墨渗——我分不清自己是在辨伪还是在**拖延**。

拖延是因为我知道：

一旦我认定“真”，我就会把言临钉进某一栏；

一旦我认定“假”，我就会把某个人钉进**骗子**那一栏。

两栏都亮。

亮会先死人。

死人不一定死肉体。


“你怎么看？”我问顾清舟。

问得像求救。

顾清舟没有伸手碰账页。

他只道：

“你看纸边。”

纸边有磨损。

磨损里有紫。

紫得旧。

旧得像印泥在潮里活过。

我喉咙发紧。

```

## 颗粒 3（节选 L221–L262）·收束或转折

```

夜里我独坐。

独坐像罚。

罚的不是我做过什么。

是我在想：

**如果留书是第三者放的**——

如果笔迹模仿得像——

如果账页是从谢知微那里**截流**出来的半套——

如果——

我停住。

停得像怕自己变成**制造如果的人**。

制造如果的人，

最像秦家那套手。

……

我把第三页空白对着灯。

灯昏。

昏得像故意不把字照出来。

照不出来也好。

照不出来，

就还剩**不命名**的余地。

余地小。

小得像门缝。
```
