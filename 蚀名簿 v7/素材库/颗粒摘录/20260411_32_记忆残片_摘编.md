## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 32 节：记忆残片（B 视角：言临）

马达三过浪三皴，东口西口两具身。
身入黑门声先哑，哑中谁拔谁为刃。
刃寒不及纸寒重，纸外有人已脱缰。
缰脱影乱灯乱舞，舞罢空余半句真。

------

第三趟马达响起来的时候，河面像被人撕开一道口子。

口子不深。

深的是我们同时动的那一下。

陈言从东口进。

我断西口绳。

绳是旧麻，麻里嵌着潮盐，盐粒磨掌，磨得像在提醒：

**疼是活的**。


里面黑。

黑得不像夜。

像有人把灯的定义从墙上抠走了。

我摸到绳结。

结是家里的打法。

打法认得我。

认得就像手铐认腕骨。

我把结拆开。

拆开像拆自己的骨头。

```

## 颗粒 2（节选 L171–L212）·中段推进

```

桩影从侧门滑出去。

滑得像鱼。

鱼不沾地。

不沾地的人最难追。

我追到门边。

门边只剩潮风和一股极淡的烟味。

烟味像某个人刚离开。

离开不等于输。

输在这城里常常是**纸上的事**。

纸上还没写。

写的人已经不在场。


我把陈言他们推往西口。

推得像推船。

船离岸。

岸上还响。

响像有人笑。

笑不像人。

人像的话应该是骂。

骂被河吃掉了。

吃掉就好。

```

## 颗粒 3（节选 L345–L386）·收束或转折

```

车走了。

灯远了。

远得像把真相带走。

带走不等于结束。

结束在这城里常写成“待续”。

我转身往回走。

往回像走向纸里。

纸里有我的名字。

名字不一定写得全。

写全了就会亮。


仓库里空了。

空得像从未关过人。

从未不等于真。

真在潮里。

潮里还留着尿臊与消毒水的叠味。

叠味像证词。

证词在这时候不会说话。

说话的是地上几根断绳。

断绳像骨头。

骨头不说话。

```
