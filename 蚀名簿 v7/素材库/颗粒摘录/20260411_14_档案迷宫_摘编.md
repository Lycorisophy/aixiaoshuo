## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 14 节：档案迷宫（B视角：言临）

天亮的时候，雨没有停。

只是变小了。

小雨最烦。

烦在让我觉得世界变温柔了。

温柔会让我放松警惕。

我放松了，就容易在档案库里走错格。


顾清舟起得早。

他桌上摆着三只空杯。

像提前摆好三个位置。

陈言坐下时，手还在抖。

抖的不是冷。

是昨晚那声门框轻响。

顾清舟没问昨晚。

问昨晚会把夜里的东西带进白天。

白天有白天的规矩。

规矩的第一条是：

**别用故事换纸**。

顾清舟把陈言那只密封袋推回灯外。

“你今天想去哪？”他问。

陈言张口就要说“档案馆”。
```

## 颗粒 2（节选 L296–L337）·中段推进

```

更深的地方有铁柜。

铁柜一排排。

排得像墓。

墓上贴着年份区间。

区间切得很整齐。

整齐得像有人专门教过怎么切人。

陈言想找“户籍”“人口”“迁移”。

他嘴型一动。

我就知道他要往亮处走。

亮处是陷阱。

陷阱不是鬼设的。

是人设的。

我拉住他袖口。

隔着手套。

拉得很轻。

我写：

**先找备份。**

他愣住。

“备份不也在系统里？”

我说：

“系统在灯里。”
```

## 颗粒 3（节选 L572–L613）·收束或转折

```

袋里是复印件。

复印件的灰边很重。

重得像墨粉受潮后自暴自弃。

陈言翻页。

翻得很慢。

慢得像怕翻出血。

我在心里数页。

一。

二。

三。

四。

五。

六。

到第七页前，我伸手。

压住纸角。

压得很轻。

轻得像按一个人的脉。

陈言抬头。

“你干什么？”

我说：

“先别看这一页。”
```
