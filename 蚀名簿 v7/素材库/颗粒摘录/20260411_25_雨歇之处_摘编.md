## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 25 节：雨歇之处（B 视角：言临）

雨歇云脚尚低垂，巷石犹潮屐齿迟。
一纸无名刚烙骨，半声将吐又吞之。
绳痕在腕风在袖，谁令回眸认旧旗？
此身若可作舟楫，逆水何堪载两疑。

------

雨不是突然停的。

是老城先学会**把声音放低**——檐口滴水从密变疏，像有人把算盘珠一颗颗往后拨，拨到某一格，忽然不想算了。

我站在衔霜楼外的石阶下，没上去。

上去意味着我要把自己放进一盏灯里。

灯里的人都好看。

也好看穿。

手套还戴着。棉布里层潮得像第二层皮——这比喻我用过很多次，用多了就不像比喻，像口供：**我习惯把手藏起来**。

可今天藏不住的不是手。

是那句迟早要落地的话：

**我接过命令**。


语言学里有个粗俗却好用的说法：**称呼不是礼貌，是权力**。

你喊“师傅”，是把对方放进可支使的格；你喊“同志”，是把关系先钉在某种正确的木板上。命令也一样——它不要求你同意，只要求你**在应声的那一刻，把自己缩进一个更小的字形里**。

我爹——我在心里仍这么叫他，不是亲，是**旧债的简称**——从不把话说满。

他只说：

**看着他**。

**别让他死得太快**。

```

## 颗粒 2（节选 L175–L216）·中段推进

```

檐水又落了一滴。

滴答。

在石板上碎开。

碎得像某个姓氏在潮里溶化。

陈言抬眼看我。

这一次他看的是眼睛。

“你现在说这些，”他问，“是因为你良心发现，还是因为你那条线——**断了**？”

我喉咙一紧。

紧得像绳子又缠上来。

我想说“都有”。

都有是最方便的答案，方便到像撒谎。

我想说“我不知道”。

不知道是最安全的答案，安全到像逃。

最后我写：

**命令还在。**

**只是我——不想只当回声了。**

他看完，嘴角动了一下。

不像笑。

像疼。

“回声。”他重复这个词。

重复得像在舌尖试毒。
```

## 颗粒 3（节选 L313–L354）·收束或转折

```

风从巷尾拐过来。

带着潮腥与旧纸霉味。

我闻到就想吐——不是胃，是记忆。

记忆也会反酸。

陈言转身要走。

走得很干脆。

干脆得像把我留在檐下当一件**还没决定要不要扔的雨具**。

“陈言。”我出声。

出声就后悔。

名字在雨后的空气里显得格外亮。

亮得像举手。

他停步。

没回头。

“别喊全名。”他说。

声音很平。

平得像在重复顾清舟或那张折纸里的规矩。

我舌尖一苦。

苦得像咬住了一口井绳上的苔。

“……好。”我说。

好字落下。

我们之间没有和解。
```
