## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 22 节：暗格寻踪（A视角：陈言）

谢知微给的门牌号，写在一张薄纸上。

薄得像刀。

门牌号对应的不是商铺，是城北一片快要拆干净的旧巷。巷子窄，窄得两个人擦肩都要侧身；墙皮剥落，剥落处露出更老的砖，砖缝里嵌着黑潮，像有人把井底的泥抹上来晒干。

顾清舟把车停在外围。

“走进去。”他说。

我点头。

点得像赴刑。


门环是铜的。

铜绿厚。

厚得像岁月故意不让人碰响它。

我抬手要敲。

顾清舟按住我的腕。

“别敲。”他说。

“敲了会像拜访。”

“拜访会被记住。”

我喉咙发紧。

“那怎么进？”我问。

顾清舟从袖里取出一串钥匙。

钥匙很旧。

旧得像不该属于任何合法房东。
```

## 颗粒 2（节选 L280–L321）·中段推进

```

暗格底板还有一道更细的缝。

细得像没打算让人发现。

顾清舟用竹片探进去。

探得很慢。

慢得像在给时间留余地。

底板松了一下。

松动像叹息。

下面露出石阶的边缘。

边缘潮得发亮。

亮得像井口的反光。

我心脏一缩。

“下面……”我说。

顾清舟道：

“下面不是给你现在下去的。”

我咬牙。

“为什么？”我问。

顾清舟看着我。

“因为你下去，会变成‘到过下面的人’。”他说。

“到过的人，最容易被写进——”

他停住。

我胸口发闷。
```

## 颗粒 3（节选 L546–L587）·收束或转折

```

我们退回暗格前。

退回像把心跳按回胸腔。

顾清舟低声道：

“今晚到此。”

“到此的意思是——”

他看我。

“意思是你的手别再往深处伸。”

“伸深了，你会变成‘摸到过’的人。”

“摸到过的人，最容易被写成——”

他又停。

我接上：

“共犯。”

顾清舟没有点头。

没有摇头。

他的沉默像默认。

默认比骂我更狠。


那块底板下还有一道细缝。

细缝在油灯里潮得发亮，亮得像井口的反光——我们刚才已经看见过一眼，不必再看第二眼。

顾清舟把护壁板推回去。

推得像把一截不该落字的记忆塞回墙里。

```
