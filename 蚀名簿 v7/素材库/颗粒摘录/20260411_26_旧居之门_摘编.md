## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 26 节：旧居之门（B 视角：言临）

陈言来得很迟。

迟不是拖。

是他在巷口站了很久——久到雨后的水痕在他鞋边缩成一圈更黑的边，像井口在地面留下的影子。

他抬头看我一眼。

那一眼里没有“信”。

只有**赌**。

赌和信长得像，差一口气：信要解释，赌只要结果。

“门环别碰。”我说。

碰了会像拜访。

拜访会被记住——这话不是我发明的，是这宅子的语法。


钥匙在我袋里。

袋布贴着腿侧，贴着像贴着一块还没结痂的伤。

我把钥匙掏出来。

齿口磨圆。

圆得像这家人早就算准：总有一天，会有人把它插进锁孔，把它当成“回去”的手势。

锁舌退开的声音很轻。

轻得像有人在里屋吸了一口气。

陈言肩线一紧。

“顾清舟不在。”他忽然说。

不是问。
```

## 颗粒 2（节选 L210–L251）·中段推进

```

下到一半，壁上有漆。

漆很旧。

旧到剥落处露出底下更深的色——那色不偏红，不偏蓝，偏一种**闷住的紫**。

紫得像有人把印泥涂在墙上，又用水洗过，洗不干净，只剩一种闷住的耻色。

陈言伸手要摸。

“别摸。”我说。

摸会留脂。

脂会留痕。

留痕就是——

他把手收回。

收得像被烫。

“你们家……”他起头。

又停。

停得像把刀尖撤回半寸。

“习惯。”我说。

习惯这两个字最安全。

安全到像谎言。


石阶尽头是一扇铁皮门。

门边钉着一块小木牌。

木牌上的字被潮晕开，晕得像哭过：

## 颗粒 3（节选 L414–L455）·收束或转折

```

上面忽然传来一声极轻的响。

像木板热胀冷缩的“咔”。

陈言猛地抬头。

我也抬头。

抬头像本能。

本能之后才是判断：

**老宅不是空的。**

空是给别人看的。

陈言唇线绷紧。

“你爹？”他问。

问得像把刀递到我手里：

**你接不接**。

我摇头。

“不知道。”我说。

不知道在这时候最像真话。

真话不会让人好受。

陈言低声道：

“他如果在，你现在算什么？”

算叛徒。

算诱饵。

算——
