## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 18 节：档案残页（A视角：陈言）

天亮之前，我其实已经醒过一次。

醒在便利店的塑料椅里，颈骨像被人用钝器敲过，后脑勺贴着玻璃窗，窗外霓虹把雨丝染成一段一段的碎色。我梦见自己在翻一本没有页码的册子，每翻一页，纸上就空一行；空行越来越多，最后整页只剩两个名字并排躺着——像两行不肯愈合的伤口。

我把自己从梦里拽出来，去洗手间用冷水泼脸。

镜子里的人眼白发红，胡茬冒头，像某个正在从“写故事的人”滑向“故事里失踪者家属”的半成品。

我回到衔霜楼时，顾清舟正在擦一只茶杯。

擦得很慢。

慢得像在擦一把刀。

“你回来了。”他说。

不是问候。

是确认。

我点头，把文件袋放到桌角——放得很轻，轻得像怕纸会疼。

顾清舟看了一眼那只袋子。

“先吃饭。”他说。

“吃不下。”我说。

顾清舟没有劝。

他只把一碗粥推到我面前，粥面平静，平静得像某种刻意的羞辱：世界还在照常运转，连米汤都能比你更稳。

我端起碗。

粥是温的。

温得像在提醒我：你还活着，活着就得继续用胃承接日子。

我喝了两口，第三口卡在喉咙里。

```

## 颗粒 2（节选 L276–L317）·中段推进

```

信封里果然有一张照片。

照片拍的是某个档案盒侧面的标签残角：墨迹、编号、还有一行被水渍晕开的手写备注。备注只剩半截，像被人用指甲刮过。

**……外来（临）……**

**装订：07-09 混册**

**缺页登记：见副卡**

我手指发冷。

冷得像摸到井沿。

另一张便签上是一行打印体，冷得像机器吐出来的：

**北城巷库房 · 丙区 · 架位 14-2 · 批次 1974-1982（临时）**

**提示：对读装订孔。**

装订孔。

我脑子里立刻闪过沈近屋里那张老照片边沿的压痕，也闪过档案馆第七页复印件上那排更靠内的订孔——两种疼法叠在一起，叠得我胃里发酸。

“副卡是什么？”我抬头问。

谢知微已经在擦柜台玻璃。

擦得像没听见。

顾清舟只道：

“去了就知道。”

“不知道也得回来再说。”


北城巷库房不是市政大厅那种亮堂堂的地方。

它更像老城把自己藏起来的胃：铁门、霉味、消毒水试图盖住霉味却盖不住的涩，以及那种一进去就会变小的脚步声——不是空间真的小，是纸太多，纸会把人的存在感压薄。

```

## 颗粒 3（节选 L552–L593）·收束或转折

```

我站起来的时候，腿有点麻。

麻得像在井沿上坐太久——我随即咬了一下舌尖，把这个比喻咬断。井是井，纸是纸；我不该让意象自己串门。

我想去最里那排铁架后头取外套。

顾清舟刚才把它搭在阴影里，灰扑扑一团，像某个今天没来上班的人留在世上的替身。

越往里走，霉味越厚。

厚到某一瞬，霉味底下冒出另一种味道。

不是纸。

是那种被水泡开、又被时间反复摁进泥里的腥——陈腐、钝、黏，贴在鼻腔里不肯走。

我停住。

顾清舟几乎同时起身。

他没问“你怎么了”。

他只走到我侧后，脚步放得很轻，轻得像怕惊动架子上的眼睛。

最底层那几只木箱与墙面之间，本应是水泥抹死的死角。

可死角裂了。

裂口不大，却足够让潮气往外爬：抹层剥落，老砖裸露，黑湿的水渍从缝里渗出来，像一张慢吞吞睁开的嘴。

“塌了。”我哑声说。

不是修辞。

是真的塌——几块砖歪斜着，后面不是实墙，是更深的暗，暗里有一线浅浅的水光。

顾清舟从我肩上探过手，按住我腕子。

“别碰砖。”他说。

“也别伸手下去。”
```
