## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 19 节：涂改之痕（A视角：陈言）

雨从凌晨开始变细。

细得像有人把音量调低，好让别的声音浮上来——复印机的嗡鸣、鞋底在瓷砖上的摩擦、还有我指节捏着文件袋时发出的那种干响。

我没睡稳。

睡稳是别人的特权。

我睁眼时，衔霜楼外间的灯还亮着，灯罩边沿一圈茶色，茶色里沉着昨夜的雨气。顾清舟坐在案前，像一夜没动，又像动了很多次——案上多了一只放大镜，多了一叠透明护套，多了一张写着“B-09”的小笺。

小笺上的字很稳。

稳得像在提醒我：今天不是去“问人”，是去“对痕”。

“吃饭。”顾清舟说。

我摇头。

“那喝水。”他又说。

我喝了。

水从喉咙下去，像把火压到更深的地方。


北城巷库房我们昨天来过。

丙区最里那道塌角昨天还像一张没合上的嘴，今天外面已经缠了绳、挂了块不写字的牌——牌面空白，空白得比任何字都更像警告。

今天再来，管理员的眼镜链响得更密。

她把我们领到另一排架子：**B-09**。

标签上印着“并册留存/待复核”，字体的边沿被潮气啃过，啃得像一张不想负责任的嘴。

“这一箱不能全复印。”管理员说，“能看的页，你们看；不能看的，你们别看。”

我差点笑出来。

笑出来会裂。
```

## 颗粒 2（节选 L208–L249）·中段推进

```

第三处实话最恶心。

恶心是因为它太像“办公流程”。

我们在一份并册说明里找到一行被涂掉的经手栏——涂掉用的是修正液，修正液上又打印了一行新字。

新字的字体与整页表格完全一致。

一致得像它天生就在那里。

可放大镜下，修正液的颗粒边界与打印墨点的渗透深度不一样。

不一样就是：**先毁，后补**。

先毁后补，还能把字体对齐到这种程度——

我不敢往下想。

一想就会走到“原来如此”。

而顾清舟早说过：**断不是答案。**


中午管理员换班。

换班像给牢笼换了一把钥匙。

新来的男人更年轻，说话更硬。

“你们还要看多久？”他问。

“看完为止。”顾清舟答。

男人皱眉。

“B-09 不是观光区。”他说。

我抬头。

“那是什么区？”我问。

```

## 颗粒 3（节选 L464–L505）·收束或转折

```

夜里，顾清舟把三张纸排在桌上。

三张纸来自三个不同系统的复印件留存：库房、侧厅调档、还有一张谢知微让人送来的“旧扫描件边角”。

三张纸的角落，印着**同一个外包项目编号的后六位**：

**380714**

后六位像一枚小小的胎记。

胎记长在不同人的档案上。

长得让人想吐。

顾清舟用指尖点了点那串数字。

“数字化是理由。”他说。

“理由是合法的。”

“合法的东西最方便穿过门缝。”

我盯着那串数字。

盯得像要把数字盯出血。

“所以是……”我开口。

顾清舟抬眼。

那一眼像拦阻。

拦阻我把话说满。

我硬生生改口：

“所以不是一个人？”

顾清舟点头。

“至少不是一个人的偶发。”他说。
```
