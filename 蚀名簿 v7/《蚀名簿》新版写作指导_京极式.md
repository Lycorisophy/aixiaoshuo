# 《蚀名簿》新版写作指导（京极夏彦式）

> **用途**：指导分节成稿的流程、文风锚点、元信息格式与设定约束。  
> **设定依据**：[`05_故事大纲_事件结构_时间正序.md`](05_故事大纲_事件结构_时间正序.md)、[`02_人物设定_整理自真设定集V4.md`](02_人物设定_整理自真设定集V4.md)、[`04_证据推理法医动机_整理自真设定集V4.md`](04_证据推理法医动机_整理自真设定集V4.md)、[`06_结局设定_整理自真设定集V4.md`](06_结局设定_整理自真设定集V4.md)、[`03_参考资料与炫学_整理自真设定集V4.md`](03_参考资料与炫学_整理自真设定集V4.md)、[`写作备忘_关键场次信息投放.md`](写作备忘_关键场次信息投放.md)。  
> **成稿目录建议**：与本书相关的正文 md 置于独立文件夹（ `正文分节/`），文件名严格采用 **`《蚀名簿》第X幕第X节.md`**（`X` 为阿拉伯数字：`第1幕第1节` … `第7幕第8节`）。

## 一、结构总览：七幕八节（56 节）与篇幅

| 项目 | 约定 |
|------|------|
| **幕数×节数** | **7×8＝56 节**（固定） |
| **单节正文** | 以 **约 4500～6000 汉字** 为弹性目标（京极式信息密度高，宁可略长勿空洞） |
| **全书正文总量** | **20～30 万汉字**：56×≈5360≈30 万；若严卡 30 万内，平均约 **5300 字/节**；若趋近 20 万，平均约 **3600 字/节**。定稿前用字数统计**按节微调**。 |
| **工序** | **①** 为全部 56 个文件写好**完整元信息头**（见第三节）→ **②** 再逐节写正文。一次只**主攻一节**正文，以免线索漂移。 |
| **特列** | **第 1 幕第 1 节**：在元信息之后、本节正文之前，含 **序言**（全书起笔，可与 1986 清明、失名恐惧、志怪作家身份相照，**不必**开篇泄底替身网）。**第 7 幕第 8 节**：正文末附 **尾声**（雨、紫、伞、记住/命名伦理等与 [`06`](06_结局设定_整理自真设定集V4.md)、[`01`](01_背景_时间与地点.md) 对扣）。 |

## 二、京极夏彦式文笔：四条支柱与可执行清单

**理性主义内核（与本书设定对齐）**  
卷内落点可表述为：**世上没有真正的「不可思议」**——井妖、吃名字、拘魂等，均为**人心、制度缺口与社会叙事**所投射的**显影**；拆解落实在**纸、档案、户籍、丧事流程、外包与权力话术**上（互见 `04` 物证链、`03` 妖怪表）。**禁止**以超自然实体收束真相。

| 支柱 | 含义 | 写作时可检核 |
|------|------|----------------|
| **稠密感官** | 触觉、嗅觉、湿度、温度、光、声、质地优先于抽象形容词 | 每节至少 **2～3 段**以「雨、霉、茶、油墨、井底回声、紫痕、纸边」等**可触可嗅**之物锚定空间 |
| **慢热思辨** | 长句、层进、先立民俗或常识再错位 | 允许 **顾**或叙述层使用「所谓……，其实不过是……」类**否定常识起句**（忌前四幕替代结案）；**陈**侧可文气比喻，与顾形成语速差 |
| **妖怪—心理隐喻** | 怪谈为**表**，心理与社会结构为**里** | 每出现妖怪俗名，后文或同节内需能**指回**具体人事（胁迫、失踪话术、档案篡改等），见 `03` |
| **理性收束** | 不可思议皆有**因由与工序** | 关键转折靠 **E 链、户籍、副本、副联、手套** 等落地，而非「灵光一现」 |

**视角与独白**  
- 叙述主视角遵循 **`05`**：**一、三、五幕**以 **陈言（A）** 为主；**二、四幕**以 **言临（B）** 为主（**022 末**可极短保留陈被带离；**023 起必为 B**）。  
- **每幕第 1 节**在定场诗之后，设 **人物内心独白** 一段（约 **300～800 字**为宜）：用**本幕主视角人物**的声音（陈用第一人称「我」；言临可用第一人称或贴近其「少言、多记」的**短句内心**）。**目的**：让读者**体感切换**到本幕视角。**注意** [`06`](06_结局设定_整理自真设定集V4.md) **H.0**：**不得**以 **顾清舟第一人称专章** 写全书；顾的内心若写，宜用**第三人称限知**或**陈在场时的观察**，且独白段**不要**放在「顾独占一节」的结构里作第一人称长篇。

## 三、单节文件格式：元信息（须置于正文之前）

每一节一个 md 文件。文首使用 **YAML 前置元数据**（两行 `---` 包裹），字段**尽量填满**；正文从第二个 `---` 之后开始。

### 3.1 定场诗与幕首独白（仅每幕第 1 节）

- **定场诗**：**七言八句**，共 **56 字**（八句，每句七字）。建议 **押韵**（常见为偶句脚韵，或首韵随你定稿）。内容紧扣**本幕母题**（如雨、井、名、纸、替身、记忆），**不必**直白的剧情剧透。  
- **幕首内心独白**：紧接定场诗之后、本节「事件正文」之前；**仅 `节: 1`** 的节需要写「幕级」定场诗+独白（见下表「每幕第 1 节」）。

**第 2～8 节**：不写新的定场诗；可在元信息 `本节提要` 中标明视角延续，正文开篇用**极短**时空钩（一两句）接入即可。

### 3.2 YAML 模板（复制到每节文件顶部后逐项填写）

```yaml
---
蚀名簿_节_meta:
  书名: 蚀名簿
  幕: 1                    # 1-7
  节: 1                    # 1-8
  文件命名: 《蚀名簿》第1幕第1节.md
  成稿状态: 元信息已定稿 / 正文草稿 / 正文定稿   # 三选一，随进度改

叙事:
  主视角: 陈言（A）        # 或 言临（B）；与 05 该段事件一致
  时间_公历: 1986-04-05    # 草案，可随 05 平移±1～2 日
  时间_稿内提示: 清明后·侵幕

大纲与事件:
  对应_05_事件序号: ["009"]    # 字符串列表；一节可对应多格
  本节提要_一句话: 
  事件列表_条列:               # 2-5 条，写作时勾选完成
    - 
    - 

前文与后文:
  前文总结_供作者复盘:         # 写本节正文前，用 5-10 句概括已发生
  下节规划_钩子:               # 文末要递出的悬念或动作

设定与证据:
  须遵守_硬约束:               # 列关键词，如 H.5井底不藏尸、022-030证物链、沈近线勿前半钉死替身标签
  证据推进_E链:               # 如 E02种子、无则写「无」
  妖怪民俗壳_若出现:          # 对应 03 条目或写「无」
  信息投放备忘:               # 可链到 写作备忘_关键场次信息投放.md 中的小节编号，如「015」

参考资料:
  - 文件: 05_故事大纲_事件结构_时间正序.md
    节录: 
  - 文件: 03_参考资料与炫学_整理自真设定集V4.md
    节录: 

篇幅与节奏:
  目标字数_汉字: 5500
  思辨段落_预估占比: 约25%    # 自我提醒，防拖垮节奏

备注: 
---
```

**说明**  
- `事件列表_条列` 应从 [`05`](05_故事大纲_事件结构_时间正序.md) 对应行的 **动作/结果** 化简为可写条目。  
- `须遵守_硬约束` 建议每节至少扫一眼 [`05` 第五节「使用说明」](05_故事大纲_事件结构_时间正序.md) 与 [`04` §5.2](04_证据推理法医动机_整理自真设定集V4.md)（证物链）。

### 3.3 YAML 之后、正文之前的固定小节顺序

1. **`# 定场诗`**（**仅当 `节: 1`**）：七言八句，一句一行。  
2. **`# 幕首内心独白`**（**仅当 `节: 1`**）：视角见上节「二」。  
3. **`# 序言`**（**仅 `第1幕第1节`**）：全书序言，置于独白之后、本节叙事正文之前。  
4. **`# 正文`**：本节主体。  
5. **`# 尾声`**（**仅 `第7幕第8节`**）：置于本节正文之后。

## 六、设定红线（节内自检用）

1. **替身结构**：**叶氏**为对外门面（草案）、**秦姓**为里层；**19 世纪夺名门**与 **山区—城内寄生循环** 见 `02` 反派；**顾家与反派无组织牵连**（`02` 顾条）。  
2. **沈近**：正文**前半勿钉死**「替身目标且未遂」类作者标签；证据与营救节奏见 `04` §五叙事节奏说明。  
3. **证物与井**：**021 不见成册**、**022–030** 链、**047/058** 无意识书写，不得与 `05` 矛盾。  
4. **尸体**：**H.5** 井底不藏尸；第三幕尸线收束。  
5. **1986**：身份凭据以 **户口簿、介绍信、档案** 为主，忌「一张身份证定乾坤」(`04` §1.2)。  
6. **结局**：社会面**见报**、顾**串联揭露**经陈在场、陈**持册撰文**与**诺上交**、**末页实写**（`06` §0）。  
7. **京极式理性**：怪谈描写可浓，但**真相层**须能指回**人为与制度**；**禁止**以真鬼结案。

## 七、推荐工序小结

1. 建文件夹，预建 56 个空文件：`《蚀名簿》第1幕第1节.md` … `《蚀名簿》第7幕第8节.md`。  
2. **只填 YAML + 定场诗/独白/序言占位**（第 1 幕 1～8 节先写完幕1的定场诗仅在第1节）。  
3. 对照第四节表，把 `对应_05_事件序号` 全部填齐。  
4. 从 **第1幕第1节** 开始写正文；每节完更新 `成稿状态` 与 [`05_序号与正文节号对照表.md`](05_序号与正文节号对照表.md)。  
5. 全书完稿后做**总字数**与**E 链是否各点落地**（`04` §4.3）总检。
