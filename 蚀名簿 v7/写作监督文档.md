## 1. 互动模式（Cursor）

| 模式 | 适用场景 | 说明 |
|------|----------|------|
| **Ask** | 只读答疑、设定查询、不改文件 | 适合「这句话是否违反 015？」「E 链某条在何处？」等；智能体以解释与引用为主，**不**擅自改正文。 |
| **Agent** | 续写正文、改 YAML、同步进度表、执行检索与补丁 | 默认**执行模式**：按节打开 `正文分节/`、对照 `05` 与备忘、写完自检、更新本表与 [`写作进度_五幕成稿.md`](写作进度_五幕成稿.md)。 |
| **Plan** | 多方案取舍、大范围结构调整、需先对齐架构再动笔 | 先产出可执行步骤与影响面，**确认后再**进入 Agent 改稿。 |

**约定**：涉及**未决剧情**、**可能动设定**或**与已发表正文冲突**时，智能体应先**列出方案并请你确认**，再写入正文（见下文「问题处理流程」）。

## 3. 正文编写约束（摘要）

- **权威层级**：`06` §0 → `05` → `02` → `04` → `03` + 新版写作指导；冲突时以上述顺序为准。  
- **不得擅自**：增减**关键情节**、改变**已定人物性格**与**主线逻辑**；若大纲需动，先改 `05`/`02` 等并请你定夺。  
- **每节**：`对应_05_事件序号` 与 [`05_序号与正文节号对照表.md`](设定集/05_序号与正文节号对照表.md) 一致；关键场次必落句见 [`写作备忘_关键场次信息投放.md`](写作备忘_关键场次信息投放.md)。  
- **幕末（可选）**：每幕收束后可按规则写 **幕末读者向资料**（见 `.cursor/rules` 中「幕末读者向资料」条），**防剧透**。

## 5. 问题处理流程（需你确认后执行）

1. **暂停**：停止继续扩写该节。  
2. **检索**：必要时联网检索（刑侦、档案、历史、行业细节等）。  
3. **推理**：综合设定与检索结果，给出**至少一个**可执行方案（具体改句、增删段落或补设定条目）。  
4. **输出**：方案 + 明确一句：**「请确认是否执行」**。  
5. **执行**：你确认后，再改正文 / YAML / `设定集`/`05`（按方案范围）并**同步本监督文档**。
