# 《蚀名簿》v7 · AI 辅助创作指南（AGENTS）

> **用途**：固化人机协作**范式**与**任务 SOP**，供 Cursor Agent / 人类作者快速对齐。  
> **不替代**正典：详规仍以 [`.cursor/rules/蚀名簿-v7-写作.mdc`](.cursor/rules/蚀名簿-v7-写作.mdc)、[`写作监督文档.md`](写作监督文档.md)、[`设定集/`](设定集/)、[`写作备忘_关键场次信息投放.md`](写作备忘_关键场次信息投放.md)、[`《蚀名簿》新版写作指导_京极式.md`](《蚀名簿》新版写作指导_京极式.md) 为准。

## 1. 范式总览

| 维度 | 约定 |
|------|------|
| **权威层级** | `06` 结局 → `05` 事件 → `02` 人物 → `04` 证据/动机 → `03` 炫学 + 新版写作指导；冲突时以上述顺序为准（见 [`写作监督文档.md`](写作监督文档.md) §3）。 |
| **人机分工** | 人：剧情取舍、动设定/大纲、发表锁、红线。AI：在边界内起草/改写、grep 对照、更新 YAML 与进度表、输出自检清单。 |
| **可审计轨迹** | 每节 **YAML** + **`05` 事件行** + **备忘硬句** + **`写作进度_五幕成稿.md`** + **`自检_备忘执行进度.md`** + **`写作监督文档` §7**，避免「只存在于聊天」的设定。 |
| **防漂移** | 正文已落地专名/机制 → 回写 `01` §2.3 / `02` / `05` 或 [`设定集/正文_已钉专名与互见.md`](设定集/正文_已钉专名与互见.md)；新开写前 **grep 设定集**，无则先钉再写。 |

## 2. Cursor 模式选用

| 模式 | 用途 |
|------|------|
| **Ask** | 只读：设定查询、句级是否越界、不改仓库。 |
| **Agent** | 执行：写正文、改 YAML、同步表、补丁、检索。 |
| **Plan** | 多方案、大范围结构、先对齐步骤与影响面，**确认后再**改稿。 |

涉及**未决剧情**、**可能动设定**或与**已发表正文**冲突时：先列方案 → 人类确认 → 再写入（见 [`写作监督文档.md`](写作监督文档.md) §5）。

## 4. 任务 SOP

### SOP-A：撰写某一节正文（默认 Agent）

1. 读该节 **YAML**（视角、时间、`对应_05_事件序号`）。  
2. 读 [`设定集/05_故事大纲_事件结构_时间正序.md`](设定集/05_故事大纲_事件结构_时间正序.md) 对应事件行 + [`设定集/05_序号与正文节号对照表.md`](设定集/05_序号与正文节号对照表.md)。  
3. 读 [`写作备忘_关键场次信息投放.md`](写作备忘_关键场次信息投放.md) 相关条 + [`自检_备忘执行进度.md`](自检_备忘执行进度.md) 对应行。  
4. **新专名/新店/路名**：先 grep → [`设定集/01_背景_时间与地点.md`](设定集/01_背景_时间与地点.md) §2.3 或 [`设定集/正文_已钉专名与互见.md`](设定集/正文_已钉专名与互见.md)；无则先补设定再落笔。  
5. 使用 [`写作监督文档.md`](写作监督文档.md) **§2.1** 类提示词；严守规则中的视角、H.0/H.5、证物链、**015 二妖百科台**、发表锁等。  
6. 完稿：输出 **§4 自检表** → 更新 YAML `备注`（CJK）、[`写作进度_五幕成稿.md`](写作进度_五幕成稿.md)、[`自检_备忘执行进度.md`](自检_备忘执行进度.md)、[`写作监督文档.md`](写作监督文档.md) §7 / §7.1。

### SOP-B：只自检、不扩写

遵循 [`写作监督文档.md`](写作监督文档.md) **§2.2**：逐项通过/待复核；若改稿，走 **§5**（方案 +「请确认是否执行」）。

### SOP-C：设定钉入 / 防漂移（Plan → Agent）

回写 `01` / `02` / `04` / `05` 中与正文一致的短条；轻量索引维护 [`设定集/正文_已钉专名与互见.md`](设定集/正文_已钉专名与互见.md)。**勿**与 `01` §1.3（1986 物质锚）冲突，除非先改设定。

### SOP-D：YAML 与进度表同步

正文、YAML 剧情要点、设定表 **专名一致**；[`自检_备忘执行进度.md`](自检_备忘执行进度.md) 与 [`写作进度_五幕成稿.md`](写作进度_五幕成稿.md) **状态与日期一致**。

### SOP-E：疑难与动设定

[`写作监督文档.md`](写作监督文档.md) **§2.3** + **§5**：暂停扩写 → 检索/推理 → 可执行方案 → 人类确认 → 再改文件。

### SOP-F：幕级校对（可选）

节内用 §4 自检；幕级参照 [`自检_第3幕_只读.md`](自检_第3幕_只读.md)、[`自检_第4幕_只读.md`](自检_第4幕_只读.md)、[`自检_第5幕_只读.md`](自检_第5幕_只读.md) 体例。**二稿加密度 / 朽幕剪接**另对照 [`写作备忘_关键场次信息投放.md`](写作备忘_关键场次信息投放.md) 049～054 与 `05` §六。读者向资料见 `.cursor/rules`「幕末读者向资料」条。
