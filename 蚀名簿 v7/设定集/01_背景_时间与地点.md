# 背景：时间与地点

> 《蚀名簿》新设定集 · 卷首锚定。与旧版真设定集一致处：**叙事起点仍为 1986 年清明节**；舞台仍为**江南老城**。本文把**地点写全**，便于后文人物、动线、证据链在同一坐标系内展开。

## 一、时间

### 1.1 故事「现在」的起点

| 项目 | 设定 |
|------|------|
| **公历日期** | **1986 年 4 月 5 日** |
| **节气与节日** | **清明**（寒食余绪未远；民间祭扫、迁坟、路口化纸与春深阴雨叠在同一时段） |
| **季节体感** | 江南**仲春向暮春**：樟树与泡桐新叶已展，早晚仍凉；雨多呈**黏连状阴雨**，非盛夏暴雨，利于「潮纸、霉味、墙缝渗水」一类书写 |
| **历法备注** | 叙事以公历记事为主（窗口条、档案戳记、热敏小票等）；人物口语可偶及农历祭扫习俗，**不与 1986 年春锚冲突** |

### 1.1.1 本城特俗：清明爆竹（与泛江南通感可不一）

舞台地理仍在**江南水网老城**，但**本城**在节俗上有一处**地方性加强**：**清明当日及前后数日**，街巷间可闻**鞭炮**断续作响——**勿**据此反推「全江南清明皆放爆竹」；亦**勿**与「部分江南地区不兴清明爆竹」的通感简单对立，本书只约定**本城**如此。

- **口耳表层（公开礼俗口径）**：祭扫时以声响**告知先人**、与纸钱香烛同属一日之内的仪式声景。
- **城内另一套口传（可与表层并存）**：又有人说，响动是为了**驱赶孤魂野鬼**、不让无主之魂在路口与生者**抢道**——两套说法**谁早谁晚、哪套更「真」**，城里亦**说不清起源年代**；叙事不必考据成史，只保留**口传叠层**与春深阴雨中的**妖谣气氛**互文。
- **认知投放**：**侵幕 013（第1幕第5节）** 陈言**仅**在暮色里听见远处鞭炮作听觉锚，**不必**当场点破上述双层；**啮幕 030（第2幕第8节）** 脱出途中由**言临**向陈言**补述**叠层口传（宜短笔，勿压主冲突）。互见 [`02_人物设定_整理自真设定集V4.md`](02_人物设定_整理自真设定集V4.md) **言临**条；正文 YAML 见 `正文分节/《蚀名簿》第2幕第8节.md`。

### 1.2 与起点咬合的周边日期（写作硬锚）

- **沈近夜访**若与正文「清明前约一周」对齐，则**掘册与示封面**可落在 **1986 年 3 月 29 日**前后（仍在同一连阴雨季象内，可写）。**无字条**；失踪自当夜起算。
- **本卷主舞台**锁在 **1986 年春**；替身链条的**历史纵深**含 **19 世纪**整户名门被夺（`05` **000**；**对外姓草案** **叶氏**、年代定稿 **1870–1880 年代**〔**太平天国后江南秩序恢复期 / 清末洋务期**〕，`02` **定稿备忘**），名册与轮替受害之**代际计数**可再上溯至约 **1920 年代**（`05` **001**），但不在本设定集内把叙事终点钉死到二十世纪末以后——与开放式收束兼容。

### 1.3 时代氛围（不写具体政策名亦可）

- **物质现实**：无手机与互联网；联络靠**当面、市话、单位总机、书信与纸条**；复印机在**机关窗口、外包文印店**已可见；**热敏纸**多见于**对外窗口取号条、外包店小票、个别传真式回执**，**非**户籍底册或人事档案**正文用纸**，**忌**写成「人人手里一张热敏身份证感」。
- **身份凭据（叙事锚）**：**1986 年**第一代居民身份证虽已随条例与实施细则**开始发放**，但**尚未形成强制随身携带**的刚性要求，社会办事仍以 **户口簿**、**单位介绍信**、工作证与人事档案为主流；「身份证随身带」的**全民习惯尚未养成**（尤其老城、中小城市与日常窗口）。**里层身份替换诡计**宜与 **户籍底册、迁移存根、介绍信链** 同呼吸，互见 [`04_证据推理法医动机_整理自真设定集V4.md`](04_证据推理法医动机_整理自真设定集V4.md) **§1.2**。
- **追逃与司法技术锚（「在逃」合理性）**：**无**街面视频监控网、**无**手机与卫星定位追逃；通缉、协查靠**市话/电报、纸质通缉与布告、单位介绍信盘查、人工摸排**，跨省信息**常滞后**。重大案犯**短期内未落网、长期在逃**在当年**不反常**（尤其有预谋、有社会关系网者）。结局写 **秦父、秦叔仍在逃** 与此相容；正文可**择一两处**借角色口语或报道旁及「协查函在路上」「外地线索一时对不上」等，**勿**写成二十一世纪「天网式」必擒叙事。互见 [`06_结局设定_整理自真设定集V4.md`](06_结局设定_整理自真设定集V4.md) **§0-1**。
- **夜间照明**：路灯、橱窗灯、台灯与手电并存；**灯下 / 灯外**可作为控光与心理的写作抓手（与「别在灯下」类礼俗互文）。

## 二、地点（由大到小写全）

### 2.1 宏观区位（不锁实名，但坐标要清楚）

故事发生在中国**东部、长江下游南岸一带**的**江南水网丘陵区**：河汊多、老桥多、巷弄窄，新城与老城并存，行政上可归**某一地级市下属的城关与旧县城片**（**不设具体市名、县名**，避免与真实行政区划绑定；需要时可内部自拟统一代称，全文一致即可）。

- **老城**：明清以来延续的城垣与街市肌理，木构与砖混杂处，**祠堂、城隍庙、旧书院与码头文化**的沉积层仍在；本传**主叙事空间**。
- **新城 / 扩展片**：二十世纪五六十年代以来沿公路与机关大院外扩的片区，**红砖楼、单位围墙、新辟马路**；与老城之间有**班车、自行车与步行可达**的距离感，不是另一座城市。
- **叙事默认**：人物说「进城」「回城北」「去城西工地」，皆指**同一座江南老城及其关厢**，除非正文另起说明。

### 2.2 城中方位与功能片（中观）

以下方位以**叙事用罗盘**为准（**东—南—西—北**），与常见「城东庙、城西市、北城文、南城商」的江南旧城习惯大致相容。**说明**：表中 **城南** 作「机关文教带」可与俗语「南城商」并存——可理解为**二十世纪五六十年代机关、学校外扩**叠在旧城南垣外，**不必**强求四字诀字字对号入座。

| 片区 | 方位 | 功能与气质（写作功能） |
|------|------|------------------------|
| **城中心** | 老城几何与商业重心一带 | 茶馆、照相馆、小铺、菜场与机关门面杂处；**信息交汇、名册与市井流言**易在此落地；侵幕中宜作**折返枢纽**（与城北、城西之间的脚程叙事）。 |
| **城南** | 老城南侧 | **机关文教带**：旧县署余绪、邮局、学校与**公共图书馆**常集中于此；与城中心步行可达，适合开篇「先求证、再入市井」的脚程。 |
| **城北** | 老城北侧 | **文化区与「雅」一侧**：旧书院余绪、字画装裱、中医街；**衔霜楼**坐落于此带，与中药铺、安静巷弄同一气质层。 |
| **城西** | 老城西侧及关厢外延 | **工地围挡、拆迁与出土传闻**；叙事锚：**二战时**该井**枯干**，**共同体（早年城内执行面）**将纸证档案**直接埋入井内**（**无铁箱**）；**1986 年**为**取水**对该井**加深淘挖**，**扰动**埋藏而外现传闻；**沈近**可被**安排为淘井用工之一**（见 `05` **006–007**）；**瑞成纸马铺**在城西居民区深巷；**枯井 / 井口**与工地线索绑定；潮气、灰土、丧事扎作与「纸味」集中。 |
| **城东** | 老城东侧 | **城隍庙**所在宗教—民俗片区；另有**知微堂**一类临街铺面（情报、旧账、账本气味可与纸线呼应）。 |
| **行政节点** | 老城办事片或**贴靠新城一侧的市政服务窗口**（定稿时二选一，**全书统一**） | **户籍与档案窗口**、复印与盖章的「机关口气」；涂改、副联、编号与**窗口取号/回执类热敏条**可在此与城西纸线形成对照（**热敏场景限定**见 **§1.3**）。 |

#### 衔霜楼命名释义（钉死）

- **来源句**：何逊《咏早梅》“衔霜当路发，映雪拟寒开”。  
- **场景意象**：衔霜楼设为清幽小楼；冬日窗外可见梅枝含苞、枝头带霜。  
- **人物志向**：楼主以梅自期，意在乱局与逆境中守其高洁。  
- **使用边界**：正文可点到楼名与梅霜意象，不展开诗学考据；语义重心保持为“记住与承担”的人格取向，避免写成纯景物雅号。

### 2.4 动线备忘（与空间写全配套）

侵幕推荐城内脚程逻辑（可与长篇骨架互见，定稿后全书统一）：

**住处**（**兄夜访示封面后失踪**之余悸、情绪落点）→ **城南·县图书馆**（地方文献、旧报复印）→ **城中心**（交接复印、见次要人物、再入市井）→ **城西工地**（雨景、围挡、紫印、**打听与妖怪传言**）→ **城中心/城北折返**（**4/6 上午**老茶馆，**下午～傍晚**衔霜楼见顾长谈；**4/7 起顾转暗查**）→ **城西**（纸马铺、户籍、**4/11 井口与实下井无顾**；**整理资料名义**互见 `05` **020**）。

**穴幕后段**（与侵幕脚程**分列记忆**）：**城东·知微堂**一带买拐弯 → **北城巷·库房连旧城排水暗渠**无名尸与封控 → **检验节点**（`05` **040** 等），与 `05` **034→040** 同向。**耗幕**：**旧仓**外对峙 → 撤离与途中（`05` **046–048**），勿与单线「只停在侵幕」混读。

若**开篇**从住处与图书馆起笔，须在**同日或次日**内落到**城西工地**，避免「只查纸不到场」削弱临场恐惧；**城中心—城北—城中心**折返仍须压实。
