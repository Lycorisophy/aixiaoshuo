## 1. 硬纪律（与哲学备忘一致）

- 科学修辞与哲学隐喻**共用炫学配额**：陈言 / 顾清舟 / 言临每人全书 **1–2 段**京极式量级；其余只能拆成**半句—两句**。
- **量子词黑名单**：正文禁高频「波函数、退相干、纠缠」；若用，**每节最多一次**且立即人话翻译（参见哲学备忘 §6）。
- **比喻三段式**：钩（科学/博弈口语）→ 陈言自疑或言临自抑 → 顾清舟或物证打断。
- **恐怖契约**：修辞必须落到具体感官与沈近/失名者之痛，否则删。
- **解离 / 自动书写（对齐附录 H）**：全书以 **假说** 出现，服务「末页笔迹、井后失忆感」；**建议落点**：**11** 仅动作与哑谜影子；**39–40** 顾清舟 **短假说 + 反问**，陈言 **抗拒**；**总量** 与哲学备忘「荣格/阴影」共用额度，**禁止**写成医学定谳或超自然实锤。

## 2. 六项科学块：正文可说法 / 禁止说法 / 建议落点

| 块 | 正文可说法（内化） | 禁止 / 慎用 | 建议落点（节号） |
|----|-------------------|-------------|------------------|
| **1 姓氏家族 × 亲缘标签（演化合作信号）** | 同姓、同谱、同印泥「像一套**认人、认帮、认债**的便宜信号」；好合作也好骗人；**贴错标签的人最该怕**。 | 不写公式、不把犯罪动机写成**基因决定**；里层仍是**制度与利益**。 | **22** 老宅密集；**28** 流程词旁可半句。 |
| **2 名与字 × 心理档案指针** | 「名像**钉死的指针**，对外用的字像**柄**」；谁在什么场合能怎么称呼 = **规矩即使用**。 | 不写认知课；用**动作**写（窗口、报道、避讳）。 | **07/18** 类已走；**24** 契约；**36** 林晚照「一句话把他命名成谁」。 |
| **3 拘魂鬼/无头鬼 × 威胁图式** | 缺头仍能走、唤名即被拽走 = 「脑子最怕的**低概率图式**」；并置**社会性失名/失头**。 | **STS 神经元**等：全书 ≤1 次极短，立刻回到纸与情绪。 | **29** 叫名+回声；**21** 已有着墨时可不叠。 |
| **4 语用 / 意义即使用** | 「词的意义在看**谁常用、在哪用**」；窗口话术、话题标签 = 公共语用。 | 不写词向量、机器学习长段。 | **34–36** 舆论；**39** 档案馆中话术。 |
| **5 自我模型 × 预测冲突** | 「身体在这，字段在那」「两套预测在脑子里打架」；**不**展开自由能。 | 不把沈近写成诊断书文体。 | **23** 已情绪到位；**38** 沈近状态可半句。 |
| **6 量子认知（严格）** | 仅 **顺序效应** 口语：「先问谁后问谁，口供会变」「身份判断像**没选完的题**」。量子**不解释鬼**。 | 禁「薛定谔的哥哥」实锤、禁纠缠通灵。 | **24** 合作「先问谁」约定；**34** 报道顺序。 |
| **7 解离 / 自动书写（附录 H）** | 「手动了、脑子没跟上」「事后不记得那一截」；**或然问句**：「你有没有在井沿拿过笔？」 | 不写满诊疗室；**不**替代档案与指纹级证据。 | **11** 影子；**39–40** 逼近；顾清舟每次 ≤ **两三句假说** 即被打断。 |
