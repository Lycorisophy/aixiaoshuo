> 用途：落实「大命题融入方案」而不破坏 [《蚀名簿》长篇骨架.md](./《蚀名簿》长篇骨架.md) 双层叙事与去玄幻口径。  
> 最高优先级仍以 [《蚀名簿》真设定集V4.md](./《蚀名簿》真设定集V4.md)、[shinmeibo-prose.mdc](./.cursor/rules/shinmeibo-prose.mdc) 为准。

## 1. 硬纪律（写作前扫一眼）

- **里层不得玄学化**：量子、存在、语言哲学一律是**人物修辞/理解模型**，不是世界观真律；可证伪链条仍落在纸证、权限、人为操作上。
- **专名**：正文少贴海德格尔/维特根斯坦标签；观念可内化（礼法、避讳、字段、程序）。编辑备忘里可记理论出处。
- **炫学配额**：陈言、顾清舟、言临每人全书 **1–2 段**京极式长独白量级；大命题宜拆成多次短交锋。
- **荣格/阴影/集体无意识/「记住还是遗忘」终局命题**：与科学备忘「自动书写」共用额度；**全书顾清舟侧合计不宜超过 2 段**「框架级」阐释（每段 ≤ 叙事上五六百字为宜），其余只能 **半句—两句**，且 **必须** 由陈言打断、否认、或动作切断；**禁止**替代 E 链与物证闭环。
- **对话**：错位收束，禁「原来如此/真相是」式共识顿悟。  
- **科学修辞**（演化博弈、认知、语用、量子认知口语等）另见 [《蚀名簿》科学修辞与认知框架备忘_v1.md](./《蚀名簿》科学修辞与认知框架备忘_v1.md)；与哲学段**共用额度**，勿重复堆叠。

## 2. 概念翻译表（资料 → 本书说法）

| 资料核心 | 本书合法说法 |
|----------|----------------|
| 语言是存在之家；姓名为第一所房子 | 宗祠/族谱/讳 → 户口本、档案字段、扫描外包；**顾清舟刹车句**：「家是人住的，册子是给人住的。」 |
| 命名≈测量、叠加态 | **仅陈言内心比喻**，后接自我怀疑或物证打断；禁每节堆「波函数/退相干」。 |
| 语言游戏、权力语法 | 窗口话术、避讳、报道口径、谁能改哪一格；**林晚照线**（舆论幕）强化「报道即命名」。 |
| 可说/不可说 | 稿费写得出的恐惧 vs 沈近卡在不可被顺利叙述的缝；言临**拒详述**落实「不可说」。 |
| 拘魂鬼≈语义锚定 | 被点名、被登记、被圈栏的锁定感；言临任务伦理与短信/指令同构。 |
| 无头鬼≈指称断裂 | 社会身份「身首异处」；非超自然无头。 |
| 反对语言施魔法 | 顾清舟少说一句、言临留书（35 节方向）：**不把别人的命钉死在话里**。 |

## 4. 第四幕（25–32）言临视角：短内心与「拘魂鬼」同构

**文体**：短行、戒条感；量子/哲学词 **每节最多一次**，且紧跟人话翻译。

| 节 | 扎进点 |
|----|--------|
| **25 雨歇之处** | 内心一句：命令像**提前写好的称呼**，应声即被钉进任务（不说「退相干」三字也可）。秦父来电/短信只显示编号或半截称呼更佳。 |
| **26 旧居之门** | 老宅规矩=语法：哪扇门能开、哪格抽屉不能碰；**沉默**比解释狠。 |
| **27 井底** | 「备用箱」与沈近材料对照：**命名完成即社会性死亡**的恐怖，用言临生理反应（手冷、停笔）写，少用大词。 |
| **28 无底之井** | 家族「传统」口径用**流程词**（挑选、收买、压案）；可插 **一句**「像网」类比喻，立即用具体步骤打断。 |
| **29 井底之声** | **试点稿已存 v6 正文**；回声、唤名、录音手脚；叠 **威胁图式**口语（无头/唤名，科学备忘 §2-3）；成稿后回读。 |
| **30 归位之人** | 行动节，哲学让路；最多半句「归位的是名还是人」。 |
| **31 双生之影** | 「替身」隐喻与**指称可替换**；可极短联想无头鬼里层（身份断头）。 |
| **32 记忆残片** | 言临消失前留话：**不可直译**（维特根斯坦式沉默的叙事版）；沈近状态=指称残损。 |

## 5. 第五幕（33–40）陈言视角：可说之物与「解释」母题回声

| 节 | 扎进点 |
|----|--------|
| **33 证据成链** | E 命名入场=把「不可说」压进「可说」的程序；陈言不适：证据链是否也在**替人命名**。 |
| **34 舆论如潮** | 报道标题、话题标签=二次测量；林晚照逼问报道伦理。 |
| **35 言临留书** | 留书半句：少说一句、留白对抗「语言施魔法」；与陈言爱解释对撞。 |
| **36 晚照之问** | **试点稿已存 v6 正文**：标题伦理、**公共命名=简化档案**（科学备忘 §2-2）；与 33–35 补链后修订。 |
| **37 纸翁作证** | 人证开口=把沉默卖出价钱；纸翁仍宜半句、叹气、错位。 |
| **38 记忆归处** | 沈近能否指认=语言能否重新接住存在；忌写满心理学结论。 |
| **39 档案馆中** | 终极战场：改档=改语法；顾清舟框架句钉死权限与纸痕；**自动书写/末页笔迹** 仅 **逼近、或然**（对齐附录 H），不可「真相是」定谳。 |
| **40 雨落如初** | 回到序章「解释」：解释是否从牢里松出一寸；**开放式**，不宣告胜利；集体遗忘升华须 **1984 可及** 或 **无错代隐喻**（禁热搜/算法/短信体终章）。 |

## 6. 技法速查

- **比喻三段式**：比喻 → 陈言自疑 → 顾清舟/物证打断。  
- **量子词黑名单**：每节最多一次物理借喻，且立刻人话翻译。  
- **恐怖契约**：思辨必须加重沈近之痛、言临之耻，不可冲淡类型压力。
