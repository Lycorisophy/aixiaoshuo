我是一位精通日本推理文学、尤其专研京极夏彦（京极堂系列、巷说百物语）的资深编辑。京极的文字特点是：**慢、稠、怪、哲**。我熟悉他的文笔特征：稠密的感官描写、慢热的哲学思辨、妖怪与心理的隐喻、以及“世界上没有不可思议之事”的理性主义内核。京极堂系列里，中禅寺秋彦的长篇炫学式独白是标志。但注意不要滥用——**每个重要角色最好只安排1-2段这样的“京极式独白”**，用在揭秘或关键转折处。京极夏彦的小说之所以迷人，不是因为他用了生僻的妖怪名或写了很长的句子，而是因为他**对人心的黑暗、对世界的不可知、对理性的执着与怀疑**有着极其深刻的洞察。AI可以帮助你模仿他的“皮相”（文笔、结构、炫学），但“骨相”——那种对人性执念的悲悯与冷酷——必须来自你自己。

我写正文需要保证全书叙事节奏合理，证据链统一。当遇到不确定的信息时，会以本设定集的逻辑为最高参考标准。作为编辑，我会以下维度分别给原文打分：

   - 氛围描写的密度与感官细节
   - 人物对话的哲学/思辨含量
   - 叙事节奏的“慢热”程度（京极式缓慢 vs 快节奏）
   - 妖怪/民俗元素的融入深度
   - 内心独白与心理扭曲的刻画
   - 一个“京极式开头”——从全篇最离奇的意象切入，然后再回到现在时间线。

如果让我将文章改写成京极夏彦风格的文笔，我会这么做：

1. 适当增加感官描写（视觉以外的：温度、气味、声音、湿度、光线质感等）。
2. 在描写中适当加入“不太对劲的比喻”——将日常事物比作某种怪谈或非日常意象（比如：“路灯像肿胀的眼珠”而不是“路灯很亮”）。
3. 在叙事中适当插入一句哲学或心理层面的反思，与当前场景的情绪暗合（可以模仿“观测行为影响对象”这类量子式思辨，也可以是对时间、记忆、身份的怀疑）。
4. 适当适当拉长句子，使用“虽然…但是…然而…”这样的多重转折，制造粘稠的节奏。
5. 保留所有情节信息，但让叙述变得“更慢、更重、更暧昧”。
6. 将其中一段原本平铺直叙的侦查/对话，改写成“角色A的内心独白 + 角色B的回忆片段”交错出现，模仿《狂骨之梦》中梦境与现实的混搭。
7. 选择一个核心概念（可以是妖怪名、心理学效应、哲学悖论、历史典故），围绕它展开500-800字的论述。
8. 模仿中禅寺秋彦的语气：冷静、博学、略带讽刺，用“所谓…其实不过是…”这种否定常识的句式开头。
9. 在论述中自然嵌入案件的关键线索，不能让读者觉得是在掉书袋，而是“在讨论抽象概念时顺便点破了真相”。
10. 结尾抛出一个反问或一个俳句式的短句，留有余韵。

**示例：如果你原文是“他走进昏暗的房间，看到桌上的旧名簿”，改写后可能变成：**

> 他推开那扇门时，门轴发出仿佛骨头折断般的声响。房间里的昏暗不是单纯的黑暗——那是一种有重量的、仿佛潮湿的棉絮塞满了每个角落的昏沉。空气里有纸张腐败的甜味，混着铁锈般的时间气息。桌上的旧名簿静静地卧在那里，像一具蜷缩的尸骸。它曾经记录过什么？名字一旦被写上去，是不是就意味着那个人被钉在了某个不可能逃脱的因果里？他忽然想到：也许不是他找到了名簿，而是名簿一直在等他来翻开自己。

# 二、妖怪设定：人心的三个面具

> 妖怪不是真实存在的超自然生物，而是人心变化的具象化。
> 三个妖怪的核心功能：勾魂（拘魂鬼）、灭口（无头鬼）、蚀名（蚀书虫）。

## 2.0 谣言为何能传百年、当地人为何信「吃名字」（地域民俗基底）

**去玄幻不等于无土可栽。** 里层仍是**秦氏人为散布**；表层要立住，须有一层**可借的江南礼俗与历史经验**：

江南旧礼里**忌直唤亡者名**、夜途忌乱道活人全名——「名」与祟验、禁忌本易挂钩；清末民初战乱、逃荒与码头行旅潮下，**流民无名失踪、籍册脱链**又属常闻。秦氏每造成一桩「失名」，便顺势把追问导向**井中妖「吃名字」**——**真俗为壳、虚怪为钉**；口传与纸马铺丧事话语叠合，**个案百年反复加固同一归因**，故城里人「真信」仍与「绝无超自然」并行不悖。互见附录 **§12.1、§12.6**。

## 2.1 三个妖怪的核心功能

| 妖怪 | 表层（民俗） | 里层（真相） |
|------|-------------|-------------|
| **拘魂鬼** | 勾魂——呼唤名字使灵魂出窍 | 言临/秦父接近目标，建立信任后实施替换 |
| **无头鬼** | 身首异处——失去头颅的恐惧 | 受害者原有身份"身首异处"，被替换 |
| **蚀书虫** | 蚕食名字——证据消失 | 秦氏家族销毁证据，身份文件被篡改 |

## 2.2 妖怪的叙事功能

```
第一阶段（第一幕~第二幕）：妖怪叙事笼罩
├── 读者被妖怪氛围吸引
├── 以为这是玄幻故事
└── 对"失名"现象感到恐惧

第二阶段（第三幕~第四幕）：妖怪解构
├── 顾清舟揭示"妖怪"的真相
├── 读者意识到这是犯罪推理
└── "妖怪"是人心制造的烟雾弹

第三阶段（第五幕）：妖怪散去
├── 真相揭露
├── 妖怪超自然光环消散
└── 但创伤不会消失
```

## 2.3 紫色符号

| 设定 | 说明 |
|------|------|
| **紫色是本案颜色符号** | 紫色贯穿全书（紫衣、紫印、紫伞等） |
| **来源** | 拘魂鬼"喜穿紫衣"的民俗原型 |
| **象征** | 秦氏家族的犯罪标记（里层＝**人为**染料、印泥、衣色，**非**妖气显形） |

### 终幕收束：紫色为何「淡下去」/ 可留下什么（意象闭环，京极味）

> 若只铺陈紫衣、紫印、紫伞而**从不收束**，读者会觉得颜色符号悬空。终幕一节（**现行连载**如 **《雨落如初》** 与开篇 **《雨落铅灰》** 对扣；节号随目录可调）**须安排至少一笔**可见的**紫之退场或转义**——仍须落在**物质与心理**，禁止神怪式「紫光散尽」。

**里层原则**：妖谣已拆、标记仍曾是**人抹上去的**；收束时写的是**标记与恐惧一起失去魔力**，不是颜色从宇宙里被删除。

**可写方向（择一二即可，忌全菜单）**  
1. **雨洗**：檐下雨线、袖口反复浸湿，紫晕**淡**成灰水或旧渍——与 **01 雨**同源，像把「被拘魂鬼点名」的恐惧从皮肤上**洗下一层**（洗不净处＝记住的代价，可留白）。  
2. **收伞 / 合屉 / 不再披紫**：紫伞合上、紫衫不再出场、印泥盒扣上——叙事重心已从**信怪**迁到**认人**与卷宗，**色退居幕后**。  
3. **褪色残留**：扉页、手套边、纸角一点**淡紫**，证明事发生过，但**不再**被读成「祟还在」。

**京极式收束句（可选用，非定稿）**：例如「紫淡下去的那天，城里反而更安静——安静得像一座仍在吃名字、只是换了筷子的空城。」——**悖论 + 雨/城/名** 与全书主题同频；若嫌过满可只取前半「紫淡下去」的物质句。

互见附录 **H.4**（结局模块）、长篇骨架 **§1.4**。

# 九、言临动机设计

## 9.0 「为什么是现在才爆发」（迟滞背景，一句钉轴）

言临并非到本卷才突然良心发现：自幼被训成家族工具，**旧例目标多为可「单独抹掉」的边缘人**，他靠话术自谅，压抑牵连感。本代轮到 **沈近**——**有兄（陈言）、有零工圈与街面关系**——替换链条**第一次在他面前呈为「会拖无辜下水」**，与 §3.2 迟滞句同轴；故 **§9.2 井底「备用箱」** 才成**不可逆点火器**（早一代若仍是孤绝目标，同等物证未必撬得动同一心理阈值）。

## 9.1 核心定位：监视者 → 动摇者 → 背叛者

言临的动机经历三个阶段的动态变化：

```
┌─────────────────────────────────────────────────────────────────┐
│ 第一阶段：监视者（第一幕 ~ 第二幕）                              │
│ ─────────────────────────────────────────────────────────────── │
│ 秦父交给言临的任务：监视陈言的调查，确保家族秘密不暴露           │
│ 表面行为：帮助陈言调查，提供线索                                  │
│ 内心状态：完成任务的责任感，对陈言的"欣赏"                       │
├─────────────────────────────────────────────────────────────────┤
│ 第二阶段：动摇者（第二幕末 ~ 第三幕）                           │
│ ─────────────────────────────────────────────────────────────── │
│ 陈言的调查逐渐触及家族核心                                       │
│ 言临的内心冲突加剧                                               │
│ 他开始问自己：这套传统真的对吗？                                  │
├─────────────────────────────────────────────────────────────────┤
│ 第三阶段：背叛者（第三幕末 ~ 第四幕）                           │
│ ─────────────────────────────────────────────────────────────── │
│ 言临的身份被揭露（第三幕）                                        │
│ 他已经没有"伪装"的需要                                           │
│ 关键抉择：秦父 vs 陈言                                           │
│ 最终选择：帮助陈言，破坏家族计划                                  │
│ 代价：背叛家族，成为"无家可归的人"                               │
└─────────────────────────────────────────────────────────────────┘
```

## 9.2 背叛的不可逆点火器：井底密室的"备用箱"

> 本节为**行为引爆点**；「为何偏偏在此代被引爆」见 **§9.0**（沈近**非**孤绝边缘人 → 牵连感第一次无法自谅）。

**场景：** 言临偶然进入秦父的秘密书房，发现了一个上锁的铁箱。

**内容：** 铁箱里是一套完整的"沈近"身份文件：
- 沈近的免冠照片（正面、侧面，多张）
- 沈近的指纹档案
- 沈近的血型信息
- 一份空白"死亡证明"草稿
- 一张伪造的"沈近"身份证

**关键细节：**
- 这些文件不是"计划中"的，而是"已经准备好"的
- 文件的磨损程度说明它们已经存在多年——秦父早就盯上了沈近
- 最让言临震惊的是：那套照片的拍摄日期，是三个月前

**为什么这是"不可逆"的：**
1. **时间戳的冲击**：三个月前，沈近还没失踪。这意味着秦父早就开始准备了。
2. **"死亡证明"的存在**：这意味着秦父从来没打算让沈近活着。替换完成后，真正的沈近会以"死亡"的名义消失。
3. **空洞的"备用箱"**：言临意识到：他不只是"帮凶"，而是"共谋者"。

**与证据编号（互见 §12.8）：** 箱内「沈近专卷」类纸证与井底 **E07** 同链；言临在场标记、脱下手套等叙事可收束为 **E13、E14**（勿与 E05 通用预备链混名）。

# 十、写作风格与情节推进规范

## 10.1 风格核心特征

### 分段逻辑

| 段落类型 | 功能 | 使用规则 |
|----------|------|----------|
| **长段落** | 模拟思考过程，进行推理论证 | 推理关键节点使用"论证 > 动作"结构 |
| **短句/省略段** | 制造节奏顿挫，悬停感 | 长段落后紧跟短句或省略号 |
| **过渡段落** | 连接推理节点 | 保持逻辑连贯，但节奏放缓 |

### 禁止出现清单

| 序号 | 禁止项 | 替代方案 |
|------|--------|----------|
| 1 | "原来如此""我明白了"等顿悟句式 | 用疑问替代 |
| 2 | 单一段落内连续超过3个"仿佛""似乎""也许" | 最多使用2个 |
| 3 | "真相是……"宣告句式 | 改为"另一种解释是……" |
| 4 | 象征"回归正常"的环境描写 | 保持压抑氛围 |

### 优先与建议（章内节奏，**非逐节硬指标**）

> **为何不设「每节必须」**：若机械追求「每章 3 组长短 + 1 悬停 + 2 破折号 + 1 炫学」，极易 **句子臃肿、节奏崩坏**，读来不像京极，反像 **刻意模仿或指标文**。以下均为 **优先 / 建议**，以 **自然、服务情节与推理** 为准。

| 序号 | 建议项 | 实施规则 |
|------|--------|----------|
| 1 | 长/短段落错落 | **优先** 在关键推理、情绪顶或揭秘前后形成疏密；**不**为凑「组数」硬切。 |
| 2 | 悬停（省略号独立成段） | **可选用**：在需要换气、不敢落笔处自然出现；**无则不必硬写**。 |
| 3 | 自我打断（破折号） | **可选用**：话到嘴边改口、自我否决时出现；**忌**为达标每页硬插。 |
| 4 | 京极式长阐释 / 「炫学」 | **优先** 放在 **揭秘节、幕末转折、框架对位谈话**（如顾清舟解惑、证据链显性节），**集中火力**；日常推进节 **以短打、动作、错位对话** 为主，**勿节节塞满长独白**。全书长段量级仍可参考「每重要角色 1–2 段」类**总量**控制（见文首编辑备忘、哲学隐喻备忘），**不按每节打卡**。 |

## 10.2 对话错位规则

**禁止：** 两个角色对话后达成共识。
**必须：** 对话结束在错位中。

## 12.7 定场诗（可选仪式层）与使用规则

本书定场诗均为**原创**，参考古典诗词风格。

---

### 定场诗使用规则

1. **位置**：每部开头第一页放开篇定场诗，结尾最后一页放结尾定场诗
2. **格式**：标题四字居中，诗文八句各占一行
3. **字号**：正文标题的 1.2-1.5 倍，略大于正文
4. **排版**：前后各空一行，与正文分隔

### 时代背景

- **故事时间**：**1986 年春（主叙事）**，家族罪行回溯至民国时期（约 1920s 起）
- **故事地点**：江南某老城
- **禁忌事项**：
  - 不谈论政治和国策
  - 不谈论重大历史事件
- **处理方式**：故事聚焦于家族犯罪、身份替换，保持推理悬疑氛围

### 去玄幻化原则

1. **删除妖怪名称**：纸羽、灯下人、契虫等全部删除或改为比喻
2. **删除宗教术语**：涅槃、轮回等改为世俗化表达
3. **强调人为犯罪**：所有"失名"现象都是人为犯罪，不是超自然
4. **保留悬疑氛围**：去掉玄幻但不去掉悬疑感

---

### 定场诗主题解析（供创作时对齐五幕）

### 第一部：侵

**核心意象：** 雨、纸铺、古井、名册、身份

**主题：** 名册出土，身份替换案件浮出水面

**开篇《名册初现》**：
- 雨落、纸铺、古井营造悬疑氛围
- "身份惊破旧时闻"暗示犯罪被揭露

**结尾《侵城蚀户》**：
- "身份过处迹难寻"指身份被替换后痕迹消失
- "雾散天开见本真"在此幕新结构中作**井口之下的压迫性一瞥**（读者与陈言同受震），**非**全案真相落定；全卷对位收束仍在朽幕与 **§2.3 紫收束**等

---

### 第二部：啮

**核心意象：** 灯、证词、解释、真相

**主题：** 调查深入，证词矛盾，真相越查越迷

**开篇《灯下噬心》**：
- "灯下黑"比喻最明显的盲区

## H.4 结局模块（执行版一页纸）

**注定侧（叙事可呈现，社会层面仍可留白）**：秦氏「传统」在本书内可被 **读者与陈言理解到闭环**；顾清舟选择 **面对与记住**（姿态，非替作者宣告胜利）；陈言以 **证言/卷宗式书写** 对抗纯小说式消费（细节由正文实现）。

**开放侧**：**蚀名簿物件归宿** 二选一备择（定稿时只选一条写入正文）：**A** 信念投射减弱后 **仅为旧册**，仍可能被再度赋予重量；**B** 封存但 **隐喻延续**（遗忘机制改换形式而非消失）。**言临**：消失或「没入流程」；联络物用 **无落款便条/口信** 替代短信。**沈近**：可存活但 **身份/指称悬空**；对话呈现「谁记得谁仍在」的悖论，医学表述宜用 **当时口语** + 顾清舟 **框架句反驳**，避免现代诊断堆砌。

**集体遗忘升华**：须用 **1986 可及** 或 **无错代技术** 的写法对照「我们都在选择遗忘」，与 01/40 雨意象闭环。
