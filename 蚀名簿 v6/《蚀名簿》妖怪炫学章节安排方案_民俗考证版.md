## 一、三个妖怪的真实民俗考证

### 1.1 拘魂鬼（真实民俗）

**民俗出处**：《中国百鬼录》、《聊斋志异》等民间传说

**民俗原文描述**：
> "拘魂鬼，相貌与常人无异，经常是两人一起出入，喜穿紫衣。他们身上藏有将死者的名字和时间的名册，按照时间到达将死者的身边，出声呼唤将死者的名字。听到他们呼唤的人，灵魂就会出窍。之后拘魂鬼会拿绳索捆住魂魄，将其带往冥界。"

**民俗特征提取**：
| 特征 | 民俗描述 | 本书对应 |
|------|---------|----------|
| **外形** | 相貌与常人无异 | 秦氏成员伪装成普通人 |
| **数量** | 两人一起出入 | 秦氏家族代际搭档 |
| **服装** | 喜穿紫衣 | 紫印符号体系 |
| **道具** | 身藏名册（记载将死者名字和时间） | 蚀名簿 |
| **能力** | 呼唤名字→灵魂出窍 | 身份替换 |
| **后续** | 绳索捆魂→带往冥界 | 销毁证据→抹除存在 |

**对应犯罪逻辑**：
```
第一步：接近目标（伪装成普通人）→ 第二步：建立信任 → 第三步：呼唤名字（实施替换）
```

### 1.2 无头鬼/獝狂（真实民俗）

**民俗出处**：
- 《后汉书·礼仪志中》刘昭注引三国魏张揖《埤苍》："獝狂，无头鬼。"
- 《汉书·扬雄传上》王先谦补注引隋萧该《汉书音义》："獝狂，无头鬼也，见《字林》。"

**民俗原文描述**：
> "没头的鬼。指神话中的獝狂。《汉书·扬雄传上》'梢夔魖而抶獝狂'。"

**民俗特征提取**：
| 特征 | 民俗描述 | 本书对应 |
|------|---------|----------|
| **外形** | 没头的鬼 | 失去原有身份的人 |
| **本质** | 獝狂（无头之意） | 原有身份被"斩首" |
| **行为** | 被驱赶的恶鬼 | 受害者被动成为"影子" |

**对应犯罪逻辑**：
```
原有身份"身首异处" → 被替换者的身份寄生在受害者身上 → 受害者成为"无头的影子"
```

---

### 1.3 蠹鱼/蛀书虫（真实民俗）

**民俗出处**：
- 《汉书·五行志中之下》："昭帝时，上林苑中大柳树断仆地，一朝起立，生枝叶，有虫食其叶，成文字。"
- 《酉阳杂俎》、《聊斋志异·素秋》记载蠹鱼（又名衣鱼、书虫）
- 《仙经》："蠹虫三食神仙字，则化为此物，名为脉望"

**民俗原文描述**：
> "蠹鱼，古文中蛀书虫，学名衣鱼。俗称蠹、蠹鱼，白鱼、壁鱼、书虫。身披银鳞、形似小鱼，最爱啃食古籍纸张里的淀粉。"

**延伸含义**：
- 比喻埋头苦读的人，含有食古不化之意（韩愈："岂殊蠹书虫，生死文字间"）
- 古代读书人既恨蠹鱼毁书，又因其与典籍亲近而偏爱有加
- "脉望"：蠹鱼吃够神仙字后化成的神奇之物，可通鬼神

**民俗特征提取**：
| 特征 | 民俗描述 | 本书对应 |
|------|---------|----------|
| **外形** | 银鳞小鱼状 | — |
| **习性** | 啃食古籍纸张 | 销毁身份文件 |
| **对象** | 书籍、字迹 | 名字、记录 |
| **结果** | 文字被吞噬 | 证据消失 |

**对应犯罪逻辑**：
```
销毁受害者的一切记录 → 名字从世间"消失" → 后人无从查证
```

### 2.2 第一次炫学：引子与种因（第05-07节）

**目标**：顾清舟首次提及"名字被吞噬"的民俗，种下疑惑
**主视角**：顾清舟（通过陈言在场转述）

#### 第05节《雾中逢君》——衔霜楼茶室

**前置事件**：陈言初遇言临，听闻"井底传说"
**炫学内容**：顾清舟提及"名字被吞噬"的民俗，提出民俗学式的疑问

```
【顾清舟语录·民俗引入】

"你有没有听说过'拘魂鬼'？"

我在他对面坐下。他已经沏好了茶，茶汤碧绿，热气袅袅。

"拘魂鬼？"

"《百鬼录》里记载的一种鬼。"
他端起茶杯，目光落在我手中的字条上。
"据说它相貌与常人无异，经常两人一起出入，最显著的特征是——喜穿紫衣。"

"紫衣……"

"对。它身上藏有一本名册，记载着将死者的名字和死亡时间。按照那个时间，它会出现在将死之人身边，呼唤那人的名字。"

"然后呢？"

"然后被叫到名字的人——"
他停顿了一下，
"灵魂就会出窍。拘魂鬼用绳索捆住魂魄，带往冥界。"

我盯着他："这是迷信吧？"

"是迷信。"
他把茶杯放下，
"但迷信往往藏着某种真实的内核。"

"什么内核？"

"你有没有想过——"
他看着我，
"'名字'这种东西，为什么会被'吃掉'？"
```

**功能**：
- ✓ 引入拘魂鬼民俗（喜穿紫衣、藏有名册、呼唤名字）
- ✓ 顾清舟展示"民俗学方法"：剥开迷信看内核
- ✓ 为后续埋下伏笔

#### 第07节《户籍涂痕》——市政档案中心

**前置事件**：陈言发现户籍涂改痕迹
**炫学内容**：顾清舟分析"涂改"背后的系统性操作

```
【顾清舟语录·民俗印证】

"这不是普通的涂改。"

顾清舟把档案举到灯光下。光束穿过泛黄的纸张，照出墨迹覆盖的层次。

"看这个覆盖关系——新的墨迹下面，是旧的墨迹。不是一次涂改，是两次、三次。"

"所以有人改过？"

"不止。"
他说，
"看这个规律。同一批档案，同一种笔迹，同一种涂改方式。涂改的位置都在'姓名'和'身份'栏。"

"……"

"这不是一个人能完成的工程。"
他的声音很平静，
"这是一套系统。一套持续了很久的系统。"

"持续了多久？"

他没有回答。只是看着窗外。窗外是灰蒙蒙的天空，像一张洗褪色的旧纸。

"很久。"他终于说，"久到足以成为'传统'。"

"传统？"

"你有没有听说过——"
他转过身来，
"有一种贼，不是偷东西，是偷'名字'？"

"偷名字？"

"'盗名字'。"
他说，
"《后汉书·马援传》里有句话：'天下反覆，盗名字者不可胜数。'"

"什么意思？"

"意思是有些人，不是偷财物，是偷取别人的'名义和称号'。"

他指了指那本被涂改的档案。

"名字被偷走的人，社会上就不会再有他的记录。户籍涂掉，档案销毁，照片销毁——"

"他就'不存在'了。"我喃喃道。

"对。"
顾清舟的声音很轻，
"比死更可怕的，是'从未存在'。"
```

**功能**：
- ✓ 引入"盗名字"典故（《后汉书》）
- ✓ 揭示"系统性犯罪"的存在
- ✓ 深化"名字消失"的主题

### 2.3 第二次炫学：解构第一妖——拘魂鬼（第21-24节）

**目标**：全面解构"拘魂鬼"，揭示信任背叛的本质
**主视角**：顾清舟为主

#### 第21节《日记残章》——衔霜楼二楼藏书室

**前置事件**：发现秦氏老宅的旧日记
**炫学内容**：顾清舟讲解"拘魂鬼"的民俗起源与真相

```
【顾清舟语录·拘魂鬼民俗溯源】

"'所谓拘魂鬼——'"

顾清舟翻开一本泛黄的民俗志。书页脆得像枯叶，翻动时有细碎的沙沙声。

"'喜穿紫衣，两人同行，身藏名册。届期至将死者之家，登门唤名。闻者魂离，绳之以索，拘往冥途。'"

他念完，抬起头来。

"这是《百鬼录》的原文。你看，它有几个关键要素。"

他竖起手指。

"第一，'喜穿紫衣'——它有标志性的服装。"

"第二，'两人同行'——它不是单独行动，是搭档。"

"第三，'身藏名册'——它有记录工具，记录的不是普通信息，而是'名字'和'死亡时间'。"

"第四，'登门唤名'——它不是远程作案，必须亲自到场，呼唤名字。"

"第五，'魂离、绳索、冥途'——这是一个完整流程。"

他合上书。

"这套描述太具体了。不像是凭空想象，更像是——"

"像是记录。"我说。

"对。"
他看着我，
"像是目击者的记录。"

"你是说……真的有人见过？"

"不。"
顾清舟摇头，
"我是说——这描述的不是鬼。是'人'。"

"人？"

"穿着紫衣的人。两人搭档。带着名册。按时上门。叫人名字。然后——"

他停顿了。

"然后那个人就从社会上消失了。"

"……"

"你觉得这像什么？"

我想了想。

"像……杀手？"

"杀手。"
他重复了一遍这个词，
"但杀手不会'叫名字'。杀手不会'带着名册'。杀手也不会——"

他看着我。

"——让被杀的人'灵魂出窍'。"

"那是什么意思？"

"意思是——"
顾清舟的声音很轻，
"被杀的人，不只是肉体死亡。是他的'身份'也一起死了。"

"户籍、档案、照片、社会关系——全部被抹除。"

"在这个世界上，再也没有任何痕迹证明他'存在过'。"

"这不就是'灵魂出窍'吗？"

"不就是'魂离'吗？"

他把书合上。

"所谓'拘魂鬼'，不是超自然生物。"

"是'把人变成鬼'的人。"
```

**功能**：
- ✓ 逐条分析拘魂鬼民俗要素
- ✓ 揭示"目击者记录"的本质
- ✓ 顾清舟正式揭示"妖怪=人"

#### 第23节《对质之困》——秦氏老宅外围

**前置事件**：发现地下室入口
**炫学内容**：顾清舟揭示"拘魂鬼"是秦氏家族的自我描述

```
【顾清舟语录·紫衣与名册】

"紫衣。"

我站在秦氏老宅的门外，看着那块斑驳的门楣。字迹剥落，但隐约还能辨认出一个"秦"字。

"《百鬼录》里说，拘魂鬼'喜穿紫衣'。"

顾清舟站在我身边，声音很平静。

"紫衣在古代不是随便穿的。《韩非子》说'王请自解紫衣而朝'——紫衣是君服，是贵官的服饰。"

"所以……"

"所以'穿紫衣的拘魂鬼'，不是穿得像乞丐的鬼。是穿得像贵族的鬼。"

他指了指门楣上隐约可见的紫色痕迹。

"你看那个。"

"是紫漆？"

"不。是印。"
他走近了一步，
"一种印记。不是装饰，是标记。"

"什么标记？"

他没有回答。只是从怀里掏出一张纸——是陈言从井底密室里找到的那页蚀名簿的拓印。

"你注意看这个。"

他把拓印举到阳光下。紫色的印痕清晰可见。

"'身藏名册'，是《百鬼录》对拘魂鬼的描述。"

"这本蚀名簿——"

"不是'妖怪吃名字的记录'。"

顾清舟的声音很轻。

"是'拘魂鬼作业的工单'。"

"谁被拘，谁的名字就被写在这上面。"

"写上去之后——"

"那个人就'魂离'了。不是灵魂出窍，是从社会上消失。"

"户籍、档案、照片——全部被'拘'走，藏在这口井里。"

"所以它叫'蚀名簿'。"

"不是'吞噬名字'，是——"

"'掠取名字'。"

"'偷盗名字'。"

"'盗名字'。"

他看向那扇斑驳的门。

"所谓'拘魂鬼'，不是什么妖怪。"

"是穿着紫衣、带着名册、按时上门——"

"把人的名字偷走的人。"

"他们的名册上，记录的不是'死亡时间'。"

"是'替换时间'。"
```

**功能**：
- ✓ 揭示"紫衣"的阶级含义
- ✓ 揭示"紫印"的标记功能
- ✓ 正式定义"蚀名簿"=盗名字的工单

### 2.4 第三次炫学：解构第二妖——无头鬼/獝狂（第29-32节）

**目标**：解构"无头鬼"，揭示身份替换的核心手法
**主视角**：言临独白为主，顾清舟补充

#### 第29节《井底之声》——井底密室

**前置事件**：言临带陈言进入密室，发现大量证据
**炫学内容**：言临（内心独白）分析"无头鬼/獝狂"的本质

```
【言临独白·无头鬼民俗溯源】

我站在密室中央。四周是泛黄的档案，是成对的照片，是时间的残骸。

"'獝狂'。"

我听见自己用一种很平静的声音念出这个词。

陈言看着我。

"獝狂，"
我指了指墙上的照片——两张脸，像镜子里的倒影，
"《后汉书·礼仪志》引《埤苍》说：'獝狂，无头鬼也。'"

"《汉书·扬雄传》注也说：'獝狂，无头鬼也，见《字林》。'"

"无头鬼。"

我转过身，看着那些成对的照片。

"你有没有想过——'无头'是什么意思？"

"……"

"字面意思是'没有头'。但在古代，头不只是脑袋。"

我拿起一张照片。

"头是'首'。首是'最先'。最先的是什么？"

陈言没有回答。

"是'身份'。"
我把照片放下，
"一个人在这个世界上的'最先'，是他的名字。他的户籍。他的档案。"

"这些确定了，'这个人'才存在。"

"但如果——"

我指了指照片里的两张脸。

"如果有一天，有人把你的'头'砍掉，然后把自己的头接到你的脖子上呢？"

"……"

"你的身体还在。你的脸还在。但'你'已经不存在了。"

"'你'变成了'他'的影子。"

"一个没有'头'的影子。"

"'无头鬼'。"
我的声音很轻，
"可怕的不是'没有头'。"

"可怕的是——你的头还在，但已经不属于你了。"

"你活着，但你的'身份'死了。"

"你站在这里，但所有人叫你的是另一个名字。"

"你走到任何地方，用的是另一个人的证件，过的是另一个人的人生。"

"'你'——"

"消失了。"

"变成了一个影子。一个附庸。一个'无头鬼'。"

我放下照片。

"这才是'獝狂'真正的可怕之处。"

"不是物理上的身首异处。"

"是社会学上的'身份斩首'。"
```

**功能**：
- ✓ 引用真实典籍：《后汉书》、《汉书》、《埤苍》、《字林》
- ✓ 揭示"无头"的双重含义（物理/社会学）
- ✓ 言临内心挣扎的展现

#### 第31节《双生之影》——秦氏老宅地下室

**前置事件**：发现沈近被关押
**炫学内容**：顾清舟补充"替身"的心理学机制

```
【顾清舟语录·身份斩首】

"'梢夔魖而抶獝狂。'"

顾清舟站在地下室入口，看着那些成对的照片。

"这是《汉书·扬雄传》的原文。"

"'夔'是一种单足怪兽，'魖'是黑颜色的鬼。'獝狂'是'无头鬼'。"

"这句话的意思是：用夔和魖来驱赶无头鬼。"

"驱赶？"

"对。在汉代的丧葬仪式中，有'大傩'——大规模的驱鬼仪式。"

"十二神追恶凶，驱逐各种鬼怪，獝狂就是其中之一。"

他转过身来。

"但你有没有注意到一个问题？"

"……"

"为什么要驱逐'无头鬼'？"

我愣住了。

"因为……它吓人？"

"不。"
顾清舟摇头，
"因为'无头鬼'代表着一种'不完全的死亡'。"

"……"

"正常情况下，人死了就走了。鬼是死人的魂，完成了从生到死的转变。"

"但'无头鬼'不一样。"

"它没有头——也就是说，它失去了'身份'。"

"一个失去身份的鬼，没办法投胎转世，没办法安息。"

"它只能徘徊在人世间，以'别人的影子'的形式存在。"

他看着照片里那些成对的脸。

"这才是'替身'最可怕的地方。"

"不是'杀死一个人'。"

"是'杀死一个人的身份，然后让另一个人冒充这个身份活下去'。"

"被冒充的那个人——"

"变成了'无头鬼'。"

"一个活着的、但已经没有'头'的鬼。"

"'獝狂'。"

他的声音很轻。

"'无头鬼'。"

"不是因为它没有脑袋。"

"是因为它的'身份'被偷走了。"

"它活着，但它是另一个人。"

"它有名字，但那是偷来的名字。"

"它有脸，但那是借来的脸。"

"它的一切——"

"都是别人的。"

"它变成了一个'影子'。"

"一个附庸。"

"一个——"

"'无头'的鬼。"
```

**功能**：
- ✓ 引用真实典籍：大傩仪式、《汉书》
- ✓ 揭示"不完全的死亡"的可怕
- ✓ 深化"替身"的心理学含义

### 2.5 第四次炫学：解构第三妖——蠹鱼/蛀书虫（第37-40节）

**目标**：解构"蠹鱼"，揭示证据销毁的本质，完成全面升华
**主视角**：顾清舟为主，陈言补充

#### 第37节《纸翁作证》——瑞成纸马铺

**前置事件**：纸翁愿意作证
**炫学内容**：顾清舟/纸翁讲解"蠹鱼/蛀书虫"的真相

```
【顾清舟语录·蠹鱼民俗溯源】

"'蠹鱼'。"

顾清舟在纸翁的店铺里，看着那些纸扎。

"你知道这个典故吗？"

纸翁沉默着。

"《汉书·五行志》记载：'昭帝时，上林苑中大柳树断仆地，一朝起立，生枝叶，有虫食其叶，成文字。'"

"虫食其叶，成文字——虫吃树叶，结果叶子上出现了文字。"

"这是'蠹鱼'最原始的意象：一种会'吃字'的虫。"

他转向纸翁。

"但《仙经》里还有另一个说法。"

"'蠹虫三食神仙字，则化为此物，名为脉望。'"

"蠹鱼吃够三次'神仙字'，就会变成'脉望'——一种通鬼神的神奇之物。"

"……"

"但纸翁，你觉得蠹鱼真的能'吃字'吗？"

纸翁沉默了很久。

"不能。"他终于说，声音像从很深的地方打捞上来。

"字是纸上的墨迹。虫吃的是纸，不是字。"

"对。"
顾清舟点头，
"虫咬的是纸，不是字。"

"但当纸被咬烂，上面的字也跟着消失了。"

"外人看来，就像是'字被吃掉了'。"

他看向纸翁。

"纸翁，你做纸扎的时候，有没有烧过别的东西？"

纸翁的身体僵住了。

"不是纸扎。"顾清舟的声音很轻，"是档案。是照片。是任何能证明'那个人存在过'的东西。"

"……"

"蠹鱼吃的是纸。"

"但烧掉纸的人——"

"才是真正的'蠹鱼'。"

"'蛀书虫'。"

"'食字鬼'。"

他看着纸翁。

"不是虫在吃字。"

"是'用虫吃字做借口的人'在吃字。"

"虫子吃纸是本能，无可厚非。"

"但人烧档案是选择——"

"是'让那个人消失'的选择。"

纸翁低下头。

"'蚀名簿'的'蚀'——"

顾清舟合上书。

"不是虫在蚀。"

"是人用虫做借口，在蚀。"

"蚀掉的，是一个人的名字。"

"蚀掉的，是证明'那个人存在过'的全部证据。"

"'蚀名簿'——"

"不是虫吃名字的记录。"

"是'以虫吃字为借口，把人变成无名鬼'的——"

"共犯名单。"
```

**功能**：
- ✓ 引用真实典籍：《汉书·五行志》、《仙经》
- ✓ 揭示"蠹鱼/脉望"的民俗意象
- ✓ 揭示"蚀"的真正主体

#### 第39节《档案馆》——三妖一体的终极升华

**场景**：档案馆或衔霜楼
**前置事件**：陈言整理所有证据
**炫学内容**：顾清舟进行三妖一体的总结性分析

```
【顾清舟语录·三妖一体】

"你有没有发现一个规律？"

顾清舟指着桌上的那些证据——照片、档案、蚀名簿。

"三个妖怪。三个阶段。"

"……"

"'蠹鱼'是第一阶段：食书。"

他指了指那些被销毁的档案。

"找到目标之后，先'吃'掉他能证明自己身份的一切。档案、户籍、照片——全部销毁。"

"这样，外人就没办法证明这个人'存在过'。"

"'蠹鱼'，先把'名字'吃掉。"

"然后呢？"

"'无头鬼'是第二阶段：斩首。"

他拿起一张成对的照片。

"身份证明销毁之后，下一步是'替换'。"

"找一个外貌相似的人，取代他的位置。"

"被取代的那个人——他的'头'被砍掉了。不是物理上，是社会学上。"

"他失去了自己的名字、自己的身份、自己的人生。"

"变成了一个'影子'。一个'无头鬼'。"

"'獝狂'，再把'人头'偷走。"

"最后呢？"

"'拘魂鬼'是第三阶段：收魂。"

他把蚀名簿放在桌上。

"替换完成之后，需要有人来'收尾'。"

"把替换的证据记录下来，把'作业'流程写进名册。"

"紫衣是标记，名册是工单，呼唤名字是'验收'。"

"整套流程——"

"像不像流水线上三个工位？"

"蠹鱼负责'吃'原料。"

"无头鬼负责'加工'产品。"

"拘魂鬼负责'打包出货'。"

"……"

"这不是三个妖怪。"

顾清舟的声音很轻。

"是一个'连续作案、持续百年、流水线作业'的——"

"犯罪家族。"

"'蠹鱼'不是虫，是销毁证据的帮凶。"

"'无头鬼'不是鬼，是失去身份的受害者。"

"'拘魂鬼'不是鬼，是穿紫衣、带名册、上门盗名的——"

"作业人员。"

他合上蚀名簿。

"三个'妖怪'，不是三种妖怪。"

"是三个分工、三种角色、三个阶段。"

"剥开那层'妖怪'的外衣——"

"里面只有人。"

"只有'选择'用这种方式害人的人。"

"但这还不是最可怕的部分。"

"最可怕的是——"

"他们给自己取了这个名字。"

"'拘魂鬼'。'无头鬼'。'蠹鱼'。"

"他们知道自己在做什么。"

"他们给自己起了'妖怪的名字'——"

"这样他们就可以告诉自己：'不是我，是妖怪。'"

"'不是我在偷名字，是拘魂鬼在拘魂。'"

"'不是我在斩首，是无头鬼在砍头。'"

"'不是我在吃字，是蠹鱼在食书。'"

"给自己取个妖怪的名字——"

"是自我欺骗的最后一层窗户纸。"

"'不是我选择害人，是妖怪要吞噬名字。'"

他看向窗外。窗外是灰蒙蒙的天空。

"但剥开那层妖怪的外衣——"

"里面只有人。"

"只有'选择'害人的人。"
```

**功能**：
- ✓ 三妖一体的终极揭示
- ✓ "犯罪流水线"概念的升华
- ✓ "自我欺骗"的心理机制

#### 第40节《雨落如初》——最终主题收束

**场景**：衔霜楼或雨中老城
**前置事件**：真相揭示后的余韵
**炫学内容**：陈言的最终反思

```
【陈言（最终独白）】

蚀名簿被摆在桌上。

在灯光下，它看起来只是一本旧书——纸张泛黄，墨迹斑驳。

它不发光。不呼吸。没有心跳。

"所以，"我说，"没有妖怪。"

"没有。"

"没有超自然力量。"

"没有。"

"那些消失的人——"

"被杀了。被偷了。被'蚀'掉了。"

"然后呢？"

"然后，因为没有人'愿意'记得他们——"

"他们就真的被遗忘了。"

"但为什么没有人愿意记得？"

顾清舟沉默了一会儿。

"你有没有想过——"

他说，

"秦家不是例外。"

"什么意思？"

"你以为蚀名簿是秦家'发明'的。但也许——"

他停顿了。

"蚀名簿是秦家'发现'的。"

"发现？"

"在秦家之前，有没有别的人也需要'让某些人消失'？"

"在秦家之后，有没有别的人也在'不需要名字的人'？"

我想起了——

战乱年代的失踪者。

政治运动中的"不存在的人"。

被家庭抛弃的老人。

被社会忽视的流浪者。

失踪之后，没有人找的"无名氏"。

"你是说——"

"我是说——"

顾清舟的声音很轻。

"蚀名簿只是一个'极端版本'。"

"蠹鱼吃的是书上的字。秦家吃的是人间的名字。"

"但'吃字'这件事——"

"我们每个人都在做。"

"我们忘掉那些不方便记住的事。"

"我们忽略那些不愿意见到的人。"

"我们删除那些不想承认的过去。"

"'蠹鱼'不是什么妖怪。"

"'蠹鱼'是我们每个人心里那条虫。"

"那条专门吃'不想记得的东西'的虫。"

他看向窗外。雨还在下。

"秦家是那面镜子——"

"它让我们看到自己。"

"看到我们有多擅长'遗忘'。"

"多擅长把'别人'变成'无名氏'。"

"多擅长——"

"'蚀名'。"
```

**功能**：
- ✓ 终极主题升华：集体遗忘
- ✓ 三妖民俗意象的最终呼应
- ✓ 开放式结局
