## 写作工作流（防跑偏）

1. **开写前**：在《章节任务卡》填好本节「推进点 / 影子线索 / 误导 / 钩子」；对照《长篇骨架》该节一行。  
2. **批次**：建议 **2 节一批**；每批交付：正文 + 任务卡勾选 + 披露自检 + 影子线索台账（记「本节影子 → 计划回收节」）。  
3. **硬纪律**：E01–E16 **仅从第 33 节起**可明确命名；01–32 只投放影子线索。第一幕禁用词与第二幕「现象优先、勿定案级家族结论」见规则文件。  
4. **进度**：每完成一节，更新 [《蚀名簿》写作进度.md](./《蚀名簿》写作进度.md)。

当前节点与下一批任务以 **写作进度** 文件为准。
