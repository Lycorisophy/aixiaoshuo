# 一、核心设定确认

## 1.1 五大核心决定

| 问题 | 选择 | 说明 |
|------|------|------|
| **时间跨度** | 一百年（3-4 代人） | 从民国时期开始，约 1920s-2020s |
| **井底设定** | 藏身份文件和遗物 | 不藏尸体，避免法医学漏洞 |
| **言临动机** | 主动想打破家族传统 | 内心挣扎，"加害者也是被害者" |
| **结局** | 开放式 | 不明确说是否公开真相 |
| **妖怪元素** | 作为"社会心理"保留 | 妖怪是人心制造的烟雾弹 |

## 1.2 双层结构

```
┌─────────────────────────────────────────────────┐
│                    表层（妖怪故事）              │
│  名册 = 记录"名字"的玄幻档案                     │
│  失名者 = 被妖怪吞噬的人                         │
│  井底 = 通向"名册意识"的神秘空间                 │
│  容器 = 吸收灵魂的玄幻存在                       │
└─────────────────────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────┐
│                    里层（犯罪真相）              │
│  名册 = 犯罪记录（被害者身份信息）               │
│  失名者 = 被秦氏家族陆续杀害的人                │
│  井底 = 藏匿身份文件和遗物的密室                 │
│  容器 = 真凶本人或帮凶（一直在场）               │
└─────────────────────────────────────────────────┘
```

# 二、妖怪设定：人心的三个面具

> 妖怪不是真实存在的超自然生物，而是人心变化的具象化。
> 三个妖怪的核心功能：勾魂（拘魂鬼）、灭口（无头鬼）、蚀名（蚀书虫）。

## 2.1 三个妖怪的核心功能

| 妖怪 | 表层（民俗） | 里层（真相） |
|------|-------------|-------------|
| **拘魂鬼** | 勾魂——呼唤名字使灵魂出窍 | 言临/秦父接近目标，建立信任后实施替换 |
| **无头鬼** | 身首异处——失去头颅的恐惧 | 受害者原有身份"身首异处"，被替换 |
| **蚀书虫** | 蚕食名字——证据消失 | 秦氏家族销毁证据，身份文件被篡改 |

## 2.2 妖怪的叙事功能

```
第一阶段（第一幕~第二幕）：妖怪叙事笼罩
├── 读者被妖怪氛围吸引
├── 以为这是玄幻故事
└── 对"失名"现象感到恐惧

第二阶段（第三幕~第四幕）：妖怪解构
├── 顾清舟揭示"妖怪"的真相
├── 读者意识到这是犯罪推理
└── "妖怪"是人心制造的烟雾弹

第三阶段（第五幕）：妖怪散去
├── 真相揭露
├── 妖怪超自然光环消散
└── 但创伤不会消失
```

## 2.3 紫色符号

| 设定 | 说明 |
|------|------|
| **紫色是本案颜色符号** | 紫色贯穿全书（紫衣、紫印、紫伞等） |
| **来源** | 拘魂鬼"喜穿紫衣"的民俗原型 |
| **象征** | 秦氏家族的犯罪标记 |

# 七、故事大纲

## 7.1 五幕结构

### 第一幕：侵（第 01-08 节）

**时间：** 沈近失踪后第 1-7 天
**视角：** A 陈言（第一人称"我"）

**核心事件：**
1. 《蚀名簿》出土，工地发现一本被腐蚀的旧名册
2. 沈近失踪，留下字条："城西工地挖出老文书，听说能卖钱"
3. 陈言收到一张写有"沈近"名字的老纸片
4. 陈言查不到"蚀名"的意思，找顾清舟打听
5. 顾清舟说"那本书叫《蚀名簿》，名字被人动了手脚"
6. 陈言遇见纸翁，听说井底传说
7. 陈言发现户籍档案有涂改痕迹
8. 陈言决定下井调查，顾清舟表示陪同

**结尾：** 陈言决定下井，顾清舟表示陪同

---

### 第二幕：啮（第 09-16 节）

**时间：** 沈近失踪后第 7-14 天
**视角：** B 言临（第一人称"我"）

**核心事件：**
1. 言临视角：带陈言下井，发现大量身份文件
2. 言临视角：发现名册上每对名字（真/假），外貌相似
3. 言临视角：内心挣扎，想揭露真相但又害怕
4. 言临视角：整理失踪者名单，发现都是外来者
5. 言临视角：纸翁透露被胁迫参与
6. 言临视角：顾清舟提供关键线索，但保留关键信息
7. 言临视角：看到陈言盯着名册发呆，心中警觉
8. 言临视角：名册上沈近的名字旁——还有另一个名字

**关键线索：**
- 名册上每对名字（真/假）
- 言临的回避行为（多次出现）
- 井底的身份文件
- 名册上沈近旁有"秦观"的名字

**结尾：** 发现沈近可能被"替换"，言临内心挣扎加剧

**视角：** A 陈言（第一人称"我"）

## 9.1 核心定位：监视者 → 动摇者 → 背叛者

```
┌─────────────────────────────────────────────────────────────────┐
```

## 9.2 背叛的不可逆点火器：井底密室的"备用箱"

**场景：** 言临偶然进入秦父的秘密书房，发现了一个上锁的铁箱。

**内容：** 铁箱里是一套完整的"沈近"身份文件：
- 沈近的免冠照片（正面、侧面，多张）
- 沈近的指纹档案
- 沈近的血型信息
- 一份空白"死亡证明"草稿
- 一张伪造的"沈近"身份证

**关键细节：**
- 这些文件不是"计划中"的，而是"已经准备好"的
- 文件的磨损程度说明它们已经存在多年——秦父早就盯上了沈近
- 最让言临震惊的是：那套照片的拍摄日期，是三个月前

**为什么这是"不可逆"的：**
1. **时间戳的冲击**：三个月前，沈近还没失踪。这意味着秦父早就开始准备了。
2. **"死亡证明"的存在**：这意味着秦父从来没打算让沈近活着。替换完成后，真正的沈近会以"死亡"的名义消失。
3. **空洞的"备用箱"**：言临意识到：他不只是"帮凶"，而是"共谋者"。

# 十、写作风格与情节推进规范

## 10.1 风格核心特征

### 分段逻辑

| 段落类型 | 功能 | 使用规则 |
|----------|------|----------|
| **长段落** | 模拟思考过程，进行推理论证 | 推理关键节点使用"论证 > 动作"结构 |
| **短句/省略段** | 制造节奏顿挫，悬停感 | 长段落后紧跟短句或省略号 |
| **过渡段落** | 连接推理节点 | 保持逻辑连贯，但节奏放缓 |

### 禁止出现清单

| 序号 | 禁止项 | 替代方案 |
|------|--------|----------|
| 1 | "原来如此""我明白了"等顿悟句式 | 用疑问替代 |
| 2 | 单一段落内连续超过3个"仿佛""似乎""也许" | 最多使用2个 |
| 3 | "真相是……"宣告句式 | 改为"另一种解释是……" |
| 4 | 象征"回归正常"的环境描写 | 保持压抑氛围 |

### 必须出现清单

| 序号 | 必须项 | 实施规则 |
|------|--------|----------|
| 1 | 长段落与短段落交替 | 每章至少3组长-短交替 |
| 2 | 悬停段落（省略号独立成段） | 每章至少1处 |
| 3 | 自我打断（破折号） | 每章至少2处 |
| 4 | 炫学段落 | 每章必须有1段 |

## 10.2 对话错位规则

**禁止：** 两个角色对话后达成共识。
**必须：** 对话结束在错位中。
