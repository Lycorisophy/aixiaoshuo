## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 39 节：档案馆中（A 视角：陈言）

馆中灯白日亦寒，寒在纸边不在檐。
檐下有人谈复印，复印机响如嚼盐。
E01对上台口眼，眼风一扫已先拦。
拦余末页忽新墨，新墨或然谁敢谳。

------

市档案馆正门很亮。

亮得像故意把“公开”写在脸上。

公开在这城里常常是**反话**。

反话不等于假。

假在这时候太干净。

干净像罪。


我怀里抱着 **E01** 的副本袋。

袋角铅笔字磨淡。

淡得像被人手汗泡过。

林晚照走在我侧后半步。

半步像随时准备把我从台口拽回去。

拽回去不是逃。

逃会先亮。


取号。

台口从漆盒里拈一张硬号签递出来。

签边磨圆。
```

## 颗粒 2（节选 L127–L168）·中段推进

```

我翻开封面。

封面霉味扑上来。

扑得像一口井。

井不深。

深的是：**我看见末页**。

末页有一行新墨。

新墨不粗。

粗的是它**不该在这时候出现**。

出现像嘲笑。

嘲笑我读太多志怪——志怪里最爱写：

**纸自己会写字**。

我指尖发冷。

冷得像摸到别人的手。

别人的手——

从我的指缝里伸过去？


“你看太久。”林晚照低声道。

我摇头。

摇得像否认。

否认需要对象。

对象在这时候像鬼。

```

## 颗粒 3（节选 L281–L322）·收束或转折

```

林晚照从侧门出来。

手里捏着一叠复印申请回执。

回执上有号。

号像链。

链会追人。

“台口说，”她低声道，“这册 **E01** 关联档，昨晚有人调阅过。”

我心脏一缩。

缩得像被绳子勒住。

“谁？”我问。

“不知道。”她说。

不知道在这时候最像真话。

真话不会让人好受。


风从馆门刮出来。

刮得登记表边角翻起。

翻起像有人想把它撕走。

撕走不等于消失。

消失在这城里常写成**待续**。

我低声问：

“下一笔会落在纸上，还是落在谁的人生里？”

问得像自言自语。

```
