## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 23 节：对质之困（A视角：陈言）

言临是在巷口雨檐下被我堵住的。

老宅那一夜的气味还黏在袖口——霉、旧纸、紫——我手里多了一把钥匙似的东西：不是真钥匙，是一串能把门推开的地址与残角。我把那些东西攥得太紧，攥得掌心发疼，疼到我在雨里看见他背影时，第一反应竟不是喊，而是**停**。

停得像怕一出声，就会把纸上的两个字喊成真。

**沈近。**

**秦观。**

他听见脚步声，没有回头。

不回头像早就知道我会来。

雨线斜着，把他的肩线切得很薄，薄得像纸边。他左手拿着一把收起的伞，伞骨上水珠一线一线往下坠，坠得像在数什么。

“言临。”我开口。

名字落出去。

落出去像把钉子敲进木头。

他的肩线动了一下。

像疼。


他终于转身。

脸色很白。

白得不一定是冷，也可能是**耗**。

耗了太久的人，白得像纸。

我本以为我会骂。

会揪他领子。

会问他那天晚上为什么走进雨里不回头。
```

## 颗粒 2（节选 L320–L361）·中段推进

```

我把最伤人的那句掏出来。

掏出来像掏刀。

“言临。”我说，“名字对你到底是什么？”

他抬眼。

眼里有一瞬空。

空得像无字碑。

“是家。”我说下去，声音发紧，“还是牢？”

言临的喉结动了一下。

动得像吞咽刀片。

他没有立刻回答。

立刻回答会像撒谎。

撒谎需要熟练。

他今天不熟练。

许久，他才道：

“家也是门。”

“牢也是门。”

“门后是什么——”

他停住。

我冷笑：

“你别跟我打机锋。”

言临看着我，眼神很直。
```

## 颗粒 3（节选 L622–L663）·收束或转折

```

我换了个更卑鄙、也更现实的问题：

“你对我，有没有一句是真的？”

言临的呼吸停了一拍。

停得像死。

他低声道：

“有。”

“哪句？”我问。

言临看着我：

“让你别在灯下看。”

我胸口像被捅了一下。

捅得不深。

深的是**迟来的明白**。

明白他不是装神弄鬼。

他是在**拦登记**。

我声音发哑：

“那你为什么还走近我？”

言临闭了闭眼。

“因为走近了，才能把绳子往另一边拽。”他说。

“拽？”我问。

言临不解释。

解释会把他自己吊死。
```
