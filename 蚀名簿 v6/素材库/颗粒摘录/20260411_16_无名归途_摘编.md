## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 16 节：无名归途（B视角：言临）

天亮之前，我做过一个梦。

梦里没有井。

只有纸。

纸上有两列。

两列之间那条缝窄得像刀刃。

我站在缝里。

左边一个字在叫我。

右边一个字也在叫我。

两个声音叠在一起。

叠成同一个回声。

我醒来时，手套还戴在手上。

像梦里那层皮没有脱下来。


顾清舟一早就出去了。

出去得很安静。

安静得像故意把屋子留给我们。

陈言坐在桌前。

第七页压在一本硬书下面。

像压住一口井。

他看我。

眼神很平。
```

## 颗粒 2（节选 L248–L289）·中段推进

```

陈言忽然伸手。

要指那个名字。

我一把抓住他手腕。

抓得很急。

急得像救火。

“别指。”我说。

陈言一愣。

“为什么？”

我说：

“指会被记住。”

陈言眼里闪过什么。

“你被训练过？”他问。

训练两个字太准。

准得像刀尖抵住我喉结。

我说：

“我只是在潮地方待久了。”

陈言不信。

不信就对了。

他低声道：

“秦观。”

他又念一遍。
```

## 颗粒 3（节选 L528–L569）·收束或转折

```

我不能答**我就是**。

答了，第二幕就提前炸穿第三幕的墙。

我只能答：

“跟我有关系。”

陈言瞳孔缩紧。

“什么关系？”

我说：

“关系就是——”

我停住。

停得像把自己悬在缝上。

风从缝里吹过来。

吹得我手套边那圈淡色像要燃烧。

我说：

“我必须回到他身边。”

陈言一怔。

“回到谁？”他问。

“沈近？”

我不说是。

也不说不是。

我只重复一遍。

像重复一句咒：
```
