## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 37 节：纸翁作证（A 视角：陈言）

翁不言多多在叹，叹处潮腥纸亦烂。
半句如钉钉在舌，舌边血味不敢咽。
E三至六连成串，串上紫痕谁曾按。
按痕欲证证还怯，怯余明日认不认。

------

纸马铺里仍是那股味。

蜡纸、松香、旧木、还有一种极淡的涩——涩得像印泥在潮气里化开。

化开不等于散。

散在这城里像奢望。

纸翁坐在柜台后。

柜台高。

高得像审判台。

审判台在这屋里却更像**供桌**——供的不是神，是**不敢说话的纸**。


我把三只袋放在凳上。

不摆桌上。

摆桌上像逼他。

逼在这时候会像**点名**。

点名会先亮。

纸翁看一眼袋角铅笔字：

**E03**

**E04**

```

## 颗粒 2（节选 L153–L194）·中段推进

```

**E04**、**E05**。

他看得更久。

久得像在看自己的一生。

一生被切成纸段。

纸段上全是别人的名。

“中期……近现代……”他喃喃。

喃喃像背谱。

背谱的人不一定信谱。

信谱的人最容易被谱**套住**。

“紫。”他忽然说。

只说一个字。

紫得像钉。

钉不进肉。

钉得进眼。

我指尖发麻。

“紫是什么？”我问。

问得像蠢。

蠢在这时候是**必须**。

纸翁摇头。

摇得像拒绝命名。

“紫是……习惯。”他说。
```

## 颗粒 3（节选 L295–L336）·收束或转折

```

临走前，纸翁把我叫到里间。

里间更潮。

潮得像胃。

他塞给我一张窄条。

窄条上只有三个字：

**别登全**。

我捏着窄条。

捏得像捏雷管。

“明天你还认吗？”我问。

问得像孩子。

纸翁看我。

看了两秒。

“明天……”他说。

“明天要是有人来问我，”他说，“我就……咳。”

他咳了一声。

咳得像把话吞回去。

吞回去像把刀吞回鞘。


我走出纸马铺。

雨丝扑面。

扑面像细针。

```
