## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 21 节：日记残章（A视角：陈言）

那张带水印的薄纸，在台灯下躺了三夜。

我躺了三天。

三天里我反复做同一件事：把纸对着光转角度，转得像在逼一张沉默的嘴开口。嘴不开。开的只有我自己的脑子——脑子里全是鹿野丢下的词：**裁走、贴过、册、井、人在外。**

顾清舟不催我。

催是会把人催成炸药。

他只在我第三次对着水印发呆时，把一本册子推到我手边。

册子不是档案馆的。

是图书馆特藏库里借出来的**复印件合集**：民国地方小报、商会杂录、私人日记的授权影印——合法，但冷；冷得像从别人的生命里借了一截骨头。

“从这一页开始。”顾清舟说。

他指尖点在一页扫描件上。

扫描件边沿有锯齿，锯齿像时间咬过的牙印。


日记的主人没有署全名。

只署了一个字：**慎**。

慎得像怕写下真名就会被什么叼走。

纸上的口气却不像杂志里那种“民国文人腔”——更短、更涩，像一个人边记边怕自己第二天不敢认。

例如这一则——我照复印件抄录，不润色：

> 民国二十六年，春月。随族老修谱。墨要新，纸要整，名讳依字辈，错一处便是失礼。谱上刊格，格里分行，行下小注：嫡、庶、出、继、殇。见一幼殇，不入正格，边注仅“未名”二字，注者笔力极轻。余观之而心下不宁，不知轻的是墨，还是命。

我读得发冷。

冷的不是“旧礼法很旧”，而是我看见一种与当代窗口完全不同的“登记”，却共享同一种骨头：**先把人放进格里。**

我盯着“未名”。
```

## 颗粒 2（节选 L118–L159）·中段推进

```

我忍不住开口。

一开口就像泄洪。

“我以前写志怪，总爱讲‘命名’。”我说，“择日、五行、玄乎其玄——读者爱看，因为像文化。”

顾清舟听着。

“可现在我觉得，”我声音发紧，“那更像一只手：把一团没定的雾，硬**拎出来**，摁进格子里，摁完还说——好了，你现在是谁了。”

我停住。

顾清舟抬眼。

眼神像刀背。

不重。

但能拦住我。

我苦笑。

“这联想荒唐。”我说，“我不是科学家，我只是……”

我只是找哥哥。

找哥哥的人，什么模型都敢借。

只要模型能让他喘一口气。

顾清舟这时才慢慢道：

“你不是在讲物理。”

“你在讲**怕**。”

我点头。

点得像认罪。

顾清舟把茶杯往前推半寸。
```

## 颗粒 3（节选 L220–L261）·收束或转折

```

傍晚，谢知微来过一趟。

她不进门，只在衔霜楼外檐下站了片刻，递给我一只牛皮纸信封。

檐雨在她肩线外划出一层更亮的边，她却站得像不需要躲——鞋尖沾了一点灰泥，泥色发旧，像刚去过另一条更脏的巷子；可她不让那泥进门，递信封时用指节顶了一下纸角，像怕潮气先渗进去。

信封薄。

薄得像只剩一口气。

“我不旁听你们读书。”她说。

“我只补一条路径。”

我接过。

谢知微转身前，又丢下一句：

“族谱是旧的观测。”

“观测不会消失。”

“只会换镜头。”

她想走。

我忍不住问：

“那你信哪一本？”

谢知微停步。

停得很短。

短得像刀背擦过皮肤。

“我信**谁握镜头**。”她说。

后半句不说。

不说比说了更狠。
```
