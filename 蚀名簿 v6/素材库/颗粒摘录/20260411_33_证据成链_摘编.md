## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 33 节：证据成链（A 视角：陈言）

链成未必链能断，名落纸上骨先寒。
十四封袋十四刃，刃刃朝谁谁不宽。
百年若只凭一页，一页如何撑得船。
船到江心风未息，息声人在岸边看。

------

我又落回自己的颅骨里。

这一次不是因为换了视角写稿，是因为**车停了**。

停得太突然，刹车片在黎明前磨出一声短促的尖叫——尖叫像被人用手掌捂住嘴，捂得不干净，余音还在铁皮车厢里乱撞。

我抱着沈近。

他轻得像被水泡过的木。

木还会浮。

他浮在我臂弯里，眼睛偶尔睁一下，睁得像不认得我——不认得也好，认得在这时候会像第二道伤口。


司机从驾驶楼探出头。

头灯还亮着，亮得像审判。

“到了。”他说。

只说两个字。

两个字像钉。

我嗓子发干。

“车——”我起头。

又停。

停得像怕一问就会把某种默契问碎。

```

## 颗粒 2（节选 L263–L304）·中段推进

```

“你要我——”我起头。

“你要自己数。”顾清舟说。

他纠正我。

纠正得像刀背敲在指节上：

**这不是替我认罪**。

**这是替你把‘吓人故事’翻译成能被别人复述的句子**。

我沉默。

沉默很久。

久到窗外的雨丝又细了一层。

细得像在筛灰。


我拿起 **E01**。

袋里是那只从城西工地抄出来的旧名册副本——我们后来补过登记、走过复印，纸边磨毛，毛得像被人反复摸过名字。

“蚀名。”我低声说。

我不说“妖怪”。

妖怪在这屋里不够格。

格子里要的是**行为**。

顾清舟“嗯”了一声。

不置可否。

不置可否最折磨人。

折磨在于它逼你自己把话说满。

```

## 颗粒 3（节选 L501–L542）·收束或转折

```

林晚照忽然开口。

“你要发吗？”她问。

问得像刀。

刀尖对着我，也对着她自己。

“发什么？”我反问。

反问像挡。

“发编号？”她抬下巴，指桌上那一排袋，“还是发故事？”

我张了张嘴。

嘴型先是“故事”。

又拐成“材料”。

“材料。”我说。

林晚照笑了一下。

笑得发苦。

“材料一到报纸上，就会变标题。”她说。

“标题会吃人。”

“吃的不一定是秦家。”

她停住。

停得像把后半句留给我自己咽。

我咽下去。

咽下去像吞钉。


```
