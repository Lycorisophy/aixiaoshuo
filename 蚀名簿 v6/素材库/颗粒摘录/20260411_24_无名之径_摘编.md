## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 24 节：无名之径（A视角：陈言）

我把言临留下的折纸，压在台灯玻璃下压了两天。

两天里我无数次想拆开。

想拆得像想把雷的引线拔掉。

可顾清舟只说：

“等他来。”

“他来，不是为了让你读纸。”

“他来，是为了让你**学会怎么不读**。”

我不懂。

懂一半就够吓人。


那两天里，顾清舟也问过我一次闲话。

闲话像刀背。

“你总在摸纸边。”他说，“摸得像怕它自己翻页。”

我嗓子发干。

“他们为什么要记册？”我问，“抹痕不够吗？非要多一本。”

顾清舟沉默一瞬。

“你以为仪式是做给别人看的？”他说。

我皱眉。

“这种事也要排场？”

“排场是面子。”顾清舟道，“有人记册，是为了把一件事**塞进一套能重复的套子**里。套子越大，越不像手痒起的恶意。”

茶汽顶上来。
```

## 颗粒 2（节选 L226–L267）·中段推进

```

我们又定了几条很丑、很现实的规矩。

丑得像在给自己上铐。

**夜里不通话。**

**通话不超过九十秒。**

**见面点每次换，由顾先生给。**

**任何一方觉得‘像在录口供’，立刻散。**

散不是翻脸。

散是保命。

言临每一条都应得很轻。

轻得像在签他不配签的东西。

我最后问：

“你凭什么信我？”

言临反问：

“你凭什么信我？”

我答不出。

答不出就对了。

顾清舟淡淡道：

“信不是前提。”

“信是后果。”

“后果要等你们活下来再谈。”


```

## 颗粒 3（节选 L362–L403）·收束或转折

```

黄昏时，顾清舟接了一个电话。

接得很短。

短得像怕话柄在空气里伸长。

他放下听筒，看我一眼，那一眼里没有庆贺，只有一种把钉子拔出来后的空。

“北城巷那具。”他说，“纸上来了。”

我脊背一僵。

僵得像又看见泥里蜷着的手指。

“是什么？”我问。

顾清舟没有用故事口吻。

他只给我当时能听懂的减法：

“血型对不上。”

“指纹也对不上。”

“跟你哥早年留在厂里的那份体检表——不是一个人。”

我站着。

站得像一口气终于从胸口退潮。

退潮后露出来的不是岸，是羞耻：我居然需要一张纸，才敢承认我把我哥先埋进过另一具身体里。

“那沈近呢？”我声音发干。

顾清舟摇头。

“这张纸只负责告诉你——**不是那一具**。”他说。

“不负责告诉你——**人在哪**。”

我点头。
```
