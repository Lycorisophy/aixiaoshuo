## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 04 节：名册初现（A视角：陈言）

雨还在下。

不是从天上往下砸，而是从一切“有缝”的地方渗出来：墙缝、瓦沟、铁皮接缝、塑封膜的边缘、纸纤维之间的孔隙。老城像一块泡久了的旧海绵——你以为它只是湿，实际上它在慢慢吐出更旧的东西：盐霜、霉味、锈、水汽里带着一点点甜。

那甜不是糖的甜。

是旧纸被潮气泡软后，纤维溶出来的那种近乎无辜的甜。

我知道这种味道。

我在图书馆整理出土文献时，常常在某些盒子里闻到它——一打开，纸还没露面，甜味就先露出来，像某个看不见的东西提前对你招手。

可我这一次闻到它，是在工地。

更准确地说，是在工地围挡后面那条狭窄的背巷里。

我本来不该再来。前三天我已经被保安用“没这个人”堵在门口一次，雨把我的鞋灌成了冷汤，理智也灌成了更薄的东西。我应该回去写稿，或者至少回去把那张字条描一遍夹进本子——把它当成“生活中可以处理的一件事”。

可“应该”这种词，像纸上的铅笔线：潮气一上来，它就淡。

我第二次站在围挡边的时候，顾清舟也来了。

他撑伞，伞骨的弧度很稳，像是早就知道风会从哪个方向钻进来。他的长衫外面套着旧大衣，雨水沿着衣摆滴落，滴在泥水里，没有一点犹豫。我注意到他今天没带茶壶——或者说，他带了，但壶口被布塞得更紧，像怕这地方的潮气会顺着壶口爬进去。

“你又来了。”他看了我一眼。

我本能想反驳，说我不是“又”，是“还”。可我没说出口。

因为我忽然意识到：这件事从来不是“我来没来”，而是“我有没有被允许来”。

允许。

这个词在雨里变得很冷。

我把伞压低，雨水沿着伞沿一线一线往下拉，像有人在给空气做分割。

“你说过，”我对顾清舟说，“那批文书在这里挖出来。”

顾清舟的目光扫过围挡。

```

## 颗粒 2（节选 L137–L178）·中段推进

```
“是什么？”我低声问。

顾清舟没有回答“是什么”。他只说：“你看见了吗？”

我把袋子拖到巷子里较干一点的地方。雨水仍旧沿着围挡流下，滴在袋子上，滴在我手套上。

袋子里不是整本书。

是碎的。

撕裂的。

潮湿的。

一叠被人粗暴处理过的纸页。

有些纸页纤维粗，发脆，边缘毛刺很明显，像手工纸；有些纸页更平整，甚至能看见塑封膜残留的反光，边角有机械裁切的直线感——两种时代的质感被硬生生塞在同一个袋子里，像两种时间被人强行叠在一起。

我拿起一张。

纸很软，软到我用力一点，它就要在手套下裂开。

纸上原本应该有字。

可字不见了。

不是模糊，不是被水泡开，不是墨晕。

是“白”。

一种过于干净的白，像有人用很耐心的力气，把纸上的某些部分洗掉了。

我把那一页举到雨里，雨滴落在白处，竟然没有像落在别的地方那样形成水痕。

白处像一层薄薄的皮，拒绝吸水。

我突然想起第07节还没发生的那种直觉——涂改不是“涂”，是“磨”。

可我现在不敢把这个想法说出来。

说出来，就像给它一个结论。

```

## 颗粒 3（节选 L273–L314）·收束或转折

```
“看见了。”我说。

“你要叫它什么？”他问。

我张了张口。

“印泥。”我下意识想说。

可顾清舟摇头。

“别叫它印泥。”他说，“叫它残留。”

残留。

这个词比印泥更冷。

印泥是工具。

残留是痕迹。

是别人走过之后留下的东西。

我伸出手套指尖，下意识想摸一摸那条压痕。

我只是想确认它是真的，确认它不是我的眼睛在雨里编出来的。

指尖轻轻蹭过纸面。

那一瞬间，我感觉到一种极薄的黏。

像胶。

像封存胶干透后重新被潮气唤醒。

我把手收回来。

手套指尖上沾着一点极淡的紫。

不是鲜明的紫。

更像被水稀释过很多次的影子。

```
