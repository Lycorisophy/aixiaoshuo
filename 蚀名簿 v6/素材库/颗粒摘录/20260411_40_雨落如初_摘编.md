## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 40 节：雨落如初（A 视角：陈言）

雨落下来的方式，和一切开始时一样。

不是温柔的那种一样。

是**铅灰、黏骨、把呼吸拖慢**的那种一样——一九八四年春深，清明前后，老城又把自己泡回同一只碗里。

我站在衔霜楼檐下。

檐水一线一线往下拉。

拉得像在数谁还没睡。


桌上摆着今天要送走的东西。

送走不是扔。

扔太轻。

轻在这城里像假。

**E04**、**E06** 的复印件各三份——顾清舟用铅笔在袋外写了**来源、路径、可复核**，字迹干得像不肯渗墨。

我盯着那两行。

行里没有人名。

人名在这时候太亮。

亮会先死。


**E13**、**E14**。

两只牛皮袋，装着言临那副旧棉手套——一只磨穿边，一只更旧，旧得像**另一只手也曾藏进去**。

我把袋口封上。

封条是透明胶。

```

## 颗粒 2（节选 L162–L203）·中段推进

```

周守业——纸翁——坐在下首的凳上。

背挺得很直。

直得像第一次学会不低头。

他低声说：

“他们叫那本册子**名簿**。”

名簿两个字像两口井。

井不回答。

回答的是雨。


顾清舟道：

“三份。”

“一份**挂号**出去。”

“一份给林记者——她自有她的栏。”

“一份你自己留。”

“留，”他说，“不是为了赢。”

“是为了让**失败看起来不像成功**。”

我点头。

点得像咽苦水。


雨敲瓦。

瓦敲得像问：

**你要人记住，还是你要人活？**
```

## 颗粒 3（节选 L338–L379）·收束或转折

```

# 尾声：第十五号证据包（E15）

> 以下为 **v6 正文** 尾声，与早期《样稿》中同题材料**脱钩**；物证口径以 **1986 可及**与 **`真设定集` 附录 H.0** 为准。

雨停在凌晨四点半左右。

停得像有人把算盘最后一颗珠拨回去。

我把最后一份复印件封进牛皮袋，袋口缠绳，绳结打得笨——笨得像故意让人看出：**这是人手打的**。

顾清舟在旁看着。

不伸手。

伸手会登记。

登记在这时候像毒。


**E15** 并不是“凭空从叙述里长出来”的。

它来自衔霜楼后巷那只旧报箱——铁丝锈断了一截，像怕它开口；箱门上褪色的字写着**住户专用**，字边被雨泡糊，糊得像故意不让谁认全。

没有人给我发短信。

也没有人给我打寻呼——那种东西在这城里太显眼，显眼会先亮。

来的是一纸**便条**，由林晚照转交，便条上只有一行：

**后巷报箱。带手套。别喊全名。**

林晚照补了一句：

“纸条是今早有人塞进报社传达室的。”

“传达室老头说不认识人。”

不认识在这时候最像真话。


我戴手套。
```
