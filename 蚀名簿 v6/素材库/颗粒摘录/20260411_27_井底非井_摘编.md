## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 27 节：井底非井（B 视角：言临）

锁舌弹开的声音很脆。

脆得像骨头在黑暗里折断。

其实腕里那一拧轻得很——像先把声按进肉里，再让它炸出来。

陈言没动。

他站在我侧后，站得像把自己钉在潮里，只留眼睛往前送。

送得太用力，用力得像怕一眨眼，箱子里会少掉什么——或少掉**最后一点还能骗自己的余地**。

我把箱盖掀起。

掀起得很慢。

慢不是温柔。

慢是怕快会把自己割到。


箱里先映入眼帘的是塑料套。

套边磨毛。

毛得像被人反复摸过、抽过、又塞回去——那种摸不是珍惜，是**核对**。

核对像职业。

职业不需要感情。

感情会留痕。

陈言的呼吸停了半拍。

半拍就够。

够他认出最上面那层：**身份证件的轮廓**。

不是一本。
```

## 颗粒 2（节选 L142–L183）·中段推进

```

再往下是一张纸。

纸不是正式公文。

是**草稿**。

草稿的抬头被划掉又重写，重写处墨团发黑，像有人在夜里手抖。

陈言读得很慢。

慢得像每个字都在嘴里出血。

我看到那行字——我不需要读完。

我早见过这类东西的口气：

**死亡证明（草稿）**

**姓名：沈近**

后面的空白栏里，有人用铅笔写过又擦，擦痕里仍留着“待填”的痕迹。

待填不是疏忽。

是**等日子**。

等日子的人最冷静。

冷静得像在井边等水满。

陈言抬头看我。

他眼里没有泪。

泪在这时候太干净。

干净得像假。

他只有红。

红得像血不上来、又下不去。
```

## 颗粒 3（节选 L348–L389）·收束或转折

```

出门前，我回头看了一眼铁箱。

箱盖敞着。

敞得像一口小井。

井不深。

深的是：**它不吃土，吃名**。

陈言在阶上等我。

他没催。

催是信任的人才做的事。

他只在等我**自己走上去**。

我上去。

每一步都像把自己从“秦家的手”里拔出来。

拔会带血。

带血也好。

血是热的。

热证明我还不是纸。


上到书房，天光从破窗漏进来。

漏得像刀口。

陈言站在光边。

一半亮，一半暗。

像某个人生硬的比喻——我不说。

```
