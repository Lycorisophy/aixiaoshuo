## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 30 节：归位之人（B 视角：言临）

荒栈临河草没踝，铁牌斜挂字半删。
潮绳旧印皆相识，识得愈真愈不寒。
人归不在名归册，册外风声正叩关。
欲行先问行后事，事后谁担这一滩。

------

河腥比霉味更直。

直得像一句话怼进鼻子里：

**这里停过很多东西。**

停过货，停过人，停过不想被看见的日夜。

陈言站在断墙下，墙头嵌着半块水泥字，字里只剩“运”和“三”——中间那截塌了，塌得像被人故意砸掉名字中间那一横。

他抬头看我。

“你确定是这？”他问。

我点头。

点得像把自己钉在潮地上。

“靠河第三栋。”我说。

“外墙面有道竖裂，裂里塞过麻丝——麻丝发黑，黑得像老血。”

陈言顺着我的目光看过去。

看到了。

看到后他脸色更白。

白得像纸。

纸一湿就透。


```

## 颗粒 2（节选 L155–L196）·中段推进

```

我把唇凑到他耳边。

凑得很近。

近得像犯罪。

“你听。”我说。

“里面如果有脚步，不止一双，我们就撤。”

陈言点头。

点得像在忍疼。

我们等。

等到河面上有船过，马达声盖过一切。

马达声里，我听见里面脚步移动。

移动得很慢。

慢得像拖。

拖的不一定是铁链。

也可能是**腿**。

陈言的指节在我掌下发抖。

抖得像要断。

我低声道：

“一个。”我说。

“重，慢。”

“像守。”

陈言闭了闭眼。
```

## 颗粒 3（节选 L385–L426）·收束或转折

```

我们撤回去。

撤得像从没来过。

来时潮腥在鼻子里。

走时潮腥还在。

还在就对了。

还对证明城没把我们吞掉。

吞掉的人，连腥都闻不到。

陈言走在前。

前不是勇敢。

前是他怕慢一步就会回头。

回头会像认输。

我跟在后面。

跟得像影子终于学会走路。

走路会响。

响在这时候是好事——

响证明我们还没被写进“没来过”。


夜还长。

长的不止时间。

还有**等待**。

等待会把人磨成针。

```
