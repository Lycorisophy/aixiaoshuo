## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 20 节：空白之页（A视角：陈言）

城隍庙的香，和纸马铺的香不是同一种。

纸马铺的香急着办事，急着把话说到另一边去；城隍庙的香却慢，慢得像在等——等什么，它不说。你站在殿前被烟熏一下，喉咙里会泛起一种发苦的甜，那甜味旧得很，旧得像从很多年的雨里熬出来的。

我来之前，顾清舟只交代三件事。

别拍照。

别指碑。

别在庙里把“沈近”两个字说得太响。

“响会变成回声。”他说。

“回声会登记。”

我本想反驳他：庙里最不缺的就是回声，钟鼓一敲，满堂都是登记。可话到嘴边我又咽回去——因为我已经见过纸上的“登记”，见过空栏与红圈，见过同一根线在不同系统里反复出现。

我怕的不是回声。

怕的是回声背后那只**整理回声的手**。


城东这一片，白天永远半热半冷。

热的是游人，冷的是角落。

我们绕开主殿的鼎沸，从侧廊往里走。廊下的石板被鞋底磨得发乌，乌里透着潮，潮里藏着香灰。香灰细，细得像某种不肯落地的雪。

碑在偏院。

偏院更静。

静得像被人从喧闹里抠出来，单独放在一旁。

那碑不高，却直。

直得像一根拒绝解释的钉子。

我第一眼看见它时，心里先是一松——松是因为我终于找到了顾清舟说的“没写字的砖”：碑面真的是空的。
```

## 颗粒 2（节选 L238–L279）·中段推进

```

我差点失控。

失控不是骂，是想把册子抢过来翻——翻到底，翻到天荒地老，翻出我哥哥的名字到底被谁挪走了。

顾清舟把我往后拉了半步。

半步像一道极窄的河。

“陈言。”他只喊我名字。

我胸口起伏。

起伏像拉风箱。

鹿野看着我，眼神里没有怜悯。

怜悯会软。

软了就会被利用。

他只有平静。

平静得像一块真正的石头。

“你想问见证什么。”他说。

我点头。

点得像磕头。

鹿野却摇头。

“问错了。”他说。

我喉咙发干。

“那该怎么问？”我问。

鹿野抬眼，看向小殿屋脊的阴影。

阴影里有一只瓦当，瓦当残缺，残缺处露出灰黑的天空。
```

## 颗粒 3（节选 L434–L475）·收束或转折

```

回衔霜楼的车上，我一直攥着那张空白纸。

攥得像攥着哥哥的袖口。

顾清舟开车，不说话。

不说话是他的体贴。

体贴比安慰狠。

狠在它逼你自己把思绪理顺。

许久，我才哑声道：

“他为什么只说词？”

顾清舟看着前路。

“说词，不说链。”他说。

“链要你自己接。”

我苦笑。

笑得像裂。

“我接不上。”我说。

顾清舟沉默两秒。

“你已经接上了一截。”他说。

“哪一截？”我问。

顾清舟没有直接答。

他只道：

“你怕空白。”

我怔住。
```
