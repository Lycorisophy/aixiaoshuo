## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 28 节：无底之井（B 视角：言临）

百年非鬼百年局，局里生人换死鱼。
边民易断边民线，线断无声声自虚。
收买压案同一手，手不流血血在书。
书外谣传拘魂鬼，鬼名原是遮罪裾。

------

我们没在老宅久留。

久留会像等人来收尸。

收尸在这城里不一定是死人——有时是**把活人收进纸里**。

陈言走得很快。

快得像怕慢一步，箱子里的寒气会追上来贴他的背。

我跟在后面。

跟得像影子终于学会走路。

走路会响。

响在这时候是好事——响证明我们还没被抹成“没来过”。


巷口风硬。

硬得像有人用木板拍你的脸。

陈言停在一截断墙后，墙后堆着拆下来的旧梁，梁上钉子锈成暗红，像干涸的口令。

他转身看我。

“你说。”他说。

只说两个字。

两个字像把刀柄递过来：

## 颗粒 2（节选 L133–L174）·中段推进

```

风从巷尾卷过来，卷得旧塑料袋沙沙响。

响得像有人在翻一本巨大的册子。

我接着写：

**挑好了，就先养线。**

**线不是绳，是人与人之间那种“便宜信号”——同乡、同姓、同单位、同一张桌上的饭。**

**信号越便宜，越像真的。**

陈言打断我。

“你在写论文？”他问。

问得像嘲讽。

我摇头。

“我在写**成本**。”我说。

成本两个字出口，我才意识到它多冷。

冷得像算盘。

陈言沉默两秒。

“然后呢？”他问。

我写字：

**养到能下手的时候，纸先动。**

**纸一动，人就跟着动。**

**人一动，旧名字就像潮里的字——糊了，还能认，但谁认谁麻烦。**

陈言的指节发白。

“户籍、档案、复印件。”他接上。
```

## 颗粒 3（节选 L377–L418）·收束或转折

```

远处有鸽哨。

鸽哨尖。

尖得像在灰天上划一道白。

白很快散。

散得像名字。

我忽然想起小时候有人教我背谱系——背得像背课文。

课文背熟了，就不问意义。

意义一问，就会看见井。

井不深。

深的是：**你以为你在岸边**。

其实你在井壁上。

井壁湿滑。

湿滑得像别人的手在推你。

……

陈言转身出巷。

我跟上。

跟上像把自己从“秦家的流程”里撕下来。

撕会疼。

疼证明我还活着。

活着的人，才有资格去找**还没被写进草稿里的那个人**。

（本节完）
