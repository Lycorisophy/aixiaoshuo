## 颗粒 1（节选 L1–L28）·开场气氛与钩子

```
# 第 06 节：纸翁缄默（A视角：陈言）

我回到老城时，天已经黑透。

新城区的灯太白，白得像一张刚从打印机里吐出来的纸，连影子都显得干净。可老城的灯不一样——它黄，黄得像旧报纸的边缘；它弱，弱到你走到一半，才发现自己其实一直在靠雨水的反光认路。

雾从河那边爬过来，贴着巷口的墙，像有人把一张潮湿的棉布披在城上。

我把寻呼机别在腰侧，手指隔着布料摸了一下机壳。

电池只剩一格。

它像一个不肯再多说的证人。

市政大厅那条**窄条**我不敢留原件，只在本子里**影描**过一遍——描痕也只是一张影子。它可以证明我曾经被提醒过，却证明不了提醒是谁给的，也证明不了“查号”这件事到底指向什么。

我需要一个更硬的东西。

纸。

章。

号码。

任何能被第三方复做的东西。

所以我走向瑞成纸马铺。

```

## 颗粒 2（节选 L30–L71）·中段推进

```

纸马巷的水更深了。

青石板之间的缝隙像被撬开，黑水从里面渗出来。巷子里没有风，只有雨，雨落在檐下的铁盆里，敲出一种单调的节奏。那节奏让我想起市政服务中心的键盘声——密密麻麻，像一张网。

瑞成纸马铺的门半掩着。

门缝里透出一点暗黄的光，像火苗被人用手掌捂着。

我抬手敲门。

里面没有立刻回应。

过了很久，门才被拉开一点。

纸翁的脸露出来。

他没说“进”。

他只是看了我一眼，目光落在我口袋的位置，像在确认我带没带什么不该带的东西。

“你去了？”他问。

我知道他问的是哪儿。

“去了。”我说。

“查到了？”

我摇头。

“查不到。”我说，“连‘查不到’都不给我留一张纸。”

纸翁的嘴角动了一下。

那不是笑。

更像一种“果然如此”的疲惫。

他把门拉开。

“进来。”
```

## 颗粒 3（节选 L204–L245）·收束或转折

```

我把市政服务中心的经历简短讲了一遍。

讲到“没有结果单”的时候，纸翁的指尖在桌面上轻轻敲了一下。

一下。

像盖章。

“听见了吗？”他说，“你连‘拒绝’都拿不到。”

我没说话。

我忽然明白自己今天为什么那么难受。

不是因为查不到。

而是因为查不到这件事本身也不允许被记录。

“那我该怎么查？”我问。

纸翁看着我。

他似乎在犹豫。

他犹豫的不是要不要帮我。

更像是在衡量：帮我，等于把我推到哪一层。

“你先学会一件事。”他说。

“什么？”

“留痕。”

他把这两个字说得很慢。

像咬住一块硬骨头。

“你嘴里说的都能被抹掉，”他盯着我，“纸上的才算。”

我想反驳，说我写字。
```
