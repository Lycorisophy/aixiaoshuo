## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 38 节：记忆归处（A 视角：陈言）

归处非家家在纸，纸边照片两相似。
似边若问兄何在，在旁瞠目如不识。
E七E八E九并看，看后心酸酸不起。
起唇欲唤名三字，三字如钉钉在齿。

------

沈近坐在榻沿。

榻沿矮。

矮得像这城市只肯给他半张体面。

他手里捏着一只搪瓷杯。

杯里水晃。

晃得像他握不住稳定。

稳定在这时候像奢侈品。

奢侈品在这城里叫**正常**。


我把 **E07**、**E08**、**E09** 依次排开。

不堆。

排。

排得像给病人换药：

先轻后重。

重的不一定疼。

疼的是**认不出来**。

沈近看一眼 **E07**。

```

## 颗粒 2（节选 L111–L152）·中段推进

```

顾清舟在屏风后。

后不后不重要。

重要的是他不压场。

压场会让沈近变成展品。

展品会亮。

亮会先死。

顾清舟只隔着屏风说了一句：

“别逼他**当场命名**。”

命名两个字像提醒。

提醒我：

**语言有时是刑具**。

我点头。

点给空气看。

空气不会安慰人。

空气只会把雨腥送进来。


**E09**。

相关者旧照、底片袋角、街景里那一截没拍全的檐——我把它们摊开。

摊开像摊一张网。

网眼很细。

细得像想捞住什么。

```

## 颗粒 3（节选 L225–L266）·收束或转折

```

顾清舟走出来半步。

半步就够。

够他把话截成短的。

“有人失名，”他说，“不是失在舌头。”

“是失在**指称链条**。”

我皱眉。

“说人话。”我说。

顾清舟停了一下。

停顿像他惯常的留白。

“他记得疼，”他说，“未必记得疼**属于谁**。”

我胸口一撞。

撞得像门被人踹了一脚。

沈近忽然开口。

声音哑：

“我记得……井。”

井字一落。

落得像石头进潮。

我脊背发凉。

“井里……”他起头。

又断。

断处空白。
```
