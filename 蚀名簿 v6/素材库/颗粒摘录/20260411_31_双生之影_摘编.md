## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 31 节：双生之影（B 视角：言临）

灯小如豆豆如刑，影双人双各不明。
照来旧相浑相似，似到骨肉亦心惊。
替身非戏戏非命，命在指缝指缝轻。
轻处欲言言又止，止时风已叩门声。

------

等待会把时间抻成线。

线勒在脖子上。

勒得不紧。

紧的是你知道它**迟早会收**。

陈言坐在破窗下，窗外河面黑得像泼了墨。

墨里偶尔裂一道白。

白是船灯。

船灯过去，马达声盖过我们的呼吸。

呼吸被盖住就好。

好不等于安全。

安全在这城里像干净纸。


他忽然开口。

开口前先把声音压到最低：

“你给我看箱子那天。”

他说。

“你说备用。”

```

## 颗粒 2（节选 L145–L186）·中段推进

```

他忽然把照片翻过去。

背面有铅笔字。

字迹浅，浅得像怕写深了就犯法：

**观 / 近**

两个字中间一道斜杠。

斜杠像刀。

刀不快。

快的是斜杠本身的意味：

**可替换**。

陈言低声道：

“这是哪来的？”

我问：

“你哪来的？”

反问像挡。

挡不等于答。

陈言看着我。

“我哥屋里书里夹的。”他说。

“我以前以为是两个人合影。”

“现在我觉得——”

他停住。

停得像把刀尖撤回半寸。
```

## 颗粒 3（节选 L275–L316）·收束或转折

```

陈言把照片收回怀里。

收得像把刀收回鞘。

鞘里还响。

响像心跳。

“十一点半。”他说。

不是问。

是提醒。

提醒也像命令。

命令像称呼。

我点头。

“第三趟马达。”我说。

他嗯了一声。

嗯完又补一句——补得像不小心漏出来的软：

“你别死。”

我愣了一下。

愣得像被点名。

“你也是。”我说。

也是两个字太轻。

轻得像回声。

回声不需要共识。

回声只需要重叠。
```
