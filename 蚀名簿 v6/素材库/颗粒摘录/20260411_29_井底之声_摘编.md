## 颗粒 1（节选 L1–L42）·开场气氛与钩子

```
# 第 29 节：井底之声（B 视角：言临）

城西那口井还在施工围挡里。

围挡破了一块，像被人撕开嘴。

嘴不说话。

说话的是井里那种**潮**——潮气涌上来，涌得像有人从下面呼吸。

陈言站在围挡外。

他没往里冲。

冲的人容易变成“到过的人”。

他这些日子学乖了。

学乖像疼出来的茧。

“你带我来听？”他问。

问得像嘲讽。

我摇头。

“带你来看**洞**。”我说。

洞比声音诚实。

诚实不等于好听。


我弯腰捡起一块碎砖。

砖轻敲井壁。

敲在某一截，声音**空**。

空得像鼓。

再往上移半掌，敲下去**闷**。
```

## 颗粒 2（节选 L142–L183）·中段推进

```

回声来了。

来了两遍。

两遍叠在一起，叠得像故意让你听不清：到底是上面喊的，还是下面回的。

我懂。

懂不需要鬼。

鬼只需要你相信：**井会答应你**。

井不答应。

井只会把你的声音折回去。

折回去让你以为——

**有人在叫你下去。**


陈言忽然道：

“录音呢？”

他问得很冷。

冷得像刀。

我抬眼。

“你怎么会想到录音？”我问。

问得像试探他。

陈言不答。

他只看着我。

看得我无处躲。

```

## 颗粒 3（节选 L302–L343）·收束或转折

```

陈言转开话题。

转得像救我。

也救他自己。

“沈近。”他说。

只两个字。

两个字像两口井。

我点头。

“仓库。”我说。

“旧国营转运站在改线后荒了半边，靠河那排——”

我停住。

停得像怕说太满。

说太满会像给秦父递条子。

陈言盯着我。

“你瞒了什么？”他问。

问得像最后一张试纸。

我沉默。

沉默里井底那声唤名又在耳朵里刺了一下。

刺不拔。

拔了会流血。

流血会登记。

“我瞒——”我起头。
```
