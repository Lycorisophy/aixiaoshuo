# 《蚀名簿》服化道与场景设计完整方案

> 版本：v1.0
> 更新日期：2026-04-04
> 定位：服务于悬疑推理、烘托氛围、体现专业性
> 参考：民国时代背景（1986年春），京极夏彦风格

---

## 一、核心设计原则

### 1.1 三大功能定位

| 功能 | 说明 | 实施策略 |
|------|------|----------|
| **烘托氛围** | 建立压抑、潮湿、暧昧的民国悬疑感 | 感官联动：气味+声音+光线+触感 |
| **服务推理** | 道具和场景提供线索，同时设置误导 | 每件关键道具有"真/假"两层叙事 |
| **体现专业性** | 时代考据+职业细节+民俗真实 | 参考民国史料，保证细节可信 |

### 1.2 民国时代特征（1986年可及物品）

**衣着特征**：
- 干部服、中山装（男性主流）
- 素色旗袍（女性主流）
- 蓝灰色调为主，避免过于鲜亮的颜色
- 布料：棉布、卡其、灯芯绒

**生活物品**：
- 搪瓷杯、铁皮暖水瓶
- 机械手表、钢笔
- 竹编暖壶、黄铜钥匙
- 油纸伞、帆布包

**建筑特征**：
- 砖木结构老宅、白墙黛瓦
- 木质门窗、花格窗棂
- 石板路、青砖地面
- 潮湿霉斑、水渍痕迹

## 二、主要角色服化道设计

### 2.1 顾清舟（云清子）

| 属性 | 设计 | 推理功能 |
|------|------|----------|
| **年龄感** | 35岁左右，略显疲惫 | — |
| **主色调** | 藏青色/灰色长衫，旧但不破 | 暗示有底蕴但不张扬 |
| **材质** | 老粗布，浆洗过的挺括感 | 与秦氏老宅的腐朽形成对比 |
| **标志性物品** | 左手腕旧珠串（木质，暗沉） | 暗示家族渊源 |
| **随身物品** | 粗陶茶壶（随身带，不离手） | 体现冷静性格；茶壶可作为"掩护动作" |
| **鞋子** | 黑布鞋，鞋底干净 | 与泥泞工地形成反差 |
| **眼镜** | 圆框老花镜（阅读时戴） | 体现学者气质 |
| **气味** | 茶香+旧纸气息 | 暗示衔霜楼主人的身份 |

**动作习惯**：
- 说话前先喝茶（停顿/思考的标志）
- 翻书时用指腹而非指尖（保护古籍的习惯）
- 站立时微微后仰（保持距离感）

**京极式描写示范**：
> 他的长衫是藏青色的，那种被时间洗淡的颜色，像雨天屋檐下的积水。左手腕上缠着一串珠子，木质的，已经磨得看不清纹路。他端起茶壶时，动作很慢，仿佛在确认什么——又仿佛什么都没有确认。

### 2.3 言临（秦观）

| 属性 | 设计 | 推理功能 |

| **材质** | 整洁但材质普通 | 融入人群的设计 |

| **表情管理** | 温和的微笑，从不变色 | 压抑的情感表达 |

**手套描写（关键道具）**：
- 材质：黑色皮手套，柔软但旧
- 细节：左手手套食指指尖有磨损（写字习惯）

**动作习惯**：
- 说话时看着对方的眼睛（但焦点在"观察"而非"交流"）

**京极式描写示范**：
> 他始终戴着一副旧手套。那种黑色的皮质，经过无数次穿戴，已经变得柔软服帖。他从不摘下来——握手的时候不，吃饭的时候不，甚至睡觉的时候也不。我问过他为什么。他说："手会出卖人。"但我没有问的是：出卖的是谁的手？是他自己的，还是他想隐藏的那个人的？

## 三、核心道具设计

### 3.1 蚀名簿（E01）

| 属性 | 设计 |
|------|------|
| **外观** | 旧式线装册页，封皮暗褐，边角磨损 |
| **材质** | 手造纸，略带霉斑 |
| **尺寸** | 约A5大小，厚约三指 |
| **内页** | 泛黄宣纸，墨迹浓淡不一 |
| **字迹** | 每页两列，名对名排列；后页有"腐蚀"痕迹 |
| **气味** | 陈年纸墨+淡淡的霉味 |
| **触感** | 干燥但指尖有刺痛感（心理投射） |
| **关键细节** | 封底内侧有紫色印痕 |

**推理功能**：
- ✓ 误导：表面是"妖怪道具"，吓唬读者
- ✓ 真相：实为犯罪记录，记载每一次替换
- ✓ 线索：成对名字出现时，暗示外貌相似

**京极式描写示范**：
> 蚀名簿躺在桌上，像一具蜷缩的尸骸。它的封皮是暗褐色的，那种被时间浸透的颜色——不是自然的衰老，而是某种主动的"接受"。我伸手去碰它，指尖触到纸面的瞬间，有一阵微弱的刺痛，像是有什么东西在纸页里醒了过来。它闻起来是陈年纸墨的气息，混着淡淡的霉味——但仔细分辨，还有另一种味道：铁锈味。像血干涸后渗入纸纤维的那种。

## 五、场景氛围描写技法

### 5.1 民国悬疑氛围的五大感官联动

**核心原则**：不是单独描写视觉，而是通过气味、声音、触感、温度、视觉五种感官的联动来构建"身临其境"的悬疑感。

#### 气味作为"记忆触发器"

| 场景 | 主导气味 | 暗示/功能 |
|------|---------|----------|
| 秦氏老宅 | 霉味+旧纸+铁锈 | 腐朽、隐藏的秘密 |
| 瑞成纸马铺 | 稻草+竹篾+焚烧残渣 | 死亡、痕迹处理 |
| 井底密室 | 地下室潮湿+防腐药水 | 长时间封闭、证据保存 |
| 衔霜楼 | 茶香+樟脑 | 顾清舟的理性空间 |
| 知微堂 | 古董沉稳+墨水尖锐 | 情报、信息的双重性 |

**描写示范**：
> 空气里有两种味道在交战。一种是地下室特有的潮湿，凉丝丝的，像是从石头缝里渗出来的；另一种是更古老的味道——纸张腐败的甜腻，混着某种说不清的、像铁锈又像干燥血迹的金属味。前者让我想退出去，后者让我想留下来。

#### 声音作为"不安放大器"

| 场景 | 主导声音 | 暗示/功能 |
|------|---------|----------|
| 枯井 | 回声放大 | 声学诡计，恐惧倍增 |
| 秦氏老宅 | 寂静（太安静） | 不对劲的预警 |
| 纸马铺后院 | 焚烧噼啪声 | 证据处理、毁灭 |
| 城隍庙 | 风声+远处人声 | 见证者的沉默 |

**描写示范**：
> 井底太安静了。不是那种"没有声音"的安静，而是一种"有意识地屏蔽了什么"的安静。我的呼吸声变得格外清晰——吸气、呼气、吸气、呼气——像是在数着什么。远处有风经过井口，发出一种低沉的呜咽，像是有什么东西在用风声说话。

#### 触感作为"危险预警"

| 场景 | 主导触感 | 暗示/功能 |
|------|---------|----------|
| 蚀名簿封面 | 干燥但刺痛 | 心理投射 |
| 井壁砖石 | 冰凉+湿滑 | 危险区域的边界 |
| 言临的手套 | 皮革的温软（异常） | 身份可疑 |
| 地下室铁箱 | 冰凉+锈迹 | 年代久远 |

**描写示范**：
> 我伸手去碰蚀名簿的封面。纸面是干燥的，带着一种老旧书籍特有的涩感——但当我指腹真正触到它的时候，有一阵微弱的刺痛，像是有什么东西在纸页里醒了过来，在试探我的边界。那感觉很难描述：不是疼痛，而是某种"确认"——像是一个人在黑暗中伸出手，碰到了另一个人的手，然后问："你是谁？"

---

### 5.2 光影作为"叙事工具"

#### 光的明暗对比

| 场景 | 光线设计 | 叙事功能 |
|------|---------|----------|
| 秦氏老宅正堂 | 正午强光，但被高墙遮挡 | 表面的"正常"掩盖阴暗 |
| 井底密室 | 微弱裂缝光 | 真相被遮蔽但存在 |
| 衔霜楼 | 暖黄灯光 | 理性、安全的避风港 |
| 城隍庙 | 香火明灭 | 迷信与真相的模糊边界 |
| 档案馆 | 日光灯惨白 | 官方记录的冷漠 |

**光影描写示范**：
> 光线从瓦缝里漏下来，在地面上画出几道细长的光斑。那些光斑是静止的，但看起来却像是在缓缓移动——也许是风在摇动屋檐，也许是灰尘在光柱里浮动，也许是时间本身在流逝。那一刻我突然意识到：在这座老宅里，光也在变老。它不再是新砍的木头反射的那种明亮的白，而是被岁月浸透的、昏黄的、疲惫的光。

### 5.3 空间作为"心理外化"

#### 封闭空间的压迫感

| 空间 | 封闭程度 | 心理暗示 |
|------|---------|----------|
| 枯井 | 完全封闭，只能上下 | 无法逃脱的困境 |
| 井底密室 | 半封闭，有通道 | 被迫面对的秘密 |
| 秦氏老宅 | 大空间+小角落 | 表面宽敞，实则处处藏匿 |
| 纸马铺后院 | 焚烧炉角落 | 毁灭的边界 |

**空间压迫描写示范**：
> 地下室比我想象的要小。四面墙壁向我逼近，天花板压得很低，我不得不弯着腰才能站直。空气是凉的，带着一种地下室特有的潮湿，还有另一种味道——旧纸张腐败的甜腻，混着某种说不清的、像铁锈又像干燥血迹的金属味。这种味道让我想起一个画面：伤口结痂，但痂皮下面还在流血。
