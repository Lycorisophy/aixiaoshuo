## 三、核心场景速查表

### 3.0 枯井、井底与尸体线（仲裁速读）

- **城西工地枯井**与**秦氏老宅后院井**可为**不同实体**（「双井或多井」）；哪一口承接**下井动作、传闻、声学**，以正文为准。本图 **§3.3** 仅示意老宅侧空间关系。
- **井底密室 / 侧洞**：只藏**身份文件与遗物**，**不藏尸体**（与《长篇骨架》§1.1、真设定集 §1.1、附录 **H.5** 一致）。
- **第一具无名尸**：仅**第三幕《穴》非井场景**（如 **北城巷库房** 砖渠）；与井底文件线**空间分离**，禁止在名簿井底发现尸体。

## 四、声学诡计设计

### 4.1 枯井声学原理
```
                    地面
                      │
           ┌──────────┴──────────┐
           │    外层井壁          │
           │   （垂直光滑）        │
           │                     │
           │  ┌─────────────────┐ │
           │  │   声波汇聚点    │ │
           │  │   （底部扩大）   │ │
           │  │                 │ │
           │  │ 说话声→反射→  │ │
           │  │ 汇聚→放大→返回  │ │
           │  └─────────────────┘ │
           └─────────────────────┘

放大原理：
- 垂直井壁：声波不易散失
- 收缩井口：形成"喇叭口"效应
- 底部扩大：增强回声
```

### 4.2 心理暗示机制
```
恐惧状态
    ↓
进入井底
    ↓
声波放大自己的声音
    ↓
产生"有人在模仿我"的错觉
    ↓
恐惧加深
    ↓
可能产生幻听（"听到有人叫自己名字"）
    ↓
秦氏成员解释为"蚀名簿在呼唤"
```

## 五、感官联动描写要点

### 5.1 气味设计

| 场景 | 主导气味 | 心理暗示 |
|------|---------|----------|
| 秦氏老宅 | 霉味+旧纸+铁锈 | 腐朽、隐藏 |
| 纸马铺 | 稻草+竹篾+焚烧 | 死亡、痕迹处理 |
| 井底密室 | 潮湿+防腐药水 | 封闭、证据保存 |
| 衔霜楼 | 茶香+樟脑 | 理性、安全 |
| **知微堂** | 樟脑+旧木柜+淡墨 | 交易、算计、纸寿 |
| **北城巷库房** | 霉味+消毒水涩味+**潮腥**（塌角/砖渠） | 纸的压迫、体制霉斑、**与尸线挂钩的脏腥** |
| **废弃仓库** | 铁锈+潮水泥+久闭空气 | 关押、等待、营救前的窒息 |

### 5.2 氛围描写公式
```
【京极式氛围描写】=
视觉（昏暗/潮湿）+ 气味（陈腐/铁锈）+ 声音（寂静/回声）+ 触感（冰凉/刺痛）
+ 一句哲学性反思
+ 打破"正常"认知的比喻
```

### 5.3 描写范例
> 空气里有两种味道在交战。一种是地下室特有的潮湿，凉丝丝的；另一种是更古老的味道——纸张腐败的甜腻，混着铁锈般的金属味。这种味道让我想起：伤口结痂，但痂皮下面还在流血。

## 六、时代质感要点（1984年）

### 6.1 可用物品

- 服装：藏青干部服、素色旗袍、军绿外套、解放鞋
- 物品：搪瓷杯、铁皮暖水瓶、机械手表、英雄钢笔
- 交通：永久自行车、公共汽车、绿皮火车
- 信息：纸质信件、有线广播、报纸、**单位/公用电话**、听筒与电话机
- **检验/比对侧（与第18、24节等互文）**：介绍信、盖章回执、纸质检验意见摘要、指纹卡或登记痕迹、血型与**厂检/单位存档表**比对等——**避免**现代 DNA 实验室口癖堆砌；叙事需要时可称「省城/上级检验所见」一类**口语**

### 6.2 禁止与慎用

- ❌ 手机、互联网、个人电脑、GPS、信用卡
- ⚠️ **彩电**：当时城里**已有**，但**远未普及**，勿写成每户客厅默认配置；若写，宜用「谁家有一台」「围看少数频道」等限定语境
- ❌ 终章与公开叙述中错代技术堆砌（与真设定集附录 H.0 一致）
