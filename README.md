### 五部结构

| 部 | 名称 | 腐朽阶段 | 核心主题 |
|----|------|----------|----------|
| 第一部 | **侵** | 入侵开始 | 名册出土，百鬼初现 |
| 第二部 | **啮** | 咬噬深入 | 名字被一点点啃噬 |
| 第三部 | **穴** | 形成空洞 | 侵蚀成洞，关系断裂 |
| 第四部 | **耗** | 消耗殆尽 | 意义消亡，秩序崩塌 |
| 第五部 | **朽** | 腐朽重生 | 腐朽尽头，或死或生 |

### 核心改动

1. **书名**：《蚀名簿》——"蚀"取自腐朽五阶段
2. **部名**：侵→啮→穴→耗→朽（腐朽过程）
3. **标题**：采用四字典故风格（例：五里雾中、入廛垂手）
4. **人物**：真名+化名，化名不含真名字
5. **定场诗**：每部开头和结尾各一首（7言56字）
6. **时代**：1984年江南某老城
