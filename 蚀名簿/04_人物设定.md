## 一、双人主视角设定

### 叙事结构

本书采用**双人主视角**叙事，参考福尔摩斯探案集（华生视角）和京极夏彦"百鬼夜行"系列。

| 视角 | 身份 | 说明 |
|------|------|------|
| **A视角** | 男主角身边的人 | 协助调查，记录事件，观察推理过程 |
| **B视角** | 反派角色 | 揭示幕后真相，陈述动机和手法 |

### A视角（男主角身边的人）

**职责**：
- 记录事件经过
- 协助调查
- 观察男主角的推理
- 作为读者代入视角

**特点**：
- 普通人视角
- 见证"降妖除魔"过程
- 记录而不主导

### B视角（反派角色）

**职责**：
- 揭示幕后真相
- 陈述犯罪动机
- 解释"妖怪"的意义
- 推动主题深化

**特点**：
- 了解全部真相
- 陈述人性阴暗面
- 承担"降妖除魔"的解释功能

## 二、系列常驻角色

### 1. 鹿野 / 云清子（系列常驻）

| 属性 | 内容 |
|------|------|
| **真名** | 沈静渊 |
| **化名** | 鹿野（僧名）、云清子（道上名） |
| **出身** | 江南藏书世家"衔霜楼"，正一派道士，后转为曹洞宗僧人 |
| **系列定位** | 串联多部小说的关键人物 |

**背景故事**：
沈静渊出身江南书香世家，家族被权贵陷害，满门入狱。他因在外云游而幸免，手刃仇敌后由道转佛，以"鹿野"为法号。

**辨识特征**：
- 灰色或藏青色僧袍/道袍
- 左手腕戴旧珠串
- 随身带粗陶茶壶

**化名说明**：三种名字之间没有重复字。

---

| **身份** | 城隍庙偏殿守碑人 |
| **系列定位** | 规则守护者，提供对抗失名的手段 |

## 三、本传核心角色

### 3. A视角：陈言（化名）/ 沈远（真名）

| 属性 | 内容 |
|------|------|
| **真名** | 沈远 |
| **化名** | 陈言 |
| **职业** | 民俗文献整理者 |
| **视角定位** | **A视角**：男主角身边的人，记录者 |

**背景故事**：
在某图书馆/档案馆工作，专门整理出土文献和民间文书。性格沉默寡言，善于从文献中发现线索。

有一个哥哥叫沈近，在故事开始前已"失名"。这是他介入此事的直接原因。

**能力**：
- 文献解读：能追溯文献链条，发现伪造与叠写
- 口述史整理：善于还原历史事件的真相

**化名说明**："陈"谐音"陈"，"言"取自言语记录。与真名"沈远"完全不同字。

**辨识特征**：
- 随身携带旧钢笔和笔记本
- 深色外套，衣领竖起
- 说话简短精准

---

### 4. B视角：言临（化名）/ 宋观（真名）

| 属性 | 内容 |
|------|------|
| **真名** | 宋观 |
| **化名** | 言临 |
| **职业** | 无（自称观察者/记录者） |
| **视角定位** | **B视角**：反派角色，揭示真相 |

**背景故事**：
没有职业、没有固定住所的人。自称在"观察"和"记录"，但从不让人看他写的东西。

是最早发现"失名"现象的人之一，实际上他**知道全部真相**。

**能力**：
- 敏锐的归纳能力
- 语言与符号直觉
- 能捕捉规则漏洞

**在叙事中的作用**：
- 作为B视角，揭示幕后真相
- 陈述反派动机和手法
- 解释"妖怪"的社会隐喻

**化名说明**："言"取自言语，"临"意为在场。与真名"宋观"完全不同字。

**辨识特征**：
- 总戴着一副旧手套
- 随身携带空白笔记本
- 说话时喜欢重复别人的话

---

### 5. 纸翁（化名）/ 真名不详

| 属性 | 内容 |
|------|------|
| **真名** | 不详（梁家不使用真名） |
| **化名** | 纸翁 |
| **职业** | 瑞成纸马铺老板，纸扎匠 |
| **视角定位** | 辅助角色，提供线索 |

**背景故事**：
瑞成纸马铺是城中最古老的纸扎铺子，世代相传。纸翁掌握多种民间秘术：藏名术、替身术、渡劫纸马等。

他的祖上与名册的来历有关。

**能力**：
- 纸扎技艺
- 藏名术：将真名藏在纸扎中
- 替身术：用纸人替代被点名者

**化名说明**："纸"取自纸扎行业，"翁"是尊称。
