## 四、不明对话问题

### 问题概述

部分对话缺少说话人标识，导致读者难以理解对话来源。

### 问题示例

**示例1**（第9节）：
```
"你告诉他了？"顾清舟终于开口。

"告诉什么？"

"真相。"
```
✅ 此处有说话人标识，问题不大

**示例2**（第16节）：
```
"家……族。"沈……近……说，"你……和……他……们……不……一……样。"

"那……你……呢？"

"他……有……选……择……吗？"
```
⚠️ 第二句"他"指代不明

### 整改建议

1. 每段对话超过3句必须标注说话人
2. 转换说话人时必须有明确的过渡句
3. 避免连续超过5句无标识对话
