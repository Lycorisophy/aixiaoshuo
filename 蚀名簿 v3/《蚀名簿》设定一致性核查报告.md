## 1. 叙事结构 / 主角定位：设定集的“男主角”与正文不一致（严重）

### 1.1 设定集要求
- 设定集：
  - “**男主角 = 顾清舟** … 类似福尔摩斯 … 衔霜楼主人”（设定集 **L345–347**）
  - “陈言（沈远）≈ 华生医生：第一人称记录者”（设定集 **L348–354**）

### 1.2 正文呈现
- 正文开场第一人称自我介绍：
  - “**我叫陈言，是个写小说的** …”（正文 **L27**）
- 顾清舟在正文里是“来帮忙/带路/神秘同伴”式配角登场：
  - “我转身，看见**顾清舟撑着伞走过来**。”（正文 **L91**）

### 1.3 不符合点
- **设定集：顾清舟是男主、负责‘真相解构/除妖’的核心驱动者。**
- **正文：陈言承担男主叙事功能（开场、主视角、主要行动），顾清舟更像关键配角。**

### 1.4 整改建议（两选一，必须选边站）
- **方案 A（改正文，贴设定集）**：把“解构与推理驱动”更多放到顾清舟身上，让他成为真正意义上的主导者（哪怕叙事仍是陈言第一人称，也要让读者感到“福尔摩斯在房间里”）。
- **方案 B（改设定集，贴正文）**：承认陈言是男主，顾清舟是关键配角/灰色盟友；把设定集里关于“顾清舟=男主=福尔摩斯”的定位整体下调。

> 这一条会影响你后面所有“除妖/解构/节奏设计”的发力点，所以我把它列为**最关键的不一致**。

## 2. 妖怪系统：设定集要求“妖怪三件套”，正文完全缺席（严重）

### 2.1 设定集要求
- “本案中，《蚀名簿》记载的妖怪有三个：**拘魂鬼、无头鬼、蚀书虫**。”（设定集 **L79–80**）
- 并且有“妖怪出场安排/解构时机”（设定集 **L218+**，后续大量表格）。

### 2.2 正文呈现
- 我在正文中全文检索：
  - “拘魂鬼 / 无头鬼 / 蚀书虫 / 衣鱼 / 獝狂”**均为 0 次出现**。

### 2.3 不符合点
- 设定集的“双层结构”（表层妖怪故事→里层犯罪真相）需要读者先被“妖怪版本”抓住，再被推理解构。
- 但正文目前更像直接走“都市传说+档案恐怖+家族替换”，**缺少可被解构的‘妖怪叙事外壳’**。

### 2.4 整改建议
- 如果你坚持设定集 v3.0 的京极式目标：
  1) 至少让三只妖怪以“民间传说/流言/仪式称呼”的形式进入正文（不需要真出现，但要被人相信）。
  2) 再安排顾清舟（或主角）逐步解构：把“拘魂鬼/无头鬼/蚀书虫”分别拆成**可验证的犯罪机制/社会心理机制**。
- 如果你更喜欢正文现在的调性（弱妖怪、强档案恐怖）：
  - 建议把设定集里的“妖怪三件套”改成“可选氛围壳”，不要作为硬约束。

## 3. “妖怪不真实 / 除妖=推理解构”在正文里落地不足（中-严重）

### 3.1 设定集硬约束
- “**妖怪不是真实存在的超自然生物** … 顾清舟的‘除妖’方式：不是符咒法术，而是用推理解构案件。”（设定集 **L71–73**）
- “真相解构 → 顾清舟用推理还原‘妖怪’真实面目”（设定集 **L323**）

### 3.2 正文现状（既有符合点，也有偏离风险）
- **符合点**：正文确实出现“不是妖怪，是人”的压实句：
  - “井下…可能有东西。**不是妖怪，是人。**”（正文 **L1399**）
- **偏离风险**：正文在后段对“真正的井”给出了更强的超自然方向（见下一条“无底井”）。而且顾清舟目前更多是“神秘掌握信息者”，他的“推理解构”作为方法论落地不够强。

### 3.3 整改建议
- 你要么：
  - **把顾清舟（或主角）的解构写成可复述推理链**（证据→推断→反证→结论），让读者看到“妖怪外壳如何被拆掉”。
- 要么：
  - 承认你想写更偏“本格超自然”，那就要同步修改设定集的核心原则（否则永远对不上）。

## 4. 井底设定：设定集强调“密室+遗物”，正文出现“真正的井没有底”的强超自然表达（中-严重）

### 4.1 设定集硬约束
- “井底设定：**藏身份文件和遗物，不藏尸体**”（设定集 **L17**）
- 双层结构里层：
  - “井底 = **藏匿身份文件和遗物的密室**”（设定集 **L41**）

### 4.2 正文呈现
- 你正文里有一处很关键的说法：
  - “一口是伪装…通向密室，真正的那口…通向某个更深的地方…**真正的那口井……没有底。**”（正文 **L34135–34139**）
  - 后面还进一步把“没有底”推向“无限深空间/永远无法逃离”的方向（正文 **L34149–34152**）。

### 4.3 不符合点
- 设定集允许表层有“井底神秘空间”的民俗说法，但**里层真相必须收束到‘密室/犯罪现场/证据藏匿处’**。
- “真正的井没有底”如果在最终解释里仍然是字面意义，会与“里层=密室”冲突。

### 4.4 整改建议（关键是：最后要收束）
- 如果你要保持设定集：
  - 把“没有底”最终解构为：
    - 心理暗示 + 回声效应 + 深井结构错觉，或
    - 井下多层结构/暗道（读者可理解的建筑逻辑），或
    - “没有底”是象征语（败者永远回不去原身份），但**物理空间仍是密室系统**。
- 如果你要保留“无限深空间”的字面超自然：
  - 那设定集的“双层结构里层”需要改写（否则会一直打架）。
