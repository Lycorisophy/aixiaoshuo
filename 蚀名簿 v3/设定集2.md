# 六bis、妖怪设定说明（与V3设定集.md保持一致）

> **⚠️ 妖怪设定说明（以V3设定集.md为准）**

根据V3设定集.md，妖怪元素的定位如下：

### 妖怪的真正定位

| 设定 | 说明 |
|------|------|
| **妖怪不是真实超自然** | 妖怪不是"真实存在的超自然生物"，而是人心变化的具象化 |
| **表层叙事** | 妖怪作为"社会心理层面的真实"保留，用于制造悬念和氛围 |
| **里层真相** | 妖怪传说是秦氏家族散布的烟雾弹，掩盖人为犯罪 |
| **"除妖"方式** | 顾清舟用推理解构案件，而非符咒法术 |

### 三个妖怪的核心功能

| 妖怪 | 表层（民俗） | 里层（真相） |
|------|-------------|-------------|
| **拘魂鬼** | 勾魂——呼唤名字使灵魂出窍 | 言临/秦父接近目标，建立信任后实施替换 |
| **无头鬼** | 身首异处——失去头颅的恐惧 | 受害者原有身份"身首异处"，被替换 |
| **蚀书虫** | 蚕食名字——证据消失 | 秦氏家族销毁证据，身份文件被篡改 |

### 紫色符号

| 设定 | 说明 |
|------|------|
| **紫色是本案颜色符号** | 紫色贯穿全书（紫衣、紫印、紫伞等） |
| **来源** | 拘魂鬼"喜穿紫衣"的民俗原型 |
| **象征** | 秦氏家族的犯罪标记 |

### 妖怪的叙事功能

```
第一阶段（第一幕~第二幕）：妖怪叙事笼罩
├── 读者被妖怪氛围吸引
├── 以为这是玄幻故事
└── 对"失名"现象感到恐惧

第二阶段（第三幕~第四幕）：妖怪解构
├── 顾清舟揭示"妖怪"的真相
├── 读者意识到这是犯罪推理
└── "妖怪"是人心制造的烟雾弹

第三阶段（第五幕）：妖怪散去
├── 真相揭露
├── 妖怪超自然光环消散
└── 但创伤不会消失
```

### 与"无底井"的统一

| 设定 | 说明 |
|------|------|
| **表层** | "真正的井没有底"——超自然恐惧 |
| **里层** | 井底是藏匿证据的密室，可理解的空间逻辑 |
| **处理方式** | 最终解构为心理暗示+深井结构错觉，或象征语（败者永远回不去原身份） |

## 7.1 标题设计原则

### 文艺风格定位
- **含蓄有意境**：使用意象、隐喻、古诗意境
- **统一风格**：每幕标题意象统一，形成整体感
- **呼应主题**：标题与"名字""身份""记忆"主题呼应
- **避免直白**：不直接透露情节，保持神秘感

### 各幕意象系统

| 幕名 | 核心意象 | 标题风格 | 情感基调 |
|------|----------|----------|----------|
| **侵** | 雨、纸、井、雾 | 朦胧、神秘、初入 | 压抑、不安 |
| **啮** | 噬、啮、暗、影 | 侵蚀、黑暗、深入 | 紧张、挣扎 |
| **穴** | 穴、破、露、真 | 揭露、突破、真相 | 冲突、震撼 |
| **耗** | 耗、尽、择、别 | 消耗、选择、代价 | 悲壮、抉择 |
| **朽** | 朽、烬、余、雨 | 余韵、循环、闭环 | 惆怅、开放 |

### 首尾呼应设计
- **第 01 节**：雨落铅灰（开始）
- **第 40 节**：雨落如初（结束，呼应开篇）
- 形成"雨"的意象闭环

- **每节结尾**：留一个小悬念，让读者忍不住点"下一节"
- **每 3 节**：设置一个中等高潮
- **每幕结尾**：设置一个大高潮

### 情感锚点
- **陈言对哥哥的执着**：让读者理解他的动机
- **言临的内心挣扎**：让读者对他产生共情
- **沈近的无辜**：让读者希望他被救

### 反转点设计
- **第 16 节**：发现"秦观"这个名字（第一次反转）
- **第 23 节**：言临坦白想打破传统（第二次反转）
- **第 29 节**：言临选择帮助陈言（第三次反转）
- **第 35 节**：言临消失（第四次反转）

### 节奏变化
- **第 1-8 节**：慢热铺设（悬疑氛围）
- **第 9-16 节**：加速发展（发现真相）
- **第 17-24 节**：情感冲突（身份揭露）
- **第 25-32 节**：高潮迭起（营救行动）
- **第 33-40 节**：缓慢收束（情感余韵）

## 9.5 场景设计要点

### 京极式空间处理

| 原则 | 说明 | 示例 |
|------|------|------|
| **信息密度** | 每个场景都有多余信息，等待被发现 | 茶馆里有人在谈论失踪者，但被主角忽略 |
| **空间隐喻** | 场景物理特征暗示主题 | 秦氏老宅的"深"暗示秘密的"深" |
| **重复出现** | 关键场景多次出现，每次不同 | 茶馆在不同章节出现，每次有新人、新信息 |
| **气味/质感** | 场景有独特的感官特征 | 纸马铺的纸灰味，照相馆的显影液味 |

### 场景转换技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **时间标记** | 用场景暗示时间流逝 | 从"天亮"到"入夜"到"深夜" |
| **天气呼应** | 场景与天气形成呼应 | 雨天的茶馆更具压抑感 |
| **物件过渡** | 用物件连接场景 | 从旧照片→照相馆→老板的信息 |
| **人物引路** | 用人物带路到新场景 | 顾清舟带陈言去某个地方 |
