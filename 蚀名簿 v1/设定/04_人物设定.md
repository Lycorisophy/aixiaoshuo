## 一、双人主视角设定

### 叙事结构

本书采用**双人主视角**叙事，参考福尔摩斯探案集（华生视角）和京极夏彦"百鬼夜行"系列。

| 视角 | 身份 | 说明 |
|------|------|------|
| **A视角** | 男主角身边的人（华生医生） | 记录者，观察并记录男主角的调查和推理 |
| **B视角** | 反派之一（加害者也是被害者） | 读者以为是A的朋友，实际是反派；掩盖同一时刻主角团的调查线 |

### A视角（陈言/沈远）—— 记录者（华生医生）

**职责**：
- 记录事件经过
- 观察男主角的调查和推理过程
- 作为读者代入视角

**特点**：
- 民俗文献整理者，善于从文献中发现线索
- 哥哥沈近失踪是介入此事的直接原因
- 与言临是朋友关系（读者视角）
- 与男主角（鹿野）是合作关系

**与男主角的关系**：
- 陈言负责文献整理和现场记录
- 鹿野（云清子）负责调查推理和"降妖除魔"
- 参考福尔摩斯与华生的分工

### B视角（言临/宋观）—— 反派之一

**职责**：
- 作为另一叙事线，揭示"反派视角"的事件经过
- 掩盖同一时刻A视角（主角团）是如何调查的
- 制造信息差，让读者无法预判真相

**重要设定**：
- 表面上与A是朋友，读者会认为他是帮助者
- 实际上是反派之一（加害者也是被害者）
- 直到第五章真相揭露前，读者都不知道B的真实身份
- B视角的叙述会让读者产生"共情"，增加反转冲击力

**辨识特征**：
- 总戴着一副旧手套
- 随身携带空白笔记本
- 说话时喜欢重复别人的话
- 对文献和名字有异常的兴趣

**化名说明**：
- "言"取自言语，意为"记录者"
- "临"意为"在场"
- 与真名"宋观"完全不同字

## 二、系列常驻角色

### 1. 鹿野 / 云清子（系列常驻）

| 属性 | 内容 |
|------|------|
| **真名** | 沈静渊 |
| **化名** | 鹿野（僧名）、云清子（道上名） |
| **出身** | 江南藏书世家"衔霜楼"，正一派道士，后转为曹洞宗僧人 |
| **系列定位** | **男主角**，串联多部小说的关键人物 |

**背景故事**：
沈静渊出身江南书香世家，家族被权贵陷害，满门入狱。他因在外云游而幸免，手刃仇敌后由道转佛，以"鹿野"为法号。

**辨识特征**：
- 灰色或藏青色僧袍/道袍
- 左手腕戴旧珠串
- 随身带粗陶茶壶

## 三、本传核心角色

### 3. A视角：陈言（化名）/ 沈远（真名）

| 属性 | 内容 |
|------|------|
| **真名** | 沈远 |
| **化名** | 陈言 |
| **职业** | 民俗文献整理者 |
| **视角定位** | **A视角**：记录者（华生医生） |

**背景故事**：
在某图书馆/档案馆工作，专门整理出土文献和民间文书。性格沉默寡言，善于从文献中发现线索。

有一个哥哥叫沈近，在故事开始前已"失名"。这是他介入此事的直接原因。

**能力**：
- 文献解读：能追溯文献链条，发现伪造与叠写
- 口述史整理：善于还原历史事件的真相

**辨识特征**：
- 随身携带旧钢笔和笔记本
- 深色外套，衣领竖起
- 说话简短精准

---

### 4. B视角：言临（化名）/ 宋观（真名）

| 属性 | 内容 |
|------|------|
| **真名** | 宋观 |
| **化名** | 言临 |
| **职业** | 自称"记录者" |
| **视角定位** | **B视角**：反派之一（加害者也是被害者） |

**背景故事**：
没有职业、没有固定住所的人。自称在"观察"和"记录"。与陈言是朋友关系，经常一起讨论文献和民俗问题。

**重要说明**：
- 表面上与陈言是朋友，读者会认为他是可信赖的伙伴
- 实际上他是反派之一，知道失名现象的真相
- 直到第五章真相揭露，读者都不会怀疑他的身份
- B视角的叙述内容是"反派视角"，读者看到的"真相"实为误导

**能力**：
- 敏锐的归纳能力
- 语言与符号直觉
- 能捕捉规则漏洞

**辨识特征**：
- 总戴着一副旧手套
- 随身携带空白笔记本
- 说话时喜欢重复别人的话

---

### 5. 纸翁（化名）/ 真名不详

| 属性 | 内容 |
|------|------|
| **真名** | 不详 |
| **化名** | 纸翁 |
| **职业** | 瑞成纸马铺老板，纸扎匠 |
| **视角定位** | 辅助角色，提供线索 |

**背景故事**：
瑞成纸马铺是城中最古老的纸扎铺子，世代相传。纸翁掌握多种民间秘术：藏名术、替身术、渡劫纸马等。

他的祖上与名册的来历有关。

**能力**：
- 纸扎技艺
- 藏名术：将真名藏在纸扎中
- 替身术：用纸人替代被点名者

## 六、叙事策略说明

### 双视角设计目的

1. **信息遮蔽**：B视角掩盖主角团的调查进展，让读者无法预判下一步
2. **情感误导**：读者对B视角产生共情，误以为他是盟友
3. **反转冲击**：第五章揭露B的真实身份时，情感冲击更强
4. **主题深化**：通过B视角展现"加害者也是被害者"的复杂人性

### 读者预期管理

- 前期：读者认为言临是陈言的朋友/帮手
- 中期：B视角叙述让读者更加信任这个角色
- 后期：真相揭露，B是反派之一，造成认知颠覆

---

## 七、化名命名规则

- 真名：角色真实身份
- 化名：取自职业、尊号、习惯等
- **化名与真名完全不同字**
